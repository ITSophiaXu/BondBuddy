# 材料编制知识

按用户2026-10-07授权整理“券商知识-106”。当前入口：[版本目录](2026-10-07/catalog.json)，共8个“交易所×文种”包（立项、核查、法律、私募摘要）。`packs/` 是提交 CLI 的 Markdown；`sources/` 是按原文顺序提取的7份可读来源；`originals/` 保存新增原件，已存在的交易所完整指引按字节哈希复用旧目录。
