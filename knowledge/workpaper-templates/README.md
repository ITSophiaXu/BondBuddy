# 公司债尽职调查底稿格式库

`2026-10-27/catalog.json` 与 147 份 DOCX 只保存经用户指定的公司债底稿格式，分为综合核查记录、专项核查、发行人说明、诚信查询、访谈、培训、不适用说明七类。不是已完成底稿，也不提供本项目事实或实际履职证据。

`scripts/build-workpaper-templates.py <本地模板库> <目标目录>` 从经授权的本地库生成格式副本：核验原样例 hash，将文字换为槽位，删除原图、签名、嵌入内容、批注、外链、文档属性及非页码字段。保留对应字体、段落、表格、页面和页眉页脚结构，ZIP 使用固定时间以支持复现。原件不提交本仓库。`source_sha256` 仅用于内部定位格式来源。

API 按事项和文件角色匹配，校验 DOCX hash，并把完整模板字节固定到任务输入；worker 不依赖开发者个人目录。说明使用对应标题、正文和节属性；业务文件由生成任务在格式副本中填入当前项目内容。窄序号列不能直接填长文本，宽表、残留空段落、强制分页及页码必须按内容整理并渲染复核。格式库的可解析性不代表任意填充后自动排版合格。

运行 `python -m unittest discover -s python/tests -p test_workpaper_templates.py` 验证全部147份包、七类匹配、哈希、关系和内容脱敏。`scripts/qa-workpaper-templates.py <输出目录>` 生成合成压力探针，仅用于定位格式容量限制，不能作为业务成果或专业验收。
