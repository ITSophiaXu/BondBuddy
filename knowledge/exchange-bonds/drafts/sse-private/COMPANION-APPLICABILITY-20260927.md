## 1. 私募发行对象：适当性不是一个布尔值

关联 `sse-private-private-investors`。来源为[适当性办法第2条](../../verification/2026-09-27-companion/sources/sse-suitability-2023.md#article-002)、[第6条](../../verification/2026-09-27-companion/sources/sse-suitability-2023.md#article-006)、[第8条](../../verification/2026-09-27-companion/sources/sse-suitability-2023.md#article-008)。

- 第6条分别列持牌/登记机构、其产品、特定基金及境外机构、法人/其他组织、个人、另获认可投资者。第（四）类须同时满足最近一年末净资产≥2000万元、金融资产≥1000万元、投资经历≥2年；不能只核一项。其他类别按其自身法定证据核对，不能让持牌银行额外走第（四）类路径。
- 第8条的普通私募/小公募公司债原则上仅限专业投资者中的机构投资者；不能把满足第6条（五）的个人自动放进普通私募发行对象。
- 第8条保留发行人董监高及持股比例**超过5%**股东参与**该发行人**债券的例外。必须核具体关系、时点和本期对象；5%不等于超过5%，不能泛化到其他发行人。承销机构参与另核业务分离和利益冲突。
- [第10条](../../verification/2026-09-27-companion/sources/sse-suitability-2023.md#article-010)的非交易取得只支持持有到期/卖出，不支持另行买入。2023公告对不再符合新条件的原持有人也区分持有/卖出与买入。
- [第11条](../../verification/2026-09-27-companion/sources/sse-suitability-2023.md#article-011)风险事件披露后的买入限制独立核；第14条风险不匹配特别警示不是绕过第8条资格限制的授权。第13/15/20/21/22条还涉及资格、权限、名单、至少每两年后续评估和动态调整。
- 200人和穿透另据公司债管理、私募挂牌及相应配套规则核对。本办法不能独立支持“所有资管产品一律按一人”或“一律穿透”的算法。

## 2. 公司治理、任职和债券制度

关联 `sse-private-issuer-governance`、`sse-private-disclosure-officer-2026`、`sse-private-protection`、`sse-private-trustee-continuing-duties`。公司法来源是商务部政府转载，尚未完成正式母本逐字校核；条款定位可用于继续审阅，不能提升来源等级。

- [第59—60条](../../verification/2026-09-27-companion/sources/company-law-2023.md#article-059)：有限责任公司股东会可授权董事会决定发债；全体书面同意、一人公司书面决定各有条件。不把“没有另一次股东会会议”直接判无授权。
- [第68—69条](../../verification/2026-09-27-companion/sources/company-law-2023.md#article-068)：有限责任公司董事/职工代表安排，与章程下董事组成的审计委员会代行监事会职权分开核对。第68条“职工人数三百人以上”及已设有职工代表的监事会例外不能漏。
- [第75—76条](../../verification/2026-09-27-companion/sources/company-law-2023.md#article-075)、[第83条](../../verification/2026-09-27-companion/sources/company-law-2023.md#article-083)：小规模或少股东有限责任公司的单董事/单监事、全体股东一致同意不设监事有特定条件。
- [第121条](../../verification/2026-09-27-companion/sources/company-law-2023.md#article-121)是股份公司审计委员会路径，至少3名成员、过半数任职及独立性等要求；不能照搬成所有有限责任公司第69条的统一人数阈值。[第176条](../../verification/2026-09-27-companion/sources/company-law-2023.md#article-176)国有独资公司还须单独辨认。
- [第178条](../../verification/2026-09-27-companion/sources/company-law-2023.md#article-178)按列举情形、个人责任及起算日审核任职禁止；判刑执行期满5年、缓刑考验期满2年、破产/吊销个人责任3年等不能简化成“最近三年无处罚”。涉及失信还须符合条文的债务及法院列入条件。缺查询材料不证明不存在禁止事项。
- [第204—206条](../../verification/2026-09-27-companion/sources/company-law-2023.md#article-204)：204、205分别以“公开发行公司债券的”起句。私募的持有人会议/受托安排仍引用本包已有的CSRC及上交所私募规则、实际合同，不能错引这两条作为直接私募义务来源，也不能反过来声称私募没有相应义务。206的勤勉及冲突规定不能当作已履职事实。
- [第266条](../../verification/2026-09-27-companion/sources/company-law-2023.md#article-266)：存量公司调整还需国务院实施规则；不能把2024-07-01统一当作所有存量公司出资重新起算日。公司法全文不能替代重大资产重组办法。

| 场景ID | 给定情形 | 应有结果/禁止误判 |
| --- | --- | --- |
| GOV-01 | 有限责任公司未设监事会，章程/决议证明第69条审计委员会安排 | 进入依法替代路径；不因“无监事会”直接判错，仍核真实履行和公司类型 |
| GOV-02 | 只在审计报告看到“无监事会”，无章程/任职信息 | 待补证/判断，不推定已设审计委员会也不确定违法 |
| GOV-03 | 小规模或少股东有限责任公司一名董事，或经全体股东同意不设监事 | 分别核75/83条件及实际决定，不能套普通3人监事会检查 |
| GOV-04 | 股份公司称采用审计委员会替代，但仅2名成员 | 提示121条人数条件不符；不能用有限责任公司69条掩盖 |
| GOV-05 | 有限责任公司董事会有真实有效的发债授权 | 核授权链与具体范围/期限，不一律要求本次再开股东会 |
| GOV-06 | 待任人员被宣告缓刑，考验期满不足2年 | 对应178条第二项核实际判决/起算；没有处罚搜索结果不能反推可任职 |
| GOV-07 | 存量公司认缴期限超过5年，仅有工商摘录 | 核成立日、章程及实施/过渡规则，不直接自动重设期限或确定违法 |
| GOV-08 | 私募稿以公司法204/205条直接说明必须设会议/受托管理人 | 更正适用依据至经核的私募规则和合同；不能删掉私募实际保护安排 |
| GOV-09 | 仅有受托协议或规则指南，正文写“受托管理人已完成核查” | 缺实际履职证据，不能将应为/约定改成已完成 |

`governanceReview`仍为人工handler。文献URL/摘要不等于真实控制链、任职、章程、重组评估；不能把填入`currentCompanyLawEvidence`字符串升级成已核合法。局部缺口按UPD-GAP-01标明并继续有依据的全文更新。
