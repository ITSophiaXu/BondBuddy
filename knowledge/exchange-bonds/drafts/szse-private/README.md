# 深交所普通私募公司债券募集说明书写作执行规则

依据用户于2026年10月10日转述的五项专家反馈修订。

## 适用范围和执行顺序

本次专家反馈适用于深交所普通私募公司债券募集说明书更新。先按本期材料和用户明确提供的信息更新；未提供的材料按以下财务与非财务规则分别处理。本节覆盖本知识文件及引用方法中与之冲突的旧写法；专家已给定的章节模板、段落结构和专业术语继续执行。不得将内部知识的研究状态写成募集说明书正文的草稿声明。

## 缺失财务数据使用【X】

需要更新至目标报告期、但本次材料和用户明确提供的信息均不能支持的财务数据，在正文或表格的相应数值位置统一使用【X】。包括报表金额、附注明细、经营财务指标、有息债务、授信、担保等财务金额及比例；依赖缺失输入且无法计算的合计、占比、比率和变动幅度同样使用【X】。不填零，不猜数，不用历史数字冒充目标期数字；有依据的历史比较期数据保留。确不适用的项目仍按模板使用“-”。缺失项的具体说明放入批注，不在正文另写【待补充】、【待确认】或【待人工确认】。

## 其他信息优先沿用历史内容

非财务信息需要更新，但用户没有提供材料或明确的新信息时，尽量保留同一发行人历史募集说明书的内容、写法和原有时点，不自行扩写、推测或润色成新事实。历史内容和本期材料、用户明确要求发生冲突时，以已有明确依据处理，不将已知错误继续沿用；尚不能解决的差异只在批注说明。不得机械更新旧日期，使未核实的旧事实看似已经核实到本期。历史中也不存在且无新依据的内容不自行新增，必要核对事项仅入批注；原模板必要空项保留原结构，不另造说明性句子。

## 严格执行专家模板

已有章节模板、标准句式、表格项目和专业术语的，沿用其结构与措辞，仅替换有依据的变量、数字和已明确变化的事实。财务分析缺少新原因材料时，保留仍与对应事项及期间相符的历史表述；历史原因不能解释新变动时，只披露有依据的数值变化，原因核对提示放入批注，不编造行业、经营或管理原因。不得为了行文完整自行增加章节、发行参数、承诺、判断或风险结论。

## 正文使用正式披露语言

成果应是可用的募集说明书，按发行人信息披露文件的正式、客观、结论性语体编写。统一使用“募集说明书”，不得简称为“募集书”。正文不出现AI与用户的对话、称呼、提问、操作建议、执行进度或编制过程，例如“您未提供”“请补充”“根据您上传的材料”“我已更新”。不加入“编制稿”“draft草稿”“编制稿重大待补事项”“本稿不能作为正式文件”等编制说明。原模板依法需要的发行人声明、交易所审核声明及实质风险提示仍按适用模板保留。

## 不得自行增写发行信息

发行额度、无异议函、批次、期限、资金用途、增信和机构等属于发行事实与条款，必须来自用户明确提供的信息、本期材料或历史中可沿用的原有内容；发行额度不因含金额就按缺失财务数据规则自行新增。原文没有“拟申请额度”且本期无新增依据时，不得添加“拟申请额度：10.00亿元（无异议函及批次【待人工确认】）”，也不得添加同义的推测性句子。历史有额度而无新信息的，保留原句及原有事实范围，不自行改为新申请、已获批或新批次。

## 提示放批注而不放正文

资料缺失、沿用历史、来源冲突、需要核对的事项和编制说明，确需提示时放在相关内容的Word批注中；编制工作记录可以保存处理过程。不得将提示做成正文段落、括号说明、页眉页脚、文本框或脚注，也不得用红色说明文字插入正文。不得在重大事项提示中汇总“无异议函、授信、债务台账、担保、评级、联系人、受托管理协议及签署材料待确认”等材料清单。批注简述具体需核对事项，不使用AI与用户的对话口吻。真实Word修订的显示颜色不属于这里禁止的人工红色说明文字。

## 交付前清理

通读正文、表格、页眉页脚、文本框和脚注，清理编制类待补标记、对话、草稿说明和无依据新增内容；核对“募集说明书”称谓及专家模板执行情况。仅保留按本规则需要的财务数值占位【X】，并将提示挂到对应内容的批注中。此清理不得删除真实风险披露、依法需要的声明或有证据支持的重要事实；也不得把占位值或沿用内容宣称为已核实事实。
