<a id="p00007"></a>
## P00007

第一章 总 则

<a id="p00008"></a>
## P00008

第一条 为了规范公开发行公司债券（含企业债券）审核会相关工作，加强审核委员管理，提高审核工作质量和透明度，上海证券交易所（以下简称本所）根据《证券法》《公司债券发行与交易管理办法》《上海证券交易所公司债券发行上市审核规则》等有关规定，制定本指引。

<a id="p00009"></a>
## P00009

第二条 公开发行公司债券审核会有关事宜适用本指引。本指引未作规定的，按照本所其他相关要求执行。

<a id="p00010"></a>
## P00010

本指引所称审核委员，是指按规定的条件和程序产生，对公开发行公司债券发行上市申请进行审议的专业人士。

<a id="p00011"></a>
## P00011

非公开发行公司债券、资产支持证券、公募REITs审核会有关事宜参照适用本指引的规定。

<a id="p00012"></a>
## P00012

第三条 审核委员通过参加审核会的形式履行职责。会议以合议方式进行审议，通过集体讨论，形成合议意见。本所结合审核会审议意见，出具公司债券审核意见。

<a id="p00013"></a>
## P00013

第四条 审核委员依照法律、行政法规、中国证监会规定以及本所相关规定，独立履行职责，不受任何机构和个人的干扰。

<a id="p00014"></a>
## P00014

第五条 本所负责审核委员的日常管理，为审核委员履行职责提供必要的条件和便利，并对其履职行为进行监督。

<a id="p00015"></a>
## P00015

第二章 人员组成和任期

<a id="p00016"></a>
## P00016

第六条 审核委员由本所相关专业人员和本所以外的专业人士（以下简称所外委员）担任。

<a id="p00017"></a>
## P00017

第七条 审核委员应当符合下列条件：

<a id="p00018"></a>
## P00018

（一）政治立场坚定，具有较高的政治素质和职业道德修养；

<a id="p00019"></a>
## P00019

（二）坚持原则，公正廉洁，忠于职守，严格遵守法律、行政法规、部门规章和本所及相关自律组织的业务规则；

<a id="p00020"></a>
## P00020

（三）熟悉公司债券发行上市审核相关的法律、行政法规、部门规章和本所业务规则；

<a id="p00021"></a>
## P00021

（四）最近3年没有影响履行审核委员职责的违法、违规记录以及严重不良诚信记录；

<a id="p00022"></a>
## P00022

（五）本所认为必要的其他条件。

<a id="p00023"></a>
## P00023

第八条 本所按照下列程序聘任审核委员：

<a id="p00024"></a>
## P00024

（一）本所或者本所提请中国证监会派出机构等相关单位推荐审核委员候选人；

<a id="p00025"></a>
## P00025

（二）相关单位按照客观、公正原则推荐人选；

<a id="p00026"></a>
## P00026

（三）本所组织评议并拟定审核委员名单；

<a id="p00027"></a>
## P00027

（四）本所作出聘任决定。

<a id="p00028"></a>
## P00028

第九条 审核委员每届任期2年，可以连任，连任原则上不超过2届。

<a id="p00029"></a>
## P00029

审核委员任期届满后，由本所予以续聘或者更换。审核委员完成换届前，应当按照本指引的规定继续履行职责。

<a id="p00030"></a>
## P00030

本所根据需要，可以调整审核委员每届任期年限和连续任职期限。

<a id="p00031"></a>
## P00031

第十条 审核委员因个人原因、岗位调动等情形无法继续履职的，应当及时告知本所。本所将暂停其履职，经履行相关程序后可以予以补充或更换。

<a id="p00032"></a>
## P00032

第十一条 审核委员有下列情形之一的，本所予以解聘：

<a id="p00033"></a>
## P00033

不再符合本指引规定的任职条件；

<a id="p00034"></a>
## P00034

（二）2次（含）以上无故缺席审核会；

<a id="p00035"></a>
## P00035

（三）违反法律、行政法规、部门规章或严重违反工作纪律；

<a id="p00036"></a>
## P00036

（四）本人任期内提出辞聘申请，经本所研究认为不适合担任审核委员；

<a id="p00037"></a>
## P00037

（五）本所认定的不适合担任审核委员的其他情形。

<a id="p00038"></a>
## P00038

按照本条规定解聘审核委员不受其任期是否届满的限制。审核委员解聘后，本所可以选聘新的审核委员。

<a id="p00039"></a>
## P00039

第三章 审核委员职责

<a id="p00040"></a>
## P00040

第十二条 审核委员履行以下职责：

<a id="p00041"></a>
## P00041

（一）对公司债券发行上市申请进行审议，并提出审议意见；

<a id="p00042"></a>
## P00042

（二）对主承销商和其他证券服务机构的申报工作质量发表专业意见；

<a id="p00043"></a>
## P00043

（三）对本所公司债券发行上市相关咨询事项提供专业意见；

<a id="p00044"></a>
## P00044

（四）本所规定的其他职责。

<a id="p00045"></a>
## P00045

第十三条 审核委员履行职责时应当遵守以下要求：

<a id="p00046"></a>
## P00046

（一）工作勤勉尽责，客观公正，严格遵守廉政纪律、保密纪律、工作纪律；

<a id="p00047"></a>
## P00047

（二）按时参加审核会，提前做好参会准备；

<a id="p00048"></a>
## P00048

（三）妥善保管因履行职责而获取的会议材料，保守国家秘密、发行人及相关机构的商业秘密、商业敏感信息；

<a id="p00049"></a>
## P00049

（四）存在本指引规定的可能影响公正履职情形时，及时提出回避；

<a id="p00050"></a>
## P00050

（五）不得与发行人及其他相关单位或个人进行私下接触；

<a id="p00051"></a>
## P00051

（六）不得泄露审核会讨论内容和评议情况；

<a id="p00052"></a>
## P00052

（七）不得干扰或影响其他审核委员独立判断和发表意见；

<a id="p00053"></a>
## P00053

（八）不得利用审核委员身份或履行职责时获得的信息，为本人或他人谋取不正当利益；

<a id="p00054"></a>
## P00054

（九）未经本所同意，不得以本所审核委员名义参与相关社会活动；

<a id="p00055"></a>
## P00055

（十）本所的其他要求。

<a id="p00056"></a>
## P00056

第十四条 审核委员应当亲自出席会议，不得委托他人代为出席。

<a id="p00057"></a>
## P00057

审核委员因回避、不可抗力、意外事件或者其他特殊情形不能出席会议的，应当提前通知本所。本所可以根据情况对参会委员或者会议安排等作相应调整。

<a id="p00058"></a>
## P00058

第十五条 存在下列情形之一，可能影响公正履职的，审核委员应当主动要求回避，并不得对回避事项施加影响：

<a id="p00059"></a>
## P00059

（一）本人或者其亲属近两年内担任发行人或其控股股东、实际控制人或者承销机构的董事、监事、高级管理人员；

<a id="p00060"></a>
## P00060

（二）本人或者其亲属、本人所在工作单位与发行人、承销机构存在股权关系，可能影响其公正履行职责；

<a id="p00061"></a>
## P00061

（三）本人或者其亲属近2年内为发行人提供保荐、承销、审计、评估、法律、评级、咨询等服务，可能影响其公正履行职责；

<a id="p00062"></a>
## P00062

（四）本人或者其亲属担任董事、监事、高级管理人员的公司与发行人存在行业竞争关系，或者与发行人、承销机构有利害关系，经认定可能影响其公正履行职责；

<a id="p00063"></a>
## P00063

（五）审核会召开前，与发行人、承销机构及其他相关单位或者个人进行过接触，可能影响其公正履行职责；

<a id="p00064"></a>
## P00064

（六）本所认定的可能产生利害冲突或者本人认为可能影响其公正履行职责的其他情形。

<a id="p00065"></a>
## P00065

前款所称亲属，包括配偶、父母、子女、兄弟姐妹、配偶的父母、子女的配偶、兄弟姐妹的配偶。

<a id="p00066"></a>
## P00066

本所定期督促审核委员开展回避事项自查。前款规定的情形发生变更的，审核委员应当及时向本所更新报备。

<a id="p00067"></a>
## P00067

第十六条 任何机构或者个人干扰审核委员履行职责的，审核委员应当及时向本所反映。

<a id="p00068"></a>
## P00068

第四章 审核会

<a id="p00069"></a>
## P00069

第十七条 本所根据审核工作进度安排审核会，确定会议召开时间。

<a id="p00070"></a>
## P00070

审核会可以采取现场会议、通讯会议等方式进行。

<a id="p00071"></a>
## P00071

第十八条 每场审核会由不少于5名审核委员参加，本所依照公平公正的原则随机抽选参会审核委员。

<a id="p00072"></a>
## P00072

本所从现场会议中随机抽选部分场次，邀请2名所外委员参加。

<a id="p00073"></a>
## P00073

抽选的审核委员因回避等事由无法参会的，可以抽选其他审核委员补足。

<a id="p00074"></a>
## P00074

第十九条 本所公司债券审核业务负责人或其指定的审核委员为审核会召集人，负责组织审核委员讨论并形成审议意见。

<a id="p00075"></a>
## P00075

第二十条 本所于审核会召开前，将会议时间、地点等信息通知参会的审核委员。

<a id="p00076"></a>
## P00076

审核委员收到通知后，应当尽快确认是否参会，并作廉洁履职相关承诺。因本指引第十五条规定的回避情形或其他特殊情形不能出席会议的，应当及时提出回避或缺席申请。

<a id="p00077"></a>
## P00077

本所收到相关单位和个人提出的审核委员回避申请，本所将进行核实。经核实理由成立的，该审核委员应当回避，本所及时告知申请人。

<a id="p00078"></a>
## P00078

第二十一条 本所于审核会召开前，将下列会议材料发送给确认参会的审核委员：

<a id="p00079"></a>
## P00079

拟审核项目名单；

<a id="p00080"></a>
## P00080

（二）本所公司债券发行上市审核机构（以下简称审核机构）出具的审核报告；

<a id="p00081"></a>
## P00081

（三）项目申请文件、审核问询及回复；

<a id="p00082"></a>
## P00082

（四）本所认为需要提交审核会的其他材料。

<a id="p00083"></a>
## P00083

审核委员应当认真审阅会议材料，研究审核关注问题并准备会议意见。需要就申请文件中的特定事项询问发行人、增信机构、主承销商或者证券服务机构等的，审核委员应当提前告知本所。

<a id="p00084"></a>
## P00084

第二十二条 审核会召开前，审核委员不得私下与该次审核会相关的发行人、中介机构及个人进行接触。

<a id="p00085"></a>
## P00085

第二十三条 审核会召开时，审核会召集人负责主持会议，并在会议过程中维持会议纪律。

<a id="p00086"></a>
## P00086

审核会过程中，出现不可抗力、意外事件或其他特殊情形，导致会议无法继续召开的，可以暂停会议。导致会议暂停情形消除后，会议继续进行；短时间内难以消除的，本所可以另行安排会议或者取消会议。

<a id="p00087"></a>
## P00087

第二十四条 审核会开始后，审核人员汇报项目基本信息及审核情况、审核问询及其回复情况，并提出初步审核意见。

<a id="p00088"></a>
## P00088

第二十五条 审核人员汇报后，审核委员重点围绕申请是否符合发行上市条件、审核问询及其回复情况及其他审核重点关注问题，独立发表意见。

<a id="p00089"></a>
## P00089

第二十六条 审核会根据审核委员的意见及集体讨论情况，经合议按少数服从多数的原则形成审议意见。审议意见包括通过与不通过两种类型。

<a id="p00090"></a>
## P00090

因存在尚待核实的重大问题，无法形成审议意见的，审核会可以暂缓审议。再次召开审核会审议的，本所原则上邀请前次参会审核委员参加审核会。原审核委员无法参会的，本所可以另行抽选审核委员审议。

<a id="p00091"></a>
## P00091

第二十七条 本所审核机构对审核会重点讨论情况及形成的审议意见进行记录，由参会委员确认。

<a id="p00092"></a>
## P00092

第二十八条 本所根据审核会审议意见，出具发行人符合发行上市条件和信息披露要求的审核意见或者终止审核。

<a id="p00093"></a>
## P00093

审议会召开前，发生重大事项对发行人发行上市条件产生重大影响的，本所可以取消对本单项目的审议。重大事项处理完成后，再行召开审核会审议。

<a id="p00094"></a>
## P00094

第五章 管理与监督

<a id="p00095"></a>
## P00095

第二十九条 审核会现场会议全程录音录像，按照规定接受内外部监督。

<a id="p00096"></a>
## P00096

第三十条 本所对审核委员进行监督，接受对审核委员的举报监督。

<a id="p00097"></a>
## P00097

审核委员涉嫌违反本指引或者本所相关规定的，本所可以进行调查，并根据调查结果对有关审核委员进行谈话提醒、批评或予以解聘。涉嫌违法犯罪的，本所向中国证监会报告或者依据相关规定移交司法机关处理。

<a id="p00098"></a>
## P00098

审核委员涉嫌违法违规的，在接受调查期间暂停参加审核会。

<a id="p00099"></a>
## P00099

第三十一条 本所可以将审核委员的履职情况通报其所在单位、有关自律组织或监管机构。

<a id="p00100"></a>
## P00100

第三十二条 发行人、承销机构、证券服务机构唆使、协助或者参与干扰审核委员工作的，本所可以按照相关规定进行处理。

<a id="p00101"></a>
## P00101

第六章 附 则

<a id="p00102"></a>
## P00102

第三十三条 本指引由本所负责解释。

## P00103

第三十四条 本指引自发布之日起施行。本所于2023年10月20日发布的《上海证券交易所公司债券发行上市审核规则适用指引第5号——审核会》（上证发〔2023〕171号）同时废止。
