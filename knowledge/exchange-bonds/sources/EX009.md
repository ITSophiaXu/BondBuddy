## P00005

（2023年修订）

<a id="p00007"></a>
## P00007

第一章 总则

<a id="p00008"></a>
## P00008

第一条 为了规范公司债券（含企业债券）审核实施程序，提升知名成熟发行人债券融资效率，上海证券交易所（以下简称本所）根据《公司债券发行与交易管理办法》《上海证券交易所公司债券发行上市审核规则》《上海证券交易所非公开发行公司债券挂牌规则》等规定，制定本指引。

<a id="p00009"></a>
## P00009

第二条 本所按照分类监管理念，对知名成熟发行人的公司债券申请项目适用优化审核安排，简化审核流程、提高融资服务效率。

<a id="p00010"></a>
## P00010

本指引所称知名成熟发行人，指市场认可度高、行业地位显著、公司治理完善、经营财务状况稳健、信息披露成熟的发行人。

<a id="p00011"></a>
## P00011

本所可以根据市场发展情况与审核工作开展情况，适时调整优化审核安排并向市场公开。

<a id="p00012"></a>
## P00012

第三条 主承销商、证券服务机构应当积极协助发行人评估并申请适用本指引规定的优化审核安排。

<a id="p00013"></a>
## P00013

第二章优化审核认定

<a id="p00014"></a>
## P00014

第四条 同时符合下列情形的发行人，本所可以对其公司债券申请项目适用优化审核安排：

<a id="p00015"></a>
## P00015

（一）公司生产经营符合国家宏观调控政策和产业政策，市场认可度高、行业地位显著、公司治理完善、信息披露成熟；

<a id="p00016"></a>
## P00016

（二）经营财务状况稳健，企业规模、资本结构、盈利能力满足相应要求（具体要求详见附件1）；

<a id="p00017"></a>
## P00017

（三）最近3年财务报告未被注册会计师出具非无保留意见的审计报告，或者最近3年内财务报表曾被注册会计师出具保留意见但保留意见所涉及事项的重大影响已经消除；

<a id="p00018"></a>
## P00018

（四）最近36个月内公司及其所属企业集团、实际控制人无债券或者其他债务违约、延迟支付本息的情形；

<a id="p00019"></a>
## P00019

（五）公司未受到债券融资限制，且最近36个月内公司未因债券业务违规被实施行政处罚或纪律处分；

<a id="p00020"></a>
## P00020

（六）本所根据投资者保护需要确定的其他标准。

<a id="p00021"></a>
## P00021

发行人不符合前款第二项规定的情形，但公司股票为上证50指数成分股的上市公司，或在全球市场、在国家重点支持的行业领域等具有领先地位的企业，以及本所根据国家政策导向和市场发展需要认可的其他发行人也可以向本所提出适用优化审核安排。

<a id="p00022"></a>
## P00022

鼓励符合条件的民营企业向本所提出适用优化审核安排。

<a id="p00023"></a>
## P00023

第五条 发行人符合前款情形的，可以书面形式（参考格式详见附件2）向本所说明公司符合本指引第四条规定的情形。

<a id="p00024"></a>
## P00024

本所经确认，向发行人发出通知，发行人自通知发出之日起24个月内向本所申报的公司债券项目适用本指引第三章规定的优化审核安排。

<a id="p00025"></a>
## P00025

第六条 发行人出现下列情形，可能严重影响发行人偿债能力的，发行人、主承销商应当及时向本所报告，本所可以终止对发行人公司债券项目适用优化审核安排：

<a id="p00026"></a>
## P00026

（一）不符合本指引第四条规定的情形；

<a id="p00027"></a>
## P00027

（二）相关财务指标出现重大不利变化；

<a id="p00028"></a>
## P00028

（三）融资过度且出现债务集中兑付压力；

<a id="p00029"></a>
## P00029

（四）行业地位发生重大不利变化；

<a id="p00030"></a>
## P00030

（五）债券、股票成交持续异常波动；

<a id="p00031"></a>
## P00031

（六）公司及其所属企业集团、实际控制人出现重大负面舆情。

<a id="p00032"></a>
## P00032

前款规定情形消除后，发行人可以重新按本指引第五条规定的方式向本所提出适用优化审核安排。

<a id="p00033"></a>
## P00033

第三章优化审核的措施

<a id="p00034"></a>
## P00034

第七条 知名成熟发行人可以按照下列方式编制、提交申请文件：

<a id="p00035"></a>
## P00035

（一）一般公司债券、企业债券和专项品种公司债券可以合并编制申请文件并统一申报。申报的公司债券发行规模等应当符合公司债券的法定发行条件，申报阶段无需明确募集资金具体使用安排。

<a id="p00036"></a>
## P00036

（二）可以在发行前备案阶段再明确每期发行的具体品种、发行方案、募集资金运用安排、债项评级（如有）等；企业债券可使用不超过50%的募集资金用于补充流动资金等非项目建设用途。

<a id="p00037"></a>
## P00037

（三）不存在影响公司经营或偿债能力的重大不利变化，且不存在影响发行上市条件的重大事项的，公司可以申请适当延长年度、半年度财务报告有效期。年度财务报告有效期最多延长至当年8月末，半年度财务报告有效期最多延长至次年4月末。已披露季度财务报告的，应当同步披露主要季度财务数据。

<a id="p00038"></a>
## P00038

发行人半年度经营和财务指标无重大不利变化或不存在对偿债能力产生重大影响的事项，可适当简化募集说明书中发行人基本情况、财务会计信息等相关章节信息披露内容。

<a id="p00039"></a>
## P00039

首次申请公开发行公司债券的发行人不适用本项优化审核安排。

<a id="p00040"></a>
## P00040

（四）公司董事、监事、高级管理人员在债券项目申请阶段按照规定对债券发行文件签署书面确认意见，并承诺认可各期发行文件、履行规定职责的，每期债券发行前无需另行签署书面确认意见。

<a id="p00041"></a>
## P00041

第八条 知名成熟发行人可以在项目申报时确认设立主承销商团，待各期债券发行时指定主承销商。

<a id="p00042"></a>
## P00042

第九条 本所对知名成熟发行人债券项目申请，审核时限原则上不超过10个工作日。

<a id="p00043"></a>
## P00043

第十条 申请非公开发行公司债券的，知名成熟发行人可在确定该期发行品种、发行规模、发行期限、募集资金运用安排等发行要素以及该期债券的主承销商、受托管理人与证券服务机构后，直接在发行前备案阶段向本所提交发行申请文件，经本所确认挂牌条件后发行。

<a id="p00044"></a>
## P00044

本所对企业债券和专项品种公司债券发行前备案程序另有规定的，从其规定。

<a id="p00045"></a>
## P00045

第十一条 知名成熟发行人可以在前次公司债券有效注册文件或挂牌转让无异议函到期前3个月内向本所再次申请发行公司债券。披露信息无重大变化的，发行人可以适当简化编制申请文件。

<a id="p00046"></a>
## P00046

第四章附则

<a id="p00047"></a>
## P00047

第十二条 发行人不符合本指引第二章规定的情形，但是具有一定市场认可度、财务状况健康、盈利能力良好、违约风险较低，或者属于国家政策和市场发展所支持行业的，本所可以对其公司债券项目初审、审核问询与回复、审核会等审核环节流程进行优化，提高审核效率。

<a id="p00048"></a>
## P00048

第十三条 本所对企业债券、专项品种公司债券、特定行业发行人债券项目的审核程序另有规定的，从其规定。

<a id="p00049"></a>
## P00049

第十四条 本指引由本所负责解释。

<a id="p00050"></a>
## P00050

第十五条 本指引自发布之日起施行。本所于2022年5月27日发布的《上海证券交易所公司债券发行上市审核规则适用指引第6号——知名成熟发行人优化审核》（上证发〔2022〕79号）同时废止。

## P00092

一、发行人应当参照《中国上市公司协会上市公司行业统计分类指引》确认行业归属。

<a id="p00093"></a>
## P00093

二、资产总额、资产负债率、总资产报酬率应当按照企业最近一年经审计的财务数据进行计算，或者按照最近3年经审计的财务数据分别进行计算后取平均值，两者按孰优原则选择。其中，总资产报酬率（%）=EBIT/总资产平均余额×100%；EBIT（息税前盈余）=利润总额+费用化利息支出。

<a id="p00094"></a>
## P00094

三、发行人符合下列条件之一的，可以不受资产总额、资产负债率和总资产报酬率的指标限制：

<a id="p00095"></a>
## P00095

（一）资产规模不少于3,000亿元，且资产负债率或总资产报酬率符合本附件分行业经营财务指标要求；

<a id="p00096"></a>
## P00096

（二）由中国证监会派出机构或省级政府主管部门推荐并经本所认可。

<a id="p00097"></a>
## P00097

四、本所可以根据市场发展及投资者保护需要，适时调整适用优化审核安排的发行人分行业经营财务指标要求。
