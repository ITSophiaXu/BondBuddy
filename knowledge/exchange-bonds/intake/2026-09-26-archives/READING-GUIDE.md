# 沪深公司债规则的适用顺序与开发边界

本说明基于本次31份收件、既有专家指南和单独取得的深交所官方修订说明。它把原文要求转成开发需要保留的条件与验收案例，不把材料接收或文本提取当作专业批准。新增官方取证只覆盖深交所2026优化审核公告/附件，其他来源的效力仍沿用各自记录。

## 先选择市场和发行方式，再判断专项条件

| 范围 | 主要工作底稿 | 需要区别处理的内容 |
|---|---|---|
| 上交所私募 #20 | 申请文件指引私募专章、2025审核重点、已有16节专家骨架 | 挂牌条件确认；普通财务披露两年及一期；不能套公募注册条件 |
| 上交所小公募 #21 | 公开发行审核规则、申请文件与公募披露要求 | 专业投资者；公募发行条件及三年/一期财务资料独立核验 |
| 上交所大公募 #22 | 小公募共通部分叠加普通投资者要求 | 第222号令第16条附加资格、普通投资者附加指标，不能回退小公募 |
| 深交所私募 #23 | 挂牌条件确认程序、2024募集说明书参考文本、13节专家骨架 | 两年及一期的参考文本依据明确；正式挂牌及财务有效期依据还须补齐 |
| 深交所小公募 #24 | 公开审核程序、申请文件指引、2024参考文本 | 公募财务资料、上市要求及本期机构/签章，不复制上交所节号 |
| 深交所大公募 #25 | 深交所公募要求叠加普通投资者要求 | 三年/一期财务正文与近两年附加指标表同时保留 |

范围表是研究索引。不能把任何普通公司债范围中的“通常”写成忽略新设主体、重组、申请阶段或特定审核安排的无条件代码。

公开程序与非公开程序有独立来源：深交所[EX029 P00010](../../sources/EX029.md#p00010)明确面向普通或专业投资者公开发行，私募[EX030 P00010](../../sources/EX030.md#p00010)明确挂牌条件确认。上交所[EX007 P00007](../../sources/EX007.md#p00007)是公开发行审核程序。不能因为同在“通用规则”文件夹就把全部程序适用于六种范围。

## 报告期、有效期和规则适用日是三件事

深交所2024参考文本[EX016 P00884](../../sources/EX016.md#p00884)明确：“公开发行公司债券提供三年一期财务数据，非公开发行公司债券提供两年一期财务数据”，随后以公开发行举例。因此正文之后出现的“三年”必须结合该说明判断，不能直接要求所有私募都补三年，也不能把所有历史事件回溯期改成两年。

深交所申请文件指引[EX026 P00059](../../sources/EX026.md#p00059)记载最近一期截止后六个月内有效，特别情况下申请延期不超过一个月，并保留另有规定的例外。该文件的公开申请范围要同时阅读，不能据此未经核验直接宣称深交所私募的全部财务有效期要求已解决。

上交所私募已有本市场专章取证，见[现有官方核验目录](../../verification/2026-09-26/README.md)。两个市场的财务窗口、延期程序各自取源。新稿的目标报告期由用户确认；本次法规适用日由项目另行固定，不能使用财务截止日或上传日代替。四组样本的已确认目标不需要本轮重问。

验收至少包含：同一截止日不同市场/方式；普通规则和已确认优化审核的对照；只有延期申请但无处理依据；公募近两年附加指标表不替代三年财务正文。依据缺失保留待确认，不将不确定状态填成通过。

## 公募和大公募不能只改标题

第222号令的[EX035 PAGE005](../../sources/EX035.md#page005)是普通投资者附加资格的原始依据之一，不能用“已满足专业投资者公募条件”推出满足普通投资者条件。深交所[EX026 P00177](../../sources/EX026.md#p00177)规定三年及最近一期财务信息、编制合并报表时同时披露母公司报表；[P00178](../../sources/EX026.md#p00178)另要求面向普通投资者时以列表披露近两年主要会计数据和特定财务指标。这些要求应分别记录和验收。

跨发行方式更新时，要联动发行条件、投资者范围、财务资料、风险、认购承诺与发行程序。N=0只表示没有新增财务期间，不表示可以不做结构与条款适配，也不等于不消耗任何工作量。

## 深交所2026优化审核的实质增量

官方公告为[深证上〔2026〕1227号](OFFICIAL-NOTICE.md)，2026-09-04发布并施行，2023版同时废止。用户附件与官方下载附件SHA-256相同。修订说明[EX040](../../sources/EX040.md)用于解释改动，判定仍回到正式条文[EX039](../../sources/EX039.md)。

| 变化 | 正文/说明依据 | 开发时必须保留的条件 |
|---|---|---|
| 分行业总资产报酬率要求调整 | EX039附件一；[EX040 P00011](../../sources/EX040.md#p00011) | 普通表格为“＞2.5%”，不可改成“≥2.5%”；资产和负债率列也保留严格比较符 |
| 资产规模豁免门槛调整 | [EX039 P00087–P00089](../../sources/EX039.md#p00087) | 不少于2500亿元等路径须满足相应条件并经交易所审慎确认；总资产报酬率仍不得低于1.5% |
| 上市公司替代条件调整 | [EX039 P00024–P00028](../../sources/EX039.md#p00024) | 最近两年信息披露评价A、资产不低于200亿元、净资产收益率不低于2%；仅替代第六条财务指标项，其他条件不豁免 |
| 确认函期限三十六个月 | [EX039 P00029–P00030](../../sources/EX039.md#p00029) | 需要真实确认函及出具日期；不从本次修订自行推定旧函自动延期 |
| 简明披露与申请文件简化 | [EX039 P00033–P00036](../../sources/EX039.md#p00033) | 本期发行前需补的信息仍须补齐；不能按“优化”标签删除重大信息 |
| 报表延期 | [EX039 P00037](../../sources/EX039.md#p00037) | 无重大不利变化等条件下可以申请；年度最多当年8月末、半年度最多次年4月末；已披露季度报告的同步披露主要季度数据 |
| 发行前声明简化 | [EX039 P00038–P00039](../../sources/EX039.md#p00038) | 新任人员仍需签署；审计机构免重复声明要求已有声明且主承销商核验本期引用一致 |
| 承销商团与再申报 | [EX039 P00040–P00042](../../sources/EX039.md#p00040) | 每期发行前确定该期主承销商；可提前六个月申请不等于已取得新批文 |
| 不再适用的情形 | [EX039 P00043–P00050](../../sources/EX039.md#p00043) | 条件不满足、财务恶化、融资压力、行业地位/交易/负面舆情等继续核查；不能取得资格后永久放行 |
| 删除旧安排 | [EX040 P00015](../../sources/EX040.md#p00015) | 不能沿用旧版非公开项目同时提交挂牌申请及发行文件安排，也不能自动沿用未达到优化条件发行人的旧优化安排 |

表中的数值是有范围的规则要求，不是对具体发行人的资格结论。优化审核发行人通常也需要核对最近三年审计意见及36个月债务/处罚情况，不能因普通私募主要财务披露采用两年就抹去这些独立回溯要求。

## #19行业标准有原文依据，代码映射仍待固定

以下原文均指向《中国上市公司协会上市公司行业统计分类指引》：

- 深交所申请文件[EX026 P00150](../../sources/EX026.md#p00150)。
- 深交所募集说明书参考文本[EX016 P00607](../../sources/EX016.md#p00607)。
- 深交所2026优化审核附件[EX039 P00085](../../sources/EX039.md#p00085)。
- 上交所2026优化审核附件[OV-sse-mature-2026 P00092](../../verification/2026-09-26/sources/sse-mature-2026.md#p00092)。

这些证据说明采用该标准名称有出处，但本次31份材料没有包含该分类指引的完整版本和代码表。开发可以准备版本化字典和映射结构，仍需取得实际标准文件、固定版本/hash并核对映射。不能仅凭名称近似映射到另一套行业码，更不能拿#77三大主营业务分类代替。

基础行业用于法规所需的行业归属；城建、房地产、投资控股集团等重点标签可以并存。某些规则按业务/资产构成触发，并不意味着应把多个标签拼成单个行业值。上述原文也不构成发行人实际行业已核验的证据。

## 参考文本、脚注与本期承诺

上交所投资者保护[EX015](../../sources/EX015.md)具有选择项、空格及脚注说明，不能把所有示例直接写成本期承诺。此次提取保留脚注和尾注，单独使用`FOOTNOTE-*`/`ENDNOTE-*`锚点；批注仍为`COMMENT-*`，不会作为已签认结论。

深交所募集说明书参考文本[EX016 P00281](../../sources/EX016.md#p00281)明确引用本所第2号投资者权益保护参考文本，本包没有该原件。拿到上交所同名参考文本并不能补足深交所缺口；#23–#25保留待补状态。实际本期协议、触发条件和条款间一致性仍需核对。

## 专项品种与发行机制按触发条件增加

沪深2026专项品种材料分别为[EX005](../../sources/EX005.md)、[EX032](../../sources/EX032.md)，修订说明[EX033](../../sources/EX033.md)不替代正文。2024参考文本中的专项示例不能覆盖2026新增要求。短期、可续期、可交换、绿色、科创等内容按本期实际安排进入独立增量，不能把普通规则已收齐等同所有复杂品种已上线。

招标、簿记建档、备案和债务重组置换是不同业务环节。[EX002 P00007](../../sources/EX002.md#p00007)、[EX012 P00009](../../sources/EX012.md#p00009)、[EX013 P00008](../../sources/EX013.md#p00008)各有自己的适用范围。债务重组类置换也不等于审计报告中的所有重大资产重组，不能混用一个布尔值触发全部条款。

## 缺口怎样体现在用户成果中

按已有UPD-GAP-01决定，缺少局部数据、条款资料或说明时，继续处理有依据的全文内容，具体位置和成果摘要列出待补/待人工确认。影响选择规则的市场、阶段、法规适用日、关键身份或授权不清，以及相应规则能力未接通，应分别报告。不能把工程接入缺口描述成“用户未提供材料”，也不能由用户确认目标期间替代财务事实或法规有效性核验。
