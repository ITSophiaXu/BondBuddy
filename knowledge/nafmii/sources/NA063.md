<a id="p00016"></a>
## P00016 (body)

匡算募集资金用途大类，无需披露具体明细，但需合理匡算注册规模。

<a id="p00018"></a>
## P00018 (body)

发行阶段：

<a id="p00019"></a>
## P00019 (body)

1.对于成熟层企业（即第一类TDFI、第二类DFI企业），可按注册阶段要求披露募集资金用途。

<a id="p00020"></a>
## P00020 (body)

2.对于成熟层以外的企业，应具体披露募集资金用途。

<a id="p00022"></a>
## P00022 (body)

披露科技型企业符合科技创新债券具体对应的情形，具体如下：

<a id="p00023"></a>
## P00023 (body)

情形1，应披露企业具备科技创新称号的相关情况，包括但不限于称号名称、认定机构、政策依据以及有效期等；

<a id="p00024"></a>
## P00024 (body)

情形2，应披露企业所入选名单情况或科技贷款支持范围的具体类别，包括但不限于有关筛选标准、企业符合标准的相关说明等；

<a id="p00025"></a>
## P00025 (body)

情形3，应披露企业所属上市板块、所属行业领域等；

<a id="p00026"></a>
## P00026 (body)

情形4，应披露专利所属领域、专利能否用于产业化、专利与主营业务相关性等；

<a id="p00027"></a>
## P00027 (body)

情形5，应披露有关部门认定属于科技型企业的相关依据。

<a id="p00028"></a>
## P00028 (body)

母公司发行科技创新债券支持科技型子公司发展的，根据对应情形披露子公司相关信息。

## P00038 (body)

## P00050 (body)

运用章节

<a id="p00055"></a>
## P00055 (body)

注册阶段：用于科技创新领域的，应披露拟投资项目投资领域、遴选标准及流程，科技创新领域包括科技型企业和高技术制造业、高技术服务业、战略性新兴产业、知识产权（专利）密集型产业等科技相关产业。

<a id="p00057"></a>
## P00057 (body)

发行阶段：

<a id="p00058"></a>
## P00058 (body)

1.对于成熟层企业（即第一类TDFI、第二类DFI企业），暂无投资标的具体信息的，按注册阶段要求披露项目投资领域、遴选标准及流程、是否符合科技创新相关要求等内容。

<a id="p00059"></a>
## P00059 (body)

2.对于成熟层以外的企业，发行阶段应披露科技创新的具体用途，可列示高于实际发行规模的科技创新用途。

<a id="p00060"></a>
## P00060 (body)

①用于科创领域股权投资的，披露募集资金匡算依据、发行人与拟投资企业之间的持股关系及变动情况、拟投资金额、拟使用募集资金占投资额比例、股权投资运营实体情况、投资方式、被投企业科技创新属性等；

<a id="p00061"></a>
## P00061 (body)

②用于科技创新领域基金出资的，披露基金类型及相关认定情况、基金备案情况、各方认缴金额及出资比例、资金到位情况、基金投向、已投项目情况、基金存续期等。

<a id="p00063"></a>
## P00063 (body)

披露股权投资机构符合科技创新债券具体对应的情形，具体如下：

<a id="p00064"></a>
## P00064 (body)

情形1，应披露发行人相关基金管理人资质及牌照情况；

<a id="p00065"></a>
## P00065 (body)

情形2，应披露发行人近两年投资产生的相关收入在整体营业收入的占比情况、企业或主要负责投资的团队成立时长，并以列表形式列明近三年重要成功项目退出案例；

<a id="p00066"></a>
## P00066 (body)

情形3，应披露发行人符合《国务院关于推进国有资本投资、运营公司改革试点的实施意见》（国发〔2018〕23号）相关情况，包括但不限于总体要求、功能定位、授权机制、治理结构等，并进行对应承诺；

<a id="p00067"></a>
## P00067 (body)

情形4，应披露发行人符合相关要求的依据。

<a id="p00069"></a>
## P00069 (body)

企业发行科技创新债券，应对募集资金用途及使用方式的合规性、存续期变更募集资金用途等事项进行承诺。

## P00073 (body)

债券存续期内每年4月30日、8月31日前披露存续期间募集资金具体使用情况，披露内容包括但不限于已投项目数量及情况、所投项目或公司符合科技创新属性说明、基金类型、未使用募集资金规模、募集资金管理等情况。

## P00075 (body)
