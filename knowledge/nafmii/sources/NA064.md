## P00009 (body)

披露股权投资业务模式，包括但不限于运营方式、投资资金来源、投资决策流程、风险控制策略、投资项目遴选标准、业务合法合规性等。

## P00011 (body)

发行人应突出股权投资机构行业特征，其中：

<a id="p00012"></a>
## P00012 (body)

1.发行人及其子公司存在基金投资业务的，披露如下：

<a id="p00013"></a>
## P00013 (body)

①管理人资质情况，披露管理人名称、获得资质时间等；

<a id="p00014"></a>
## P00014 (body)

②基金管理情况，包括但不限于管理基金的数量、总规模、投资方向、退出情况等，列表披露主要在管基金的名称、类型、存续期、认缴与实缴规模、已投项目数量、退出项目数量等；

<a id="p00015"></a>
## P00015 (body)

③参投基金情况，包括但不限于已参投基金的数量、参投金额等，列表披露参投基金的名称、类型、存续期、投资方向、参投份额及其对应的认缴与实缴规模等；

<a id="p00016"></a>
## P00016 (body)

④报告期内基金清盘情况，包括但不限于清盘规模、收益水平等，列表披露清盘基金名称、发行人累计投资规模、退出规模、收益水平指标等；

<a id="p00017"></a>
## P00017 (body)

⑤超期仍未退出的基金情况（如有），包括但不限于基金规模、未按时退出原因、后续延期安排等。

<a id="p00018"></a>
## P00018 (body)

2、发行人及其子公司存在股权投资业务的，披露如下：

<a id="p00019"></a>
## P00019 (body)

①已投项目情况，包括但不限于已投项目的数量、投资金额、投资方向等，列表披露已投资项目的名称、金额、行业、投资时间、持股比例等；②报告期内已投资项目退出情况，包括但不限于退出项目的规模、退出方式、收益水平指标等。
