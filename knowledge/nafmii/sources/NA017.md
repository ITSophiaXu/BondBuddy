<a id="l00008"></a>
## L00008 (body)

    第一条 为规范定向债务融资工具专项机构投资人（以下简称专项机构投资人）遴选程序，促进投资人队伍建设，加快推进多层次资本市场体系建设，根据中国人民银行《银行间债券市场非金融企业债务融资工具管理办法》（中国人民银行令〔2008〕第1号）以及中国银行间市场交易商协会（简称交易商协会）相关自律规则，制定本细则。

<a id="l00009"></a>
## L00009 (body)

    第二条 本细则所称专项机构投资人，是指除具有丰富的债券市场投资经验和风险识别能力外，还熟悉定向债务融资工具风险特征和投资流程，具有承担风险的意愿和能力，自愿接受交易商协会自律管理，履行会员义务的合格机构投资人群体。

<a id="l00010"></a>
## L00010 (body)

    第三条 符合以下条件之一的机构可成为专项机构投资人：

<a id="l00011"></a>
## L00011 (body)

    （一）中国人民银行公开市场业务一级交易商；

<a id="l00012"></a>
## L00012 (body)

    （二）银行间债券市场做市商；

<a id="l00013"></a>
## L00013 (body)

    （三）银行间债券市场债券结算代理人；

<a id="l00014"></a>
## L00014 (body)

    （四）非金融企业债务融资工具主承销商；

<a id="l00015"></a>
## L00015 (body)

    （五）信用风险缓释工具核心交易商或信用风险缓释凭证创设机构；

<a id="l00016"></a>
## L00016 (body)

    （六）定向债务融资工具平均托管量或交易量达到一定规模的机构投资人。

<a id="l00017"></a>
## L00017 (body)

    第四条 交易商协会秘书处根据本细则第三条的条件拟定180家专项机构投资人名单，经债券市场专业委员会评议后发布。

<a id="l00018"></a>
## L00018 (body)

    第五条 专项机构投资人名单原则上每两年调整一次。

<a id="l00019"></a>
## L00019 (body)

    第六条 本细则由交易商协会秘书处负责解释和修订。

<a id="l00020"></a>
## L00020 (body)

    第七条 本细则自发布之日起施行。
