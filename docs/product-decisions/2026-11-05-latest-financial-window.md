# 历史募集说明书与最新一期财务材料共同更新

2026年11月5日，用户针对PPN募集说明书明确：2024、2025年度比较数据可以直接沿用本企业历史募集说明书，用户已提供最新窗口期的2026年半年度财务报表，应据此更新财务披露；不能因未重复提供历史年度审计原件而停止更新，也不能只加一段概览。

同企业历史稿提供适用的历史比较数据，最新报表提供本期事实，目标品种知识提供披露及分析方法。先确认材料正文主体、期间、单位、合并／母公司口径及重述差异，不能凭文件名、上传分类或相似企业关系套数。未见审计意见的一期不表述为已审计；沿用历史比较数不等于本次重新核验审计原件。

对于通常的全文更新，上传的本企业新一期报表晚于保存窗口时，模型使用材料确认的最新一期进行财务滚动，并准确记录实际期间与保存值的差异。只有用户明确限定历史截止日、不纳入最新一期、局部续改或复核整改范围时，才保持该限定；不把一个较旧的保存窗口单独解释成禁止更新新一期。无法确定主体／期间的材料按具体疑点处理，不猜测，也不改写已锁定输入或历史任务。

更新覆盖合并和母公司六张主表、相关分析表、正文、指标、重要提示、风险和重复引用。表内已披露数据须逐项使用；缺少附注只限制对应附注明细、变动原因及依赖缺失输入的指标，不限制已有主表。不以概览、提示用户补年度原件或少量总额替代全文滚动。

保留原稿格式的固定编辑流程须支持新增报告期列：保留原有列及其数据，沿用相邻列样式，保持表格总宽度，记录真实新增单元格和宽度修订。复杂合并等局部限制如实记录，不能跳过其他可更新表格。

这是编制行为和工具能力的修正，不新增下载检查门槛，不改变收费、公共契约或数据库，不自动重跑生产任务或覆盖旧成果。按现行协作规则完成开发、自测和本地集成验收，再由指定发布chat统一上线。模型真实更新效果与编辑工具的自动化测试分别验证。
