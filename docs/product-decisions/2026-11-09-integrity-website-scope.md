# 诚信核查报价覆盖全部已选网站

2026-11-09，用户确认：“这个报价模块有问题，不应该限制网站的数量”。此决定覆盖此前自动计费范围中的“至多20个适用官网”。

- 用户可选择当前网站目录中的任意非空范围，包括全选。报价模块不再另设网站数量上限。
- 完整名单与网站范围保存到同一份报价快照和核查任务，不截取前20项，也不按网站数量拆成多轮或追加费用。沿用现有每轮价表、锁价和重试去重机制。
- 本次决定仅调整网站数量；主体范围、身份与网站有效性、重复项、所属项目、报价版本及输入哈希校验继续适用。历史任务和报价保持原快照。
- 真实官网无法访问或未返回查询结果时仍如实记录，报价可提交不代表所有网站已查到有效结果。

修复涉及API自动报价及公共服务范围说明，无数据库迁移或新依赖。开发和自测完成后交付统一集成与发布，不自行部署生产。
