# 2026-10-27 按目录判断并生成底稿

## 2026-10-28 生成操作入口优化

用户反馈在检查阶段找不到“确认并生成底稿”，并询问“为什么需要判断范围”。本次优化已获用户授权；下面的旧按钮名称由本节覆盖，生成清单、费用和明确确认规则保持不变。

- 选择目录后始终展示主操作按钮。初始名称为“批量生成底稿”，点击只提交可生成文件检查；旁边常驻说明“核对清单与费用后，再确认生成”。
- 将“判断范围”改为“检查可生成文件”。等待、运行、暂停、失败和完成分别显示真实状态；运行时显示已检查条数。检查期间保留禁用的生成入口，并说明下一步。
- 检查完成后，同一位置显示“确认并生成底稿”；核对清单、费用并勾选确认后才能提交。重新检查为次要操作，资料不足与业务不适用继续区分。
- 无选中项、无募集书、浏览器存储失败、待确认请求和已有活动批次均在按钮旁显示原因或恢复操作。请求不确定时继续使用原请求，既有生成接口和计费不变。
- 自动轮询不重建未变化的确认清单，保留核对位置、已展开帮助与确认状态。

实现与原型同批更新：`apps/web/src/workpaper-panel.ts`、`product-prototype/public/workpaper-batch.html`、共享 `workpaper-entry.css`。同尺寸截图、测试与集成交接见 `apps/web/test-evidence/workpaper-actions/README.md`。不新增依赖、接口或迁移。开发和自测完成不代表用户验收或生产发布。

文件生成增加“Excel 底稿目录＋募集说明书 → 范围判断 → 用户确认 → 底稿和不适用说明”的能力。入口位于现有文件生成导航，继续采用项目中明确选择的募集说明书版本。

## 用户流程

1. 选择项目及募集说明书，进入“批量生成底稿”，上传 XLSX 目录。
2. 预览编号、名称、保存目录和原表位置；勾选本批范围并填写编制要求。
3. 点击“判断生成范围”。系统提取固定募集书文本，按条目检索相关段落，分组调用既有 Codex 适配器，逐项给出可生成、业务不适用、资料不足或需外部原始证据的判断及理由。
4. 确认页优先展示全部不生成项，同时列出可引用原文位置、待补材料及实际生成费用。用户勾选已核对范围，再明确点击生成。没有确认时不创建底稿任务，也不生成说明文件。
5. 可生成项逐份编制 Word 底稿和编制说明；不生成项逐份生成可编辑“不适用说明（本次未生成情况说明）”。资料不足和需要原始证据的说明明确写“尚不能认定该业务不适用”，不伪造证据或完成记录。
6. 单独下载或按原目录打包；ZIP 包含“底稿”“编制说明”“不适用说明”目录和生成清单.json。全部不生成时仍可获得说明文件包。

判断引文必须逐字存在于本次提供的募集书段落中；缺少有效引文的“可生成”或“不适用”判断降为资料不足，显示具体缺口。不根据未披露推定业务不存在。检索片段不能证明全部原文中绝无某事项；原始证照、签章件和实际访谈/函证记录不由募集书替代。模型的语义判断仍需用户和专业人员复核。

## 文件与执行

- 支持 XLSX，单文件不超过 10 MB，最多 30 张表、10,000 行、1,000 项文件。旧 XLS 需另存 XLSX。名称列必需；编号、目录路径、类型、编制要求可选。隐藏表和公式跳过并提示；不执行公式。目录及重名路径保留安全的对应关系。
- 范围判断使用持久化 run、租约、模型调用日志和分组检查点；每组最多 12 项。任务恢复时复用已保存分组；用户重新判断会建立新任务。所有模型调用只使用项目授权的固定募集书。扫描或文本不完整时保留提示；无可引用文本时按资料不足处理。
- 确认请求固定判断 ID/哈希、目录哈希、所选条目、要求、募集书版本及价格版本。任一输入变化须重新判断；已提交批次保持原依据。网络结果不确定时用原请求 ID 恢复，不能自动提交新的生成范围。
- 可生成项复用 M4 workpaper 文种和 m4_workpaper 任务；逐项执行、失败隔离、暂停/继续/取消后续排队、只重试未完成项。成功 run 和文件保留。工作簿目录不加入固定 12 文种目录。
- 不生成项的说明根据已确认判断确定性编制，保存到私有 Blob，校验回读哈希，按原目录编号交付。说明中记录募集书来源、理由、待补材料及确认版本；它不替代原始证据。
- 范围判断、目录导入和不生成项说明不另收费。实际编制底稿沿用每份 4,500 积分（含正文和编制说明），使用现有逐步扣费、暂停保存、取消部分结算与平台失败退款规则。确认页仅对可生成项计价。
