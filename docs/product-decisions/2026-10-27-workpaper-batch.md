# 2026-10-27 按 Excel 目录批量生成底稿

用户要求：文件生成增加“上传底稿目录（通常 Excel）＋募集说明书 → 数百份底稿文件”的能力。本次实现放在现有文件生成入口的项目条内，沿用项目和准确募集书版本选择。

## 用户流程与边界

1. 选择项目和本次依据的募集说明书，进入“批量生成底稿”。
2. 上传 XLSX 目录，预览编号、名称、保存目录、原表位置和识别提示。支持查找、全选、清空和逐项选择。
3. 补充本批要求，核对份数、募集书版本、单价及总额后明确开始。
4. 后台逐份生成可编辑 Word 正文和独立编制说明。关闭页面不取消任务；可暂停后续排队、继续、结束排队、重试未完成项。
5. 已成功文件可单独下载，也可按目录结构打包下载。包内含 `底稿/`、`编制说明/` 和 `生成清单.json`。未完成项列入清单，不冒充已交付。

首版支持 XLSX，不直接读取旧 XLS、CSV。单文件不超过 10 MB，最多 30 张表、10,000 行、1,000 份输出。至少需要“底稿名称”或“文件名称”等名称列；可选编号、目录路径/分类、类型、编制要求/备注列。支持共享字符串、合并分类单元格、编号父目录和无编号的明确目录行。隐藏表跳过并提示；公式不执行、不使用缓存值，提示转为值后重传。重名路径自动加后缀，路径不能逃逸下载目录。

募集书只能支撑已披露事实。底稿记录主体、报告期、币种、单位、口径和可确认的引用定位；缺失信息标为待补充/待核实。证照、工商档案、访谈、函证、走访、承诺、签章等原始证据项只生成归档准备页或待执行提纲，不能伪造证据、已执行程序、签名印章或肯定核查结论。成果是待专业复核的工作稿。

## 执行与数据

- 复用 M4/Codex 文件任务、不可变输入、固定方法、模型调用日志、私有成果存储和授权下载。增加 `workpaper` 文种与 `m4_workpaper` 计费任务；不加入原固定 12 文种目录，也不开放普通草稿接口绕过目录绑定。
- 迁移 `0117_workpaper_batches.sql` 新建目录快照、批次、条目和尝试历史。目录内容与条目 manifest 不可修改；批次固定目录哈希、准确来源版本、条目集合、要求和报价版本。上传后的新募集书不替换已提交批次的输入。
- 每批建立独立 M4 topic/执行项目，与原项目共用 canonical execution scope。调度器每批同时只启动一项，数据库行锁、请求 ID、不可变尝试历史和既有 run 租约共同防重；多 worker 可竞争领取。
- 失败项不阻断其余项。重试只处理失败/取消项和未启动项，保留成功 run 与文件。用户暂停或取消排队时，当前文件继续收尾。若单项任务因余额、供应商或材料原因暂停，先从任务详情处理，再继续文件包。项目同一时间只允许一个待完成底稿批次。
- `workpaper` 成果登记在 M4 私有成果表及批次条目中，不作为固定文种的一次新版登记，避免数百底稿互相覆盖。现有“项目文件”固定文种区不展开底稿包，底稿进度页提供逐份及 ZIP 入口。
- 导入/预览免费。生成复用每份 4,500 积分，包含正文及编制说明，采用现有 `authoring_balance_v2` 逐步扣费、暂停保存、取消部分结算和平台失败退款规则；没有新增费率。
- API 的 XLSX 解析复用有大小、解压和 CRC 边界的 Office ZIP 读取器；下载只读当前用户授权成果并逐份校验哈希。ZIP 流按文件读取并响应背压，客户端关闭时释放活动输入流。
