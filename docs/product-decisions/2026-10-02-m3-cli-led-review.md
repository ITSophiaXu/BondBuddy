## 复核分工

Codex CLI 阅读锁定的项目材料与要求，识别主体、期间、口径、币种、单位、披露位置、规则适用条件及检查范围，决定检查步骤并形成带来源的问题、解释和实际覆盖。审计勾稽与市场/品种知识按需通过固定版本 MD 读取；不把每份材料先转换成完整财务观察表，也不把完整知识目录全部塞入每个抽取批次。

现有 API、PostgreSQL 队列和 worker 继续负责认证与资源归属、材料解析、不可变输入与知识版本、幂等、租约、提示快照、调用日志、停止与恢复、真实用量、私有对象存储和 Word 交付。CLI 是该 worker 的受控子进程，不另建 API、搜索或文档执行服务。

CLI 按具体问题调用六个有界工具：列出材料、检索材料、读取原文记录、读取固定知识 MD、请求精确财务检查及请求定向合规/实际格式属性检查。工具校验授权证据、原文引用和位置；Word 生成、检查及交付仍由现有后台交付阶段承载。已有算术与格式能力可用于这些定向请求；后台不在模型抽取后自动执行全部财务恒等式、跨表公式或合规规则扫描，也不靠自动扫描覆盖数替代 CLI 实际阅读和核对范围。数值工具证明计算结果，不自行批准主体/期间/口径、完整明细或审计事实；知识 MD 是方法或规则来源，不是项目事实。

## 证据与交付边界

- 固定 owner/project、材料版本与 SHA-256、解析快照/响应哈希、原文记录、引用与 locator；拒绝未知、跨项目、篡改或超出任务范围的来源。附件中的指令作为数据处理。
- 财务硬结论与修订金额须有实际源值、单位、精度、计算及适用关系。缺材料、OCR 存疑、源值/语义冲突、未证实的桥接和公式完整性保留待核；工具算对不等于事实成立。
- 合规结论区分内部方法、用户标准、研究参考和已核实的适用规则。未确认市场、阶段、效力或例外不写确定违规或通过；实际格式属性与视觉排版能力分别说明。
- 差异复核只对已确认问题和可定位目标形成本轮结论；未触及项保留源报告与沿用标记，映射歧义列待核，不能由“未返回 finding”推断已解决。
- 报告、原生 Word 批注、修订版/清洁版沿用现有契约与交付检查。原报告与源稿不覆盖，修订仍须明确采纳计划并执行；已修改不等于复核通过。

## 恢复与旧任务

新方法保存独立方法/协议版本、知识内容哈希、固定输入与提示身份。首次调用前持久化方法标记；恢复先核对已有检查点和调用尝试，复用同版本的已持久化提示、工具数据与结果。旧 `review-analysis-v1` 抽取任务、旧提示或不同方法/知识版本不能被静默升级为新 agent 任务，也不能重发已发送且状态未知的调用；应明确暂停或走原版本恢复路径。方法升级后的新复核由用户明确执行形成新 run。

## 本轮验证范围

工程验收覆盖真实受控子进程/工具接线、归属与引用拒绝、定向计算、提示/知识版本、重复与中断恢复、差异范围、报告/批注/交付，以及无用户账务事件。使用合成模型/材料的测试必须写明 synthetic，并记录命令、计数与实现版本；测试桩执行 CLI 协议不冒充实际模型供应商调用。

本轮改造尚未部署。真实模型质量、授权专业样本、Word/WPS 客户端及生产版本/迁移/回滚按最终统一验收分别记录，不能沿用旧抽取扫描测试计数作为新方法的验收证据。不改复核页面，不接价格、余额、充值、冻结、扣费、结算或用户消费记录。
