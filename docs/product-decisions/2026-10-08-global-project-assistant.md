# 全站 BondBuddy 项目助手

用户于 2026-10-08 确认悬浮项目助手和对话确认卡设计，并明确要求实现到产品。当前决定覆盖旧 M1 无对话、材料生成页取消对话以及 M4/M5 拆分中与本次范围冲突的部分。既有更新、复核、材料生成页面保持独立，助手是全站按需展开的入口，不占用每个页面的固定侧栏。

## 用户体验

- 登录后右下角显示 BondBuddy；支持收起、宽屏、新对话和最近对话。退出账号清除前端状态。消息、未发送文字、任务草稿、材料和确认卡保存在服务端。
- 问答直接在会话回答，不要求先创建业务项目。关联项目与正在讨论／修改的成果版本明确展示。切换页面不切换会话上下文；显式切换项目开始新对话，原对话可恢复。
- 用户可要求更新募集书、复核或生成已有开放文种。模型只提出建议；卡片核对项目、市场、品种、季度报告期、材料和额外要求。用户确认卡片后调用原执行入口，不从模型回复自动执行或冻结积分。
- 已上传历史／参考募集书的原稿信息继续必填；已有项目材料可以复用，无需用户重新上传。未完成上传有实际状态和重试，不能显示为已经保存。
- 从已完成结果继续修改，明确固定选中的清洁版作为底稿；保留局部范围和禁止项，生成新的修订版与清洁版，旧结果不覆盖。讨论措辞可以仅回复文字，不创建文件任务。
- 卡片展示真实任务状态、可下载成果和继续修改入口。收起助手、导航和刷新不取消已提交任务；运行中新增要求只用于后继草稿。

## 费用与边界

不新增价格。问答继承已发布 M4 按量封顶规则，产品帮助和任务准备按已有免费规则。文书生成沿用 4,500 固定价；募集书续改依据所选已交付版本的原市场／品种／期间，使用已有八档分类，零新增年度的纯内容修改按一期。完整复核沿用其固定价。报价发生变化重新确认，余额不足保留输入并提示充值，不自动开始。

助手确认卡是新的明确执行入口，原材料表单的一键执行行为保持不变。源文件、已生成成果、工具输出不能授予执行权限；模型不能写价格、资源归属、底稿 ID 或执行请求键。未检索不声称已检索，未知用量不写零；最终专业内容、真实支付和原账号验收另行记录。

## 实现与原型

复用 M4 持久话题／CLI／用量，新增 assistant surface、新技能快照和只读任务确认记录；复用原统一编制、M3 复核和 M4 文书的报价、队列、幂等、私有成果接口。公共字段由 packages/contracts 唯一定义。0100 为追加迁移，不修改历史任务或旧技能正文。

批准的原型存档：`product-prototype/public/global-project-assistant.html` 与 `assistant-conversations.html`，来自本会话已确认的可交互原型。演示中的定时进度、价格和结果不进入生产实现。实际 API、按钮状态、桌面／手机截图与测试证据在发布验收记录登记。

## 2026-10-09 界面与图标细化

按用户对已上线助手截图的反馈，细化悬浮面板及图标。新的视觉对照为 `product-prototype/public/project-assistant-refined.html`；原 `assistant-conversations.html` 继续描述任务确认、问答及成果续改的业务流程。

- 用对话气泡／文稿与星标组成助手标识；新对话、历史、宽屏、收起、附件和发送统一使用 SVG 线性图标，保留中文可访问名称及悬停提示。
- 面板头部保持紧凑，关联项目收为一行入口，点击时才展示选择器；选择其他项目仍开始新会话，已有对话仍可恢复。材料清单折叠，已选成果版本继续明确展示。
- 欢迎区展示三个带简短说明的任务入口；打开任务表单后不继续占用空间。附件、自动增高输入框和发送按钮归入一个输入区，空内容不能发送。
- 助手展开时隐藏重复的悬浮入口；桌面、宽屏和手机保留独立面板，任务进度适应较窄宽度。

本次只调整前端展示及选择器开合，不改变知识、CLI、任务确认、定价、权限或成果版本语义。原型与实现按同尺寸对照，合成界面证据见 `apps/web/test-evidence/assistant-refined/README.md`。该原型为本次用户明确要求的 UI 细化，未新增产品流程；最终原账号视觉验收仍由用户上线试用确认。
