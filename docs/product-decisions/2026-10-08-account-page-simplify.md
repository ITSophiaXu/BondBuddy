# 我的账号页面精简（2026-10-08）

用户基于两张当前页面截图要求：基本信息只需要账户名、绑定手机号；图 2 中五个低频区块不必常驻；同时询问“任务占用”的含义及用户名能否修改。本决定覆盖 2026-10-06 统一账号决定中低频折叠项常驻账号主页面的布局。

- 基本信息只展示账户名和脱敏绑定手机号，移除注册时间、密码修改时间、协议版本、找回说明和客服信息行，以及页头重复的用户名标签。
- 登录会话、修改密码、账号找回、数据说明、注销账号通过基本信息卡片内的单一“账号设置”按钮打开弹窗。既有功能和确认流程保留，支持关闭按钮和 Escape，旧数据说明链接直接打开弹窗内相应内容。
- “任务占用”对应账本 frozen，即已从可用积分中预留、尚未结算的额度。改为“进行中任务预留”，附结算说明；为 0 时不展示。成功交付后扣除，失败或有效取消后释放，收费规则不变。
- 手机端先展示基本信息，再展示积分与充值。
- 用户名目前同时作为登录名，现有 API 没有修改接口。本次未增加改名能力，不将显示名称编辑冒充登录账号修改。

原型：product-prototype/public/account-credits.html。实现：apps/web/src/account.ts、account.css、billing-page.ts、main.ts。关联 #361、#36。无 API、公共契约、数据库或 worker 改动。
