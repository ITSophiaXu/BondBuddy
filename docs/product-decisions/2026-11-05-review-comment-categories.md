# 复核修订稿：先分类，再说明问题

2026-11-05 用户要求复核直接在待复核募集书的副本上修改，修订版能看见正文删除和新增；批注先明确合规、格式、数据一致性或勾稽，再说明具体问题。

## 实现

现有 Word 原生修订机制继续保留：有明确证据且能唯一定位的修改写入正文修订；缺证、无法定位或结构不支持的事项保留原文并批注。上传原件不覆盖。修订版可以接受或拒绝修改，清洁版保留待确认事项。原稿已有修订仍按当前有效文本生成本轮基线；PDF 仍先转换为 Word，不能据此承诺保留 PDF 原版式。

修复批注输出遗漏复核类别的问题。新批注使用原生 Word 段落，顺序为：问题类别、问题编号与标题、具体说明、依据、处理结果，以及适用的缺少材料或定位限制。统一四类名称为“合规”“格式”“数据一致性”“勾稽”。已有长名称按明确对应关系归一化，保存既有成果的处理选择再导出时也适用。缺失类别显示“类别待确认”，不凭问题正文猜测类别；其他明确类别保留。

模型指令明确各类别的含义，要求先分类再说明，并区分问题类别与“待确认”处理状态。网页沿用既有按类别筛选及问题卡片，没有新增页面或交互。不会静默改写已保存的历史成果，也不重跑历史 AI 任务。
