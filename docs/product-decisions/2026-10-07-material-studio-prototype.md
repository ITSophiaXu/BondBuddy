# 材料生成回归原型（2026-10-07）

用户要求以 `product-prototype/public/material-studio.js` 的原材料生成表单为设计依据，增加交易所选择；移除材料页对话，只保留补充编制要求的输入框。用户随后明确本次只实现材料生成，不实现项目问答页面。本决定覆盖 10/06 合并工作区、右侧常驻助手、通过助手采纳要求的界面条款；后端知识、Codex CLI、任务持久化、权限、计费及成果能力继续沿用。

- 材料类型卡片 → 交易所 → 上传最新版募集书或选择已有项目的准确材料版本 → 对应模板及支持资料 → 选填“材料生成要求与说明” → 生成按钮。
- 当前开放立项报告、主承销商核查意见、法律意见书、普通私募募集说明书摘要。推荐函保留原型位置并注明未开放，不扩展公募/协会或组合执行。
- 立项保留本账号券商模板选择及规则上传；每种材料独立保存交易所、来源、模板和要求。切换类型不丢草稿。
- 页面无需先创建话题或与助手讨论。首次修改/上传时沿原幂等接口保存材料任务；直接要求使用公共契约可选字段 `supplemental_requirements`（最多 12000 字），不伪造助手消息，不执行模型调用、不收费。
- 生成时固定源材料、交易所知识全文/版本/hash和补充要求。worker 的 `input.json` 同时包含旧版已采纳要求和本次直接要求。旧草稿与运行快照兼容，无数据库迁移。
- 上传募集书已包含的发行人由文件任务读取，不要求先通过助手复述；没有独立结构化名称时输入如实留空，不编造发行人。显式目标字段与已关联项目上下文仍保留。
- 页面展示同一任务的真实进度、已有成果、继续全文改稿、可编辑 Word 和编制说明下载。运行期间不展示对话框；准备下一任务不修改原执行快照。
- 问答页面不属于本次交付，既有后端问答接口与历史数据保留。本次不开放新的问答入口。
