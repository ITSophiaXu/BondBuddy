# 项目基本信息与自动项目名称

用户根据更新募集说明书创建页截图明确要求：将“必填”移到“项目基本信息”标题旁；不再让用户手填项目名称，由发行人名称自动生成。

- 新建更新项目先填发行人全称，旁边以只读文字展示自动生成的项目名称。
- 名称按发行人、已选市场、适用发行方式及“募集书更新”组成；未选市场或方式时跳过，名称不虚构期次。长名称按现有 120 字符限制安全截取，完整发行人单独保存。
- 创建时仅要求发行人非空；其他尚未确定的目标信息继续允许暂存，不把标题标记解释为新增全部字段必填。
- 已保存项目保留原名称与按需修改能力，修改发行人或其他资料不自动重命名旧项目。
- 原型为 project-workspace.js / .css；实现为 update-form.ts / .css、form-model.ts 与 main.ts 的新建入口。原 API、数据库、任务与收费不变。
