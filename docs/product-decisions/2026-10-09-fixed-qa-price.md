# 项目助手普通问答固定积分（2026-10-09）

用户明确批准「按 60 积分／问题上线」。本决定覆盖全站助手及 M4 旧文档中普通 QA 按量计费的当前新任务口径，不重新定价已提交的历史任务。

- 每次明确提交的独立专业问题固定 60 积分；普通概念解释、材料解读、分析和计算使用同一价格。继续提出新的专业问题时重新报价，不因同一话题而免费。
- 产品帮助、问候、能力说明及必要任务澄清／要求整理免费。提出任务建议不直接执行文档任务；文档任务仍使用原确认卡和原价格。
- 发送前展示准确积分与成功／失败条款，沿用再次发送确认。确认后预留 60；实际答案持久交付、任务成功后扣费，失败或取消全额释放。余额不足保留输入，提示充值。
- 价格由可信运营函数发布不可变版本，保存操作者、批准依据与生效时间。以后可发布新价格；执行前若版本变化须重新确认，已运行任务按原锁定价格结算。重试同一次请求不重复收费。
- 固定价格不依赖模型成本率配置。真实模型用量继续记录，未知用量如实保持未知，不伪造成本；固定收费由已交付答案驱动。

## 实现与上线

追加迁移 `0101_m4_fixed_qa_prices.sql` 建立不可变价格表并扩展既有固定价结算守卫。迁移不种生产价格、不修改历史账务。发布 API/worker 后，通过 `publishM4QaPrice(pool, { id, points: 60, effective_at, actor, reason })` 显式登记本次批准；版本 ID 及时间登记在部署证据。后续调整须新版本，不 UPDATE/DELETE。

产品对照仍为 `product-prototype/public/project-assistant-refined.html`；新增问答费用确认状态，未改变页面布局。验收包括无模型成本率时固定报价、余额不足、成功精确一次扣费、失败／取消释放、已运行价格固定及改价后重新确认。合成工程测试与真实模型上线验证分别记录，关联 #612。
