# 项目问答先确认募集说明书，再生成回答成果

依据：用户 2026-10-28 对项目问答截图的反馈。本决定覆盖 2026-10-27 设计中把问题清单转换结果作为下载成果、仅突出清单上传的部分。

- 页面按“确认项目资料 → 确认问题 → 回答与补件”组织。项目资料首先展示项目已采用的募集说明书和版本；复用募集书保存、采用和恢复能力，在问答页内上传或选择。
- 允许免费识别问题、保存未齐资料的准备内容；开始新一轮回答必须选入项目当前采用的募集说明书。API 在创建任务和冻结积分之前检查，问题清单不能同时作为募集书。输入固定准确版本，提交后不跟随当前稿变化；历史请求按原幂等记录恢复。
- 识别结果在页面预览候选问题，不展示转换 Word 下载。零题时说明未识别成功并引导手选原文；Word 自动编号及正文中的补充要求可作为候选，提取失败的占位提示不作为问题。
- 逐题回答使用固定募集书和已选材料。较短材料提供完整文字；较长材料检索相关段落及相邻上下文，同时给出募集书概况、材料清单和提取限制。无法读取必需募集书时停止本轮，沿用失败退款规则。
- 证据不足不能输出无依据的肯定结论。按问题列出具体材料名称、期间或明细字段、核对用途；不可读文件需说明可读版本要求。公开案例只用于回答思路。
- 只有回答后的成果提供下载。成果含原问题、回答、依据及待补材料，页面仍可审阅和准备下一轮；每题 60 积分和明确费用确认沿用，缺证但完成补件建议的题目按原定价计费。
- 工作区和弹窗统一中文无衬线字体、字号、按钮及正文层级；桌面并列资料与清单，窄屏依次展示。
