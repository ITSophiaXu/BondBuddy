# 项目问答正文聚焦与验收

用户要求：不驳斥审核问题，如实解释所问，不发散到无关内容。此前真实生成的答案虽通过引文校验，仍出现内部选文措辞、重复缺口清单及额外辩解。生成完成与内容符合要求必须分别记录。

## 已确认的原因

- 旧提示同时要求项目组口吻及“当前可读取或选入内容无法确定具体事项”，存在直接冲突。
- 缺口已在正文标注，Word 又无条件追加 `missing_materials`，造成重复。
- 校验主要验证输出结构及原文引用，不能据此认定每段都切题、推论成立。
- 长材料选文在找到相关章节后继续用剩余额度装入无关章节。它增加干扰，但不能仅据上下文长度断言具体句子的成因。
- 旧模板答案的跨任务复用可能绕过新的表达要求。

## 本次实现

1. 提示先拆小问，起草后将段落、表格和计算逐一对应到小问，无对应关系的删除；写相关事实、原因及证据支持的所问结论。表格先选必要行列，再保证该范围完整，不将无关的全空列一并复制。
2. 选文限制只用于内部证据判断。正文在受影响的判断处保留具体业务缺口，不声称未选入的信息在原稿中不存在。文件复核问题回答实际进展，缺记录则标该进展待确认。
3. `missing_materials` 原样记录局部标记内容。Word 只追加尚未出现在明确局部标记中的条目；仅忽略空白和句末分号/句号，不做模糊语义去重。无标记的旧答案保留清单，结构化缺口和引文不被删除。
4. 新保存提示增加受信首部 `project-qa-reply-focus-v1`。对可明确识别的内部过程措辞、特定假想反驳、重复缺口标题和缺口位置不一致，使用现有有界校验重试，反馈固定原因，不把模型或材料文本当成指令。不自动改写、删句或放松引文要求；没有增加独立模型调用阶段或重试次数。
5. 超长材料仍优先完整相关表格、单位、邻接说明及跨章节匹配，不再用无关章节填满剩余额度。无词项匹配时只保留有界背景，覆盖信息继续记录。短材料仍全量传入；词项匹配不等于语义相关性。
6. 模板升级至 `project-qa-direct-answer-v8`，跨任务仅复用 v8 已完成答案。同任务已保存结果及旧提示按原协议续跑，不自动重跑、重收费或覆盖历史成果。

## 验收边界

程序检查是有限的机械检查，不是语义审核模型。逐段对应检查目前由生成模型自检及交付内容复核执行，尚无独立模型复核。词语规则不能证明所有段落相关，也不能证明结论的关键前提充分，不能将检查通过标为用户验收。

内容验收须给每个小问记录：所问判断、对应段落/表格、保留理由、关键事实及结论依据、局部缺口。没有对应小问的内容去掉；问题明确要求的风险、不利事实、必要限定、真实差异及实际未完成核查不能因“精简”而删去。与实际材料相冲突的问题前提应简短说明真实口径。

真实模型复验至少覆盖收入原因及持续性、仅问回款安排、明确问回款风险、局部资料不足、错误问题口径、申报合规前提缺失、实际文件复核进展。每项分别记录生成完成、引文校验、内容复核和用户验收。禁止把合成答案测试或旧结果检查当作新版真实生成。

本次不变更公共契约、数据库、计费或网页流程，无新增依赖。开发完成后交给指定集成及发布 chat；不在本开发 chat 部署，也不自动再次向外部模型发送客户原件。
