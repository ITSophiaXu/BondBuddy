# 项目问答上传募集说明书后自动使用

用户反馈：在项目问答中上传募集说明书已经表达了使用该文件的意图，不应再要求点击“使用此版继续”。

- 项目问答上传成功后自动选为项目当前稿，并加入本轮可编辑的回答材料。更换上传时替换本轮已选的原当前稿，其他补充材料、问题和要求保留。
- 完成后自动返回项目问答；移除上传后重复的版本确认。历史版本仍可主动选择，选定后同样加入本轮回答材料。
- 上传不启动问题识别、回答或扣费；已有任务的固定输入保持原状。若材料已达 50 份且无法替换原稿，明确提示移除一份补充材料，不能静默删减材料。
- 上传失败保持原选择；采用回执不明确时保留同一请求重试，版本竞争冲突显示真实状态，不自动覆盖其他页面的变更。
- 仅调整项目问答入口，不扩大其他业务页面的版本选择语义。API、worker、契约、数据库迁移和依赖不变。

原型：`product-prototype/public/qa-prospectus.html`。实现：`apps/web/src/prospectus-panel.ts`、`project-qa-workspace.ts`。本次用户截图和反馈为交互变更依据。自动化自测不代表用户验收或生产发布。
