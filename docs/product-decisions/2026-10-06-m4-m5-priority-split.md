# M4 高优先级先交付，扩展能力移 M5

状态：用户已确认首批正式材料为“立项报告＋普通私募募集说明书摘要”，并于 2026-10-06 要求执行 M4；当前正在独立实施分支开发和验收，尚未发布 issues／合并／部署。实施证据见[实施验收记录](../acceptance/m4-implementation-2026-10-06.md)。本决定覆盖上一版 M4 全功能首发和第07～13、15、17章的冲突发布范围，专业内容继续保留并按下面阶段实施。

## M4：可用的单文书闭环

M4优先交付一个可连续使用的闭环：在合并入口问答→准备一种材料→澄清缺项及保存要求→明确执行→查看真实过程和Word／编制说明→整份继续改稿→刷新恢复。

| 能力 | M4 必须交付 | M5 扩展 |
|---|---|---|
| 入口及工作区 | 单一材料生成与问答入口、常驻Agent、按文种展开、QA无左表单、讨论按钮、成果本体tabs；复核复用正在制作／过程联动 | 不另做布局 redesign |
| 文种 | 交易所普通私募立项报告及募集说明书摘要，单承销商 | 核查意见、法律意见书、推荐函；小公募／大公募摘要及适用市场扩展 |
| 模板 | 本次上传或选择本人明确保存版本；首次立项券商模板／参考报告；准确版次、可读／适用检查、hash防重复、私有隔离 | 自动匹配复用、默认版、删除／退役及完整库管理；扩展文种／市场模板 |
| QA | 基础概念、授权材料解读、常用确定性财务计算、资料清单、产品帮助、聊天文本轻量起草、免费文本导出 | 实时公开查询、法规效力／适用性检索、深度研究、多期系统分析、保存可编辑分析／轻量草稿artifact |
| 生成和续改 | 一次一个文种，真实可编辑DOCX＋独立说明；准确底稿的整份新版本 | 多文种组合；精确章节／段落局部修改 |
| 引用 | 准确版本与位置的阅读／讨论引用，来源冲突澄清；不扩大执行范围 | 固定version＋anchor＋原文后执行局部修改及真实差异验证 |
| 业务之间 | 解释跨业务需求、保留意图与已授权来源，提供“前往更新／复核工作区”操作，在目标工作区重新核对输入／报价并明确执行 | 在原会话自动准备并执行跨业务任务、固定报告更新与新报告期更新的完整承接 |
| 可靠性 | 共享话题资料与任务采用清单分开、明确来源优先、字段／要求回填、固定快照、下一草稿、准确底稿、互斥／幂等无自动排队、真实事件、完整历史／未发送草稿恢复 | 扩展功能复用同一可靠性契约，不能另建绕过权限／账务的路径 |

M4的普通私募范围包含上交所／深交所适用模板，不把公募或DFI稿换个标题当作私募材料。未开放能力有准确说明，保留相关资料和意图，无收费执行；不能静默生成另一文种／范围，也不把用户请求自动拆成多个任务。基础QA只采用已核验可用知识或准确材料，不声称已实时检索／核验现行法规。

## 交互与后端保持

上一版[工作区决定](2026-10-06-m4-agent-workspace.md)的布局和可靠性继续适用：Agent always on、无收起／全屏；工作区无补充意见textarea；系统默认规则与用户已采纳要求分开；讨论不发不执行。任务开始后工作区正在制作、右侧真实过程；完成原位成果，旧版阅读不抢切。保存／澄清不自动执行，制作中新内容只进下一草稿。

M4同业务首发文种的明确自然语言执行仍可在准确输入、已展示有效价格、授权和预留齐备时同次启动，无重复形式确认。跨业务自动启动、多文种与局部执行本阶段未开放；可讨论／保存并明确引导已开放入口。仅引用某段作全篇写作参考不构成局部改稿执行，必须清楚说明整份新版本范围，不能偷换“只改这段”的意图。

M4和M5后端继续由服务端worker调用Codex CLI。保留公共contracts、受控Skill、权限、真实调用／usage、不可变输入、租约与检查点；不迁移API／SDK运行时。真实Word、权限、历史恢复、幂等／互斥及实际账务是M4门槛，不能通过移到M5降低要求。实时web search与文件模式兼容只在M5扩展查询／编制中验证，不作为M4无外部查询闭环的前置。

费用不新定价；M4使用原G01／G05及实际QA类别与已确认价格，不以未开放文种／研究档收费。保存、必要澄清、帮助、已有答案导出／成果下载、平台纠错与内部恢复继续免费。组合一次预留、全部关键成果交付后一次最终结算的原规则在M5保留。
