# 募集说明书原稿格式保留

依据：2026-10-29 用户反馈生成稿未按上传募集说明书格式，确认修改方案后要求开始执行。本文记录首期实现，不表示已经部署或通过真实供应商、专业内容及 Word/WPS 客户端验收。

## 产品行为

- 上传原稿的现有材料区提供“沿用此稿格式”。选择保存精确材料 ID、版本、SHA-256；省略 PATCH 字段保留已存选择，显式 null 恢复自动推荐。
- 自动推荐优先可编辑 DOCX，再考虑同企业关系，同档按输入材料顺序。推荐与实际输入锁采用同一契约函数，避免材料 ID 决定格式。
- 首次编制在选定原稿上编辑。继续修改固定所选清洁版为修订基线并沿用其格式；界面明示“沿用所选成果格式”。其他新上传参考资料不替换该修订基线。
- 模板版式和适用的组织方式来自选定原稿；事实来自本项目材料；目标品种知识提供必要披露要求。既有 PPN/深交所写作规定继续执行，必要结构调整应记录对应依据，局部续改遵守范围。
- PDF 原稿如实标示重建，无原稿沿用新编路径。本期不宣称任意 PDF 都能还原为原 Word 版式。

## 输入与执行

唯一契约 `UpdateDetails.format_template` 与 `UnifiedAuthoringInput.format_policy` 定义在 packages/contracts。API 校验归属、当前版本/hash和本次锁定材料集合。策略随不可变输入固定，旧输入缺少策略时继续旧执行路径，不重写已提交任务。

新 DOCX 策略 `source-format-v1` 采用同次 CLI 内分章工具编辑。固定 Python 工具提供 inspect、replace_text、replace_cell_text、insert_paragraph、insert_row、add_comment 和 no_changes。原节点锚点在插入后保持稳定，每项操作核对完整预期原文，新增内容继承指定来源样式。

模型阶段先把锁定原稿、input.json、operations.json、模板清单及实际说明保存到私有存储，再记录模型完成与用量。正式双 Word 在可重试的 word_delivery 阶段由受信任程序重放生成。该阶段不执行模型脚本；任意模型生成的 DOCX 工作文件不能绕过定稿。定稿中断从已保存操作恢复，不重新调用模型。

本轮修订日期随输入文件固定，ZIP封包确定，重复定稿产生相同字节。原稿与历史修订保留；清洁版接受修订。无实际修改必须给出具体理由，不伪造本轮修订。

## 首期能力边界

覆盖普通段落、表格单元格、多段落单元格、同级段落、普通表行及正文/表格批注。复杂合并表格增行、增列、域/嵌入对象编辑、整章迁移等不能静默重建；工具返回具体不支持原因，任务说明保留未完成范围。首期验收不等于上述增强能力已经完成。

模板清单包含标题候选、段落/字符属性、样式继承链、表格网格/合并关系、分节和包资源；属性按引用去重，按节点分页读取。XML结构保留不替代页面视觉检查或业务正确性审核。

## 交付后格式诊断

双 Word 可下载后，独立 worker 循环读取持久化的 `word_delivery_pair.format_diagnostic`，核对账号/项目/run前缀及文件hash，执行源格式与操作重放对比。按任务持有 PostgreSQL advisory lock，连接断开后其他进程可继续；不占用生成任务槽，不改变 run 状态或再次调用模型。

诊断状态和私有报告独立于文件可用性与业务审核。报告检查段落/字符属性、样式、编号、网格和资源的非预期变化，以及新增区域是否符合指定操作；自然分页变化不作像素相同要求。基础设施错误最多重试三次，仍未完成记录 not_run，不冒充通过。

本决定对 2026-10-02 “生成后不运行额外格式检查”新增非阻断诊断例外；双 Word 下载继续采用 generated_pair_v1。未检查的内容、专业判断、页面视觉及客户端兼容性仍如实标记未执行。

项目删除清理本次私有原稿副本、输入、操作日志和格式报告。报告上传前持久化 pending_report；诊断写回前重新核对项目，删除竞态中的报告不再登记。上传或删除中断保留待清理引用，即使项目已有清理回执，也能在后续轮次只重试报告清理，不再编制或诊断已删除项目。

## 验收与后续

首期要求：多稿/续改精确版本，文字和普通表格保留格式，真实修订与清洁稿一致，错误锚点不覆盖正文，原稿不可变，任意模型DOCX无法替代正式成果，定稿可恢复，诊断并发防重且不影响下载，账号隔离与项目删除成立。

工程验证使用明确标记的合成输入和仓库获授权样本。真实样本中的临时文字修改仅用于文档引擎回归，不是发行人事实更新或专业验收。复杂表格、章节迁移及 Word/WPS 页面验收继续按具体能力补齐。
