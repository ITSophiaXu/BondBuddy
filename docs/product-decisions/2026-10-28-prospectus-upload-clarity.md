# 历史募集书入口及误上传纠正（2026-10-28）

用户反馈：更新入口的“项目募集说明书”与历史稿用途混淆；误上传后版本历史没有删除入口。

更新工作区把入口明确为“历史／参考募集书（选填）”：历史稿可用于原稿更新或结构参考，不要求提供更新后的成稿。没有参考稿可点击“先提供发行人材料”定位财务材料区。选择稿件的动作明确为“用于本次更新”。文件生成与一致性检查继续使用各自的当前募集书含义。

保存与采用分开。统一更新项目中，仅保存但未选用的历史稿不进入更新输入；服务端和浏览器保持同一规则。旧任务及旧模式项目保持既有输入。

新增未使用上传的删除入口，需确认文件名。服务端在项目锁内复核状态：当前采用稿、已锁定输入引用、关联文件或底稿批次的来源、复核草稿引用不可删除。生成结果保留。误上传通过既有材料删除接口软删除，从材料及版本列表隐藏，保留不可变版本行及递增序号；重复请求幂等。项目草稿版本递增并清除对应原稿信息，原任务快照不变。无数据库迁移、依赖或价格变化。

公共契约在 ProspectusVersion 增加可选 delete_block_reason（current / used / generated / null）。旧服务未提供该字段时不展示可用删除按钮。前后端需一起交付。

原型：product-prototype/public/prospectus-reference.html；实现：apps/web/src/prospectus-panel.ts、main.ts。对应修复明确来自本次用户反馈；原型以本 PR 的提交为准。版本详情沿用已有只读记录，合成原型不展示内部编号。
