# 同企业 DOCX 募集书更新直接编辑试验

状态：第一轮开发及本地验收；默认关闭，尚未部署。本文是 [2026-10-29 原稿格式保留决定](2026-10-29-source-format-preservation.md) 的限定例外。既有 `source-format-v1`、操作重放和已锁定任务均保持原义。

## 准入与不可变输入

API 只对灰度账号或项目，在用户明确选择“沿用此稿格式”、原稿为可编辑 DOCX 且用户声明同一发行人时写入新策略 `direct-docx-v1`。宿主确认品种、交易所及精简规则清单版本；无法确认时沿用原策略。提交时还要求支持该策略的 worker 心跳有效。策略、材料 ID、版本和 SHA-256 写入不可变输入；已提交任务不随开关变化。worker 按能力认领，未知策略不能回退为旧执行路径。

## 生成与交付

宿主交给模型锁定原稿、更新要求、材料和宿主选定的精简规则。模型在原稿上直接批量编辑，只写含真实修订的 `tracked.docx`，并限一轮自查。与原决定不同，正式修订稿来自模型生成的 DOCX，不能由操作日志重放保证。模型结束前，宿主把修订稿存入私有存储并核对哈希；交付重试只读取已保存文件，不重新调用模型。宿主接受全部修订生成清洁版；不要求模型再写第二份 Word。没有操作日志的格式诊断记录为 `not_run`。

## 质量状态与失败工作稿

宿主检查文件可打开、修订可接受及拒绝、原稿来源、页数和确定性财务勾稽。财务检查只在主体、期间、口径和单位可确定时比较；解析不足记为“未核对”，不得显示“勾稽通过”。确定性不一致允许一轮定向修复，之后重新生成清洁版并复查一次。页数超阈值不让模型改正文凑页数。页数或财务仍不一致时任务失败，不交付成功成果；用户可下载明确标注问题的修订工作稿。失败任务不按成功交付结算；模型调用及修复轮分别记录实际用量。成功任务只结算一次。

Excel 公式的缓存值可用于比对材料当前显示的数字，但须同时标记“公式缓存未验证”；因此即使显示值一致，也不能将财务状态记为全部核对通过。隐藏工作表不能充当本期主表。

页数阈值需由配对样本确定，并固定腾讯云镜像中的 LibreOffice 版本。首轮实验记录排队、准备、模型、交付、渲染、财务检查和上传时长；真实 Copilot 本地功能测试不等于线上 DeepSeek 内容质量或旧站速度已验收。
