# 桌面工作区体验收敛（2026-11-05）

用户在本次桌面 UX 检查后要求将七项建议全部实施，明确只调整设计与体验，不改变业务逻辑。此决定覆盖旧原型中与以下布局调整冲突的展示方式，保留导航、字段、任务入口及公共契约。

## 已确认范围

1. 长项目名与右侧操作独立布局，完整名称保留；按钮不被挤断。
2. 复核和问答成果页优先展示所选成果、版本与下载，1366×768 首屏可找到下载。
3. 压缩任务列表工具区和行高，保留所有筛选、同步提示与操作。
4. 桌面统一标题、按钮、间距和边框；修复文件生成“更换”按钮过窄。
5. 当前募集书只突出一个文件条目，消除项目文件页重复标题与文件名；状态异常仍完整显示。
6. 材料与问答准备页沿用现有操作按钮并吸底展示，保留禁用、确认、恢复和费用说明；不复制提交按钮。
7. 查看历史复核成果时，明确区分该成果与项目中的进行中任务，两者的版本及入口保留。

## 展示规则

- 961px 以上桌面工作区使用 28px 页标题、18px 分区标题、14px 正文、12–13px 辅助文字；主控件 40–44px，次级列表控件至少 36px。
- 使用现有深绿品牌、浅色工作区和白色内容面。沿用 SVG 图标，不增加装饰插图或新导航。
- 页头、项目上下文、步骤条和工具栏保持紧凑；表格行以约 80–88px 为通常目标，长名称允许自然增高。
- 保留全文、警告、选题、版本和材料依据，不以隐藏错误或删除必要信息换取紧凑。
- 吸底操作在工作区内布局，为键盘焦点和末尾内容留出滚动空间，助手展开后沿用工作区宽度。
- 调整 DOM 展示顺序时同步阅读和键盘顺序，不使用 CSS 视觉重排制造顺序差异。
