# 项目问答以问题清单和文档交付为中心

用户于 2026-10-27 提供现有页面截图并要求优化项目问答。本决定覆盖原 #722 的页面内嵌 BondBuddy 设计。

- 页面主流程：上传 Word / PDF 问题清单，核对问题与费用，生成包含回答的 Word，下载文档并查看待补材料。
- 移除页面中的 BondBuddy 聊天区及交流入口。全站右侧 BondBuddy 面板沿用原入口、会话和状态。
- 首次打开只展示上传和两种交付说明；选择项目后不再重复展示步骤条和项目卡。尚无历史记录时隐藏历史选择。
- 结果页优先展示文档下载和按原题顺序排列的材料清单。回答带材料缺口、尚未回答的问题均纳入；尚未形成建议时如实说明，不编造建议。题目对应关系不能核实则阻止续答并提示重新读取。
- 保留每题 60 积分的明确确认、保存、暂停/恢复、历史版本、授权下载和原请求恢复。查看清单不提交任务。
- PDF 原件保持不变，使用已有文字提取能力形成 Word 底稿；保留转换和无法提取页面的提示，不宣称保留 PDF 版式或支持扫描 OCR。

原型：`product-prototype/public/qa-document.html`；实现：`apps/web/src/project-qa-workspace.ts` / `.css`。调整依据与确认人是本次用户要求，不从截图内的旧文字推定新要求。未改变数据库或计费契约；PDF 入口需 API、worker、Python、web 同批集成。

开发和自测完成后交付到 develop 的 PR；本 chat 不执行生产发布，不将自测当作用户验收。
