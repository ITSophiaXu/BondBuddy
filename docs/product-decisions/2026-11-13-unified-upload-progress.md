# 上传进度统一（2026-11-13）

用户明确要求：普通用户只需看到“正在上传文件…”和“上传成功”；服务器校验、确认保存和记录读取并入同一个上传进度条。适用全部共享上传组件及募集书/财务材料入口。

- 字节传输映射整体0–90%，传输结束继续显示“正在上传文件…”，等待服务器回执和该入口必要的文件关联完成。
- 未获得真实成功结果时不显示100%或“上传成功”，不通过定时器虚增完成比例；准备阶段未知进度保持活动状态。
- 上传中的技术提示与重复确认按钮不向用户展示。失败、取消、需重新选择原文件等恢复操作保留。
- 成功后的版本采用/问题文件处理等独立业务流程保持原行为；募集书更新入口自动采用本次原稿。
- 不改变服务器校验、文件格式/大小/哈希、回执匹配、授权、幂等或收费；无依赖及数据库迁移。

本要求覆盖旧 #943 中普通上传须明确展示“正在确认保存”阶段的界面文案要求；#943 的上传性能问题继续独立跟踪，本次不声称提升真实网络或服务器处理速度。

关联 Issue #1317。开发交付、统一本地集成验收与生产部署分别登记，测试通过不代表用户已验收。
