# 文件生成入口与上传流程

> 后续用户要求已将募集说明书上传、替换和确认移到文件生成首页，见 [首页募集书确认](2026-10-28-generation-home-source.md)。下文“首屏只选择方式”和进入方式后确认募集书的描述由该决定覆盖。

用户反馈：两个生成入口的视觉层级像默认选中批量底稿，但下方实际是模板生成的准备流程；选中文件后还需要确认上传。用户要求分析完整流程并优化交互。具体实现仍待用户实际验收。

## 问题与调整

| 原流程问题 | 调整后的行为 |
| --- | --- |
| 入口卡片使用不同底色，容易被误认成选项状态 | 首页仅呈现两个同等权重的入口，无默认选中；点击后进入标题明确的对应工作区 |
| 尚未选择方式就展示模板准备页及下一步 | 首屏只选择方式，并简要说明项目募集书能否复用；已有准备和文种快捷入口仍直接打开相应工作区 |
| 选文件、确认上传、展开历史、采用此版、确认采用、再下一步 | 选择或拖入一份有效募集书后自动上传；成功后显示文件名及“使用此版继续”，一次明确操作完成采用并进入原流程 |
| 上传后可能误按旧版本的下一步 | 上传期间锁定继续；新版本待采用时收起旧下一步。可明确继续使用原版本，新文件保留 |
| 批量底稿补充募集书后跳到模板流程 | 募集书准备保留 `mode=workpapers`，继续后回到底稿目录。目录、范围和要求保留 |
| 底稿页的生成记录打开模板任务 | 底稿页的记录入口返回底稿任务区域；模板记录页提供底稿记录入口 |

## 正常路径

- 按模板：选择方式 → 复用项目当前稿，或自动上传并明确采用 → 选择文件与模板 → 核对文件包和费用 → 确认生成 → 查看进度、下载。
- 按目录：选择方式 → 上传 Excel 目录并选择范围 → 如缺募集书，补充后返回原目录 → 检查可生成范围 → 核对清单和费用 → 确认生成 → 查看进度、下载。
- 文件生成页首次上传和换版使用同一交互。上传不启动生成；继续会明确设置项目当前稿，说明中保留旧版本和已提交任务的依据不变。

## 保持的行为

更新募集书、关联文件一致性检查等页面仍使用它们原有的保存和采用流程。文件生成的费用确认、模板和补料的保存范围、账号/项目隔离、源版本固定、未知请求的恢复、旧版下载不变。

上传失败后显示重试；仍沿用原上传请求及已收到的字节。采用结果未知时留在当前页，原请求确认后才继续；版本冲突后需要重新明确选择。刷新恢复已保存的候选文件，不再要求重新上传。
