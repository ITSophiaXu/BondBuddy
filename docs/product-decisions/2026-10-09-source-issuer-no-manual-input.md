# 2026-10-09：上传原稿后不再手填原发行人名称

用户要求「上传历史募集书后不需要写原发行人名称」（#361 当日新增需求）。覆盖 2026-10-03 原稿信息要求中的该字段。

- 材料页不显示原发行人名称输入框；前端、输入锁定、执行及积分报价共用的缺项校验不再要求此字段。
- 仍需填写与目标企业关系、原发行市场、原品种和最新报告期。目标发行人全称照常保留，不使用目标发行人替填源稿发行人。
- 原发行人元数据保留为可空兼容字段。既有值及已提交快照保留，编辑其他原稿字段不抹除既有名字、不伪造自动识别成功。
- 企业关系和报告期用于原有定价分类；此项不调整费率、不改变同企业/母子公司语义。
- 历史稿和参考稿一致；每份材料继续按 ID、版本和 hash 独立绑定。无原稿仍可编制。
