# 每次业务任务的积分与统一账号页面

用户在 2026-10-06 要求：更新、复核等每次明确发起的业务任务展示并消耗积分；maxy 预充 5,000 积分；账号设置与积分充值合并为同页单入口；移除独立“数据保存与删除”页面入口。本决定覆盖旧 M3 本次免费范围，不追补已经提交的试用任务。

## 体验

- 唯一侧栏入口“我的账号”：余额、任务占用积分、充值和账号信息同页。密码、会话、找回、数据说明与注销为低频折叠项。旧充值链接仍打开此页并保留返回项目和订单上下文。
- 上传、保存、下载已有成果和内部重试不另收费。完整复核、差异复核、按问题修订与根据复核结果更新在明确执行前显示固定积分、余额、差额。余额不足只保留输入和充值入口，不创建任务或调用模型。
- 确认后原子预留；成功交付后扣费；失败或有效取消释放。运行与结果页显示本轮积分状态。任务不因充值回调或页面跳转自动开始。
- 移除登录后的独立数据政策页及侧栏入口，已有链接定位账号内折叠说明。注册协议使用的公开说明仍可读取；后端隔离、删除能力不变。

## 契约和上线条件

继续使用账本、价格版本、报价和预留记录。复核新增 full_review、differential_review、review_revision 配置键；后两种修订入口共用 review_revision。原八档编制价格不变。新增 quote_id 到复核／结果更新请求；报价入口为原执行路径后附 /quote。公共响应复用 FixedQuoteResponse。

复核报价的 input_hash 固定执行意图（项目草稿版本、复核草稿、来源、要求、选择及 execution_request_id），input_revision 为项目草稿版本；intent_hash 区分该类报价。启动时再次检查同一意图和生效价格，最终 run 仍保存完整不可变输入 manifest/hash。Word 按原双份交付结算；复核按当前任务可下载的报告结算。迁移只新增 0089。

2026-10-06 已通过真实账本给 maxy 幂等增加 5,000 积分，不伪造支付。当前原更新最低价 17,900 积分；复核固定价格和足以测试的积分／测试价格仍待用户确认。测试文件中的 100/200/300 为 synthetic 数据，不作为生产定价。BB_PAID_AUTHORING_ENABLED 与 BB_PAID_REVIEW_ENABLED 分别控制新任务，正式开启前需发布经用户确认的价格；不把未接通的支付渠道标为可充值。
