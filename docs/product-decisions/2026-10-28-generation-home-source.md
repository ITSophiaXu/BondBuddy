# 文件生成首页确认募集说明书

用户反馈首页已经展示募集说明书，应在这里上传替换或确认使用，不应点击生成方式后再进入一页确认。此要求覆盖此前“首屏只选择方式”的安排。

- 首页先展示募集说明书卡片，可上传新版本、下载原文件、展开版本历史，并直接确认使用当前稿。没有募集书时在同一区域上传。
- 选中文件后自动上传；“使用此版继续”在首页完成采用和确认，再选择生成方式。仅上传不会采用、生成或扣费。
- 确认后，“批量生成底稿”直接打开目录准备，“按模板生成文件”直接打开文件与模板清单，不经过独立确认页。模板方式仍通过既有接口固定来源版本；底稿方式不修改模板草稿。
- 上传中、失败未恢复、待采用、采用结果未知时，两种入口均不可继续。无效替换文件取消后可重新确认原稿；上传成功也可明确继续使用原版本。
- 确认后版本发生变化时，在首页提示重新核对；确认使用历史版本时，其他已保存版本不会再次阻断本次选择。刷新后恢复已上传候选文件，无需再次上传。
- 旧的管理募集说明书入口、文种快捷入口、目录草稿和生成记录保持兼容。已经提交的任务继续使用原输入。

实现为 `apps/web/src/file-workspace.ts`、`prospectus-panel.ts`；原型为 `product-prototype/public/file-generation.html`、`file-generation-preview.js`，共享 `file-generation-ux.css`。同尺寸截图、测试与集成交接见 `apps/web/test-evidence/generation-home-source-20261028/README.md`。界面需求关联 #361，用户本次截图和说明为交互调整依据；没有向其他 chat 或人员发送消息。

无 API、worker、公共契约、数据库迁移、价格或新增依赖变化。开发交付不代表用户验收或生产发布；待指定集成测试 chat 整合并供用户验收，随后由统一发布 chat 按授权上线。
