# 材料生成必填信息提示（2026-10-13）

用户要求删除上传后“材料已保存并加入当前草稿，不会自动开始制作。”，并在必填项未完成时明确说明缺什么、如何补充、补齐后再生成。

- 上传成功由已显示的文件确认，不再重复显示该句。
- 点击生成时，按实际文种列出缺失的交易所、立项券商及模板、募集书或生成材料；每项可定位到相应填写区，字段旁同步显示说明。补齐后清除该项，仍需用户点击生成。
- 沿用既有输入条件：法律意见书／核查意见可仅使用已选补充材料，摘要须有募集书或明确全文改稿底稿；已有全文改稿底稿无需重复上传。不新增发行人名称、补充要求等必填字段。
- 规则与可公开字段反馈由 contracts/m4-input.ts 统一定义，前后端共用。API 通过已有 Error.field_errors 返回已知字段/代码，浏览器只接受白名单代码并使用固定中文说明，不回显任意服务端诊断文字；此类缺项不再显示错误编号或建议联系支持。
- 缺项时不获取报价、不创建执行任务、不扣积分。服务端仍独立校验，前端校验不能替代归属、版本、并发及账务检查。

原型：product-prototype/public/material-input-feedback.html；实现：material-workspace.ts / m4-workspace.css。用户当前截图为此次交互变更的确认依据，登记 #361；原材料表单和全站导航保留。

无新迁移或依赖，worker 执行与账务不变；web、API 和 contracts 一同交付。开发和自测完成后纳入同一本地入口；用户验收及生产发布单独记录。
