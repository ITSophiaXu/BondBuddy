# 按章节试生成与连续生成底稿

## 用户确认的交互

2026-11-13 用户提供待开始、试生成中、待确认、继续生成中、结束五张页面图。新批次先从前 8 个已选章节各试生成 1 份；已选章节不足 8 个时按实际数量。试生成结束后，由用户一次确认继续，剩余文件依照已选章节顺序自动生成，不逐批重复确认。

章节名称、章节数量、文件数量、进度及失败数均从本批真实目录和执行状态计算。截图中的 248 份、9 章及示例完成数不作为固定规则。

- 准备时可选择章节，调整章节上下顺序。章节下全部文件清单默认常显，无折叠开关，并可逐份调整范围；部分选择时章节复选框显示半选。
- 运行后固定本批顺序和输入；页面显示当前阶段、章节、总完成数及失败数。
- 生成一份即可查看及下载；试生成阶段也能查看成果。成果入口不能仅藏在默认收起的明细里。
- 试生成结束后显示实际成功与失败数量；不能将失败或未执行文件描述为全部完成。
- 继续生成、暂停、停止及重试以服务端确认的批次状态为准。关闭页面不取消任务；重新打开同一批次恢复其真实阶段。
- 结束后可重试失败项。重新开始或重新选择章节进入新一轮准备，保留原批次及已完成文件，不自动发起重复生成。
- 沿用已有报价、积分、失败结算和支付恢复规则。新阶段与章节顺序由公共契约统一约束，前端不自行重定义计费。

## 页面接入范围

正常入口由 `FileGenerationPanel` 准备，创建后进入对应底稿批次的结果视图。旧上传／待提交恢复和受影响底稿重编入口仍由 `WorkpaperPanel` 承接；这些入口创建的新批次也采用同一试生成规则。旧批次没有新阶段信息时继续使用其原有行为，不在浏览器中假造阶段或重建任务。

章节选择与排序共用同一前端组件，消费公共契约提供的章节分组和顺序规则。对目录层级、章节稳定标识及试生成抽样的判断不能在前后端重复各自实现。

## 状态展示

| 阶段 | 主要信息与操作 |
| --- | --- |
| 待开始 | 本次已选章节／文件、实际试生成数量、顺序调整、开始试生成 |
| 试生成中 | 已处理试生成数量、实际可用成果、章节进度、按服务端能力提供暂停／停止 |
| 待确认 | 试生成结果清单、成功／失败情况、继续其余文件、重新选择章节 |
| 连续生成中 | 当前章节、总完成／失败数量、逐份成果、暂停／停止 |
| 暂停或已停止 | 已保存进度、未执行范围、实际可用成果；区分继续原任务与准备新一轮 |
| 结束 | 成功数、失败数、未执行数、按失败项重试、重新开始、成果查看／下载 |

下载期间仍应更新任务进度和新交付文件；下载互斥不应阻止暂停或停止任务。文本预览复用已有受权限保护的接口，转义正文，保留 Word 原排版的下载入口。

顶卡在有成果时提供“查看已完成的 X 份”入口，直接定位到常显成果区。成果列表按可用成果、失败、其余文件排列；各章节进度仍保持本批固定生成顺序。汇总分别列示底稿、说明、失败数量；说明项根据实际决策区分业务不适用、资料不足及需外部原始证据。

暂停、停止后如仍有文件运行，页面持续刷新并保留下载。文件收尾或等待人工处理时不提供可点击的失败重试；等待处理条件恢复或补充信息的文件保留“查看任务”入口。新结果页不使用遮盖章节列表的吸底准备按钮。

## 验证清单

1. 0、1、少于 8、超过 8 个章节，空章节、未选章节及部分选择；数量动态且试生成不重复抽取。
2. 上移／下移边界、键盘操作和焦点保留；保存、刷新和重新进入后顺序一致。
3. 统一准备入口、旧恢复入口和受影响底稿重编入口的新任务使用同一试生成规则。
4. 试生成逐份成功即显示预览与下载；全部试生成结束前不能继续其余文件。
5. 有试生成失败时如实展示；确认继续只发一次动作，不产生新批次或重复文件。
6. 刷新、重登、重复点击、旧版本响应与支付返回保留同批次、同输入及幂等请求。
7. 按章节顺序连续生成；单份失败不阻塞后续章节；暂停／停止不抹掉已生成成果。
8. 重试仅命中允许重试的失败文件，不覆盖成功成果，也不把停止后未运行文件混为失败。
9. 文本预览失败仍可尝试下载；下载挂起期间能显示新交付文件和操作状态。
10. 1440、768、390、320px 下章节名、进度、按钮和成果行无溢出、遮挡或不可达操作。

本文件记录用户交互要求和验证范围，不证明后端链路、真实模型、用户验收或生产发布已完成。
