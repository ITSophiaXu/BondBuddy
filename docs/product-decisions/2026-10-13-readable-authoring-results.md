# 募集书完成页与复核过程信息简化

依据：用户 2026-10-13 的七张截图与明确修改要求；覆盖此前在用户页面展示长文件名、任务编号、哈希和固定输入面板的决定。

- 完成页把下载区放在说明之前。清洁版在前、使用主按钮并标注适合阅读；修订版说明保留增删改痕迹用于审核。首次编制没有旧文时如实说明，两版不虚构修订差异。下载后的原规范文件名、授权、版本关联和字节校验继续保留。
- 页面不展示长文件名、“下载不会发起新任务”、通用 Word/WPS 验收状态文案以及来源校验表中的内部 ID、输入版本、SHA-256。实际材料缺口、待人工确认事项和本轮未完成的检查仍应保留在更新说明中。
- 已保存的编制说明直接转换为分段、小标题、列表及表格；常用交付术语改为用户可读的文件名称和表达。不得靠新模型调用或重跑旧任务重写说明，不推断缺失事实或删去业务限制。Markdown 和 HTML 内容仅作数据，沿用安全展示工具，禁止执行原始 HTML 或隐式加载外部图片。
- 项目信息与材料、下载、完成摘要和更新说明的主标题统一为 18px。原型/实现保持相同卡片结构；按钮沿用全站控件样式。
- 进度中的“准备下载 / 已完成”改为“保存文档 / 可下载”：前者表示后台保存阶段，后者表示任务成功后的交付阶段，不调整后端状态机。共用进度组件采用相同命名。
- 从已完成项目进入后，在成果加载完成时定位下载区一次，刷新可恢复同一成果。轮询不能持续改变阅读位置；失败/未完成任务不能展示成功下载。
- 复核过程取消“本轮固定输入 / 本轮材料与要求”面板，保留真实活动和积分。输入快照仍由后台保存，材料与要求在原材料页查看，不改变任务输入、暂停/继续或费用规则。

原型：`product-prototype/public/authoring-results.html`、`review-live-progress.html`；对应前端 Issue #361。新的设计范围由用户本次截图要求确认，不代表用户已验收运行结果。无 API、worker、契约、依赖或迁移变化；代码及本地集成测试交付，不部署生产。
