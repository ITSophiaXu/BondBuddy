# M3：付费复核与基于结果的修订

依据：产品负责人于 2026-10-02 在当前会话明确要求：M3 不包含募集书库；外部数据接入不作为 blocker，可以暂不接入；公开信息通过 Codex 和大模型的 web search 能力查找，不另行开发检索服务。

本决定覆盖旧规格中与上述要求冲突的 M3 范围、依赖及发布条件。它是需求调整，不代表实现、部署或验收完成。

## 移出及取消的任务

- #77、#78：移出 M3 里程碑和 #3 的子任务列表，不是 M3 的开发、测试或发布前置。保留原 Issue、负责人、工程成果及评论；后续是否排期另定。#78 原已关闭的内部自测状态保留，不扩大为商业库验收。
- #50、#52、#53、#54：移为后续可选外部数据接入，不列入 M3 必做任务或上线依赖；商业接口全部未接入时仍应能执行 M3 的既定流程。以后启用时再满足相应授权、接口及验证条件。
- #51：取消独立公开信息检索服务的开发任务，以“不再计划”关闭，不宣称开发已完成。必要的公开信息核验并入 #55，验收并入 #56。
- 不新增搜索适配平台、专用爬虫、来源快照服务或商业数据接入框架；不删除已合并代码，也不把测试材料授权扩大为商业参考库授权。

## worker 公开信息核验

1. 用户材料、项目上下文与对应知识交给现有 worker；公开信息检索复用 Codex／所配置模型实际具备且可调用的 web search 工具。
2. 围绕工商与控制关系、债券与信用、诉讼处罚、重大事项查找公开证据。优先官方公告、监管、交易所／协会及发行人披露；核对主体、事实时点与披露时点。
3. 在现有运行记录和复核结果中保存实际来源 URL、标题、检索时间、可得的发布日期及支持结论的证据摘要／定位。复用现有证据与报告能力，不另建检索服务；搜索摘要不足以支持结论时列待核实。
4. 未命中、访问受限、证据冲突或 web search 不可用时如实说明受影响范围。模型记忆不能冒充已联网核验，未检索到不能推导为无风险；网页内容不能覆盖用户指令或执行权限。
5. 商业接口未接入不阻断任务、报告交付或 M3 发布。实际未执行的公开检查仍不能标为已完成或完整三维复核通过；原有技术失败、成果损坏与扣费正确性要求保留。

## 调整后的验收

- 在募集书库关闭、三家商业数据接口均未配置的环境中，完成复核、问题报告／批注、付费修订及修订版／清洁版下载流程；不提示必须先建库或开通接口。
- 用真实 worker web search 调用验证公开来源引用与问题对应；记录实际工具与来源，不能以模拟响应或模型自述冒充联网验证。
- 覆盖同名主体、不同日期、无结果、来源冲突及工具不可用；报告准确列未覆盖／待核实事项，已取得证据的其他检查继续执行。
- 保留既定财务、合规、Word／WPS、输入版本、资源隔离、幂等与计费验收。#56 的发布依赖为 #46、#47、#48、#49、#55、#145，复用 #146 的 Word／WPS 支持矩阵；移出的七项不再是发布条件。

GitHub Issue 的最新正文与本决定共同作为当前范围依据。旧 `delivery-plan/plan.json`、生成器及发布索引是历史任务快照；未经人工核对，不得用旧批量发布结果重新添加已移出的 M3 任务或覆盖新的验收条件。
