# 项目问答取消手工范围编辑与材料搜索（2026-11-09）

用户根据“核对问题范围”和“查找参考材料”两张页面截图指出，这些额外操作没有必要，使界面复杂。本决定覆盖 2026-10-29 中保留问题范围合并、移除的交互要求。

- 上传清单后由系统自动处理，直接采用返回的问题，用户无需勾选段落、输入结束位置或移除问题。“查看问题内容”是默认收起的只读预览，展开不保存或提交任务。
- 删除“调整问题范围”入口及弹窗；准备区改称“生成回复”。无法整理出问题时明确提示检查或更换文件，不能继续提供已移除的范围编辑入口，也不能把空结果提交为收费回答。
- 删除按文件名搜索框、重复的已选材料列表、匹配数量及常驻操作说明。参考材料只保留一份默认收起的列表；补充材料按钮在外部直接可用。
- 当前材料选择、精确版本和顺序继续保留。必要时可展开列表调整使用材料；失效版本仍明确显示，不用同名文件替换。请求恢复区保留原始材料记录，历史请求与原收费内容不改写。
- 问题解析、逐题回填、收费规则、上传与提交恢复协议不变；历史补料续答沿用原题选择。技术处理不是额外的用户确认步骤。

实现：`apps/web/src/project-qa-workspace.ts`、`qa-reference-materials.ts` 及样式。原型：`product-prototype/public/qa-materials.html`。页面变动以本次用户截图和要求为依据；开发自测不代表用户验收。

无数据库迁移、无新增依赖。代码完成后交付开发 PR，尚未部署，待统一发布。
