# 2026-10-30：取消每日累计使用限额

用户反馈募集说明书更新因“当前账号今日处理额度已用完”被拒绝，并明确要求“不应该有每日限额”。本决定覆盖旧试用运营规范中的每日累计准入限制。

- 取消每账号每日任务数、模型 token 用量、项目创建数和上传总字节数限制，适用于新提交与后台每次模型调用。旧环境中的四项 `BB_TRIAL_*_PER_USER_PER_DAY` 配置不再参与启动配置解析或准入判断。
- 积分余额、预留、结算、暂停续跑保持既有计费规则。并发容量、短时间请求频率、认证归属、幂等、管理员停用、紧急停止与证据持久化检查继续生效。
- 真实和未知模型用量继续完整记录，按日统计仅用于运营核对，不阻止使用。
- 保留旧公开字段和历史事件枚举以兼容已保存记录；管理状态中的四个每日限额固定返回 `0`，表示不限额。保留历史页面的旧错误解析，不新增页面、提示或操作步骤。
- 旧版因每日限额拒绝的相同提交由已有幂等重试机制重新检查；旧版因 token 用量暂停的任务由现有 worker sweep 恢复，仍受积分及其他有效检查约束。不得重做已经完成的模型调用。

无数据库迁移或新增依赖。发布需协调 API 与全部执行 worker，使提交与模型调用采用相同规则；仅更新网页或修改默认环境样例不能完成修复。开发完成不表示已部署或用户已验收。
