# 报告期异常就地提示

用户于 2026-11-05 要求立即加入：“原稿期间晚于目标期、材料含有更新期间时，在同一区域提示核对。”

- 已填写的原稿最新报告期晚于本次目标时，在该原稿日期下方提示核对是否填反。按当前文件 ID、版本和 SHA 匹配原稿声明，不采用已替换版本的信息。
- 财务／审计文件名有明确且唯一的较新报告期时，在该文件旁提示“文件名显示财务期间可能……请结合报表正文核对”。财务文件名仅提供线索，不能当作已经读取正文或确认期间的证据。
- 编辑项目信息时，目标报告期下方列出同样的异常和对应文件名。修改原稿或目标期间后即时刷新，不移动输入焦点。
- 保持轻量：不自动改日期、不弹窗、不新增必填、确认或执行门槛，不引入 OCR、模型识别或新的网络请求。无提示也不表示全部报表期间已经核实。
- 对无明确期间、仅有文件下载日期、裸年份或多个不同期间的文件名，不猜测最新期。初版支持明确中文年度、半年度、中期、季度、1—3／6／9／12 月及季度末写法。
- 主材料页和侧边 BondBuddy 的募集书更新表单采用同样提示。手机原稿区的保留状态移到原稿下方，避免挤窄日期和提示。
