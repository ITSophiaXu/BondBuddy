# 文件生成选择区与布局规则（2026-11-13）

用户当天指定的新截图是本次文件选择区的交互与布局依据，覆盖旧原型中“添加其他文件类型”及“更多文件类型”的折叠入口。

- 所有可用文种默认展示，不因未选中而隐藏。尽职调查底稿包单独占一整行，保留其目录与模板设置。
- 其余十二种文件按“尽调与内核”（立项报告、主承销商核查意见）、“申报文件”（法律意见书、挂牌／发行申请书、推荐函、募集说明书摘要）、“定期报告”（年度报告、半年度报告）、“专项说明”（发行人基本情况说明、主要财务情况说明、授信情况说明、募集资金使用情况说明）分组。
- 每组展示已选数量／总数和全选／取消全选；顶部清空只取消本批文种选择，保留已填要求、资料及模板设置。切换选择只准备清单，不创建任务或扣费。
- 桌面左侧为组名和操作，右侧两列选项；手机自然转为单列。卡片名称和复选框保持对齐，组间有明确间距及分隔。
- “补充资料与编制要求”与前后卡片保留一致间距。输入框具有内边距，上传和保存操作成组排列、同高，窄屏自然换行。
- 不因示意截图新增强制报价确认，不改变现有自动保存、恢复、模板匹配、实际任务提交、积分或权限边界。

对应原型：`product-prototype/public/file-templates-v2.html`，使用仓库合成目录与模板演示。全部文种保持可选；七种尚无合成模板的选项明确提示需要对应模板，不伪造模板或成果。光大模板仅指尽职调查底稿包，其余文种使用独立文种模板。原型只演示前端交互，不接真实 API、上传、任务、模型或计费。

开发与本地验证完成后仍需纳入固定版本的本地集成验收，按指定发布 chat 统一发布。原型更新不代表线上服务已经更新或用户已经验收。

本次来源文案修正只取消对一般文种来源的统一归属推断，保留具体模板记录的真实名称。它不代表后台模板库已经完成逐文种、发行市场、发行方式及适用阶段的来源核验或替换；后端模板适用性治理需独立核对和验收。
