# 公司债底稿批量生成与变更检查

本功能在 PR #762 的目录判断、逐份持久任务和费用确认之上，接入用户确认的生成规则、公司债格式库、全文内容关联以及项目底稿文件库。默认仅处理“1 尽职调查文件”，当前目录的汇总条目也作为文件保留，数量按每份输入计算。

## 编制与交付

XLSX 导入支持常见标题和“项目”列，解析合并单元格，不执行公式或外链；优先读取尽调页，其他页不默认展开。保留完整目录名称作为业务要求，另生成去说明性括号的文件名。API 支持显式 `scope=all`，页面默认尽调范围。仅显式标记为“目录”的行不是文件。

范围判断固定募集书版本和选择修订号。小文件全文内联；大文件通过隔离文件工作区提供完整原件和 `source-spans.json`，按批读取并要求全文覆盖回执。DOCX 读取正文、表格、脚注、尾注、页眉页脚。图片、扫描PDF及嵌入内容保留部分读取标记，不能把未提取等同于不存在。

每项分类为可生成、业务不适用、资料不足或需要原始证据。可形成实质成果的部分缺料条目可生成，不能伪造证照、签章或履职记录。说明由 API 按固定决定确定性生成，并区分业务不适用与暂无法形成文件。

147份经脱敏的格式副本按事项、编号和七类角色匹配，完整模板固定在 manifest。worker 校验所有非空段落已归入使用或有具体理由的排除清单；使用的来源必须有可验证的原文—成果引用；一旦使用表格，不能遗漏其他有值单元格。检测空模板、内部编号、来源栏目和待填占位文字，保留资金来源等业务内容。计算沿用宿主校验。该校验验证覆盖结构及引用存在性，不声称独立验证模型的语义判断或图片OCR。

结果只交付 `可生成文件/`、`不适用说明/` 两类，文件名保留原编号；版本在系统元数据中显示。来源链接、覆盖回执及编制说明保存在内部，不注册为底稿用户可下载的额外编制说明，ZIP不包含清单和内部说明。旧版已注册的 workpaper 编制说明从项目列表和主题列表隐藏。

## 新版募集书影响检查

新建迁移 `0119_workpaper_changes.sql`。检查输入、结果及哈希不可变；新旧版本分别校验归属及字节hash。POST 与 run、outbox 在同一事务提交，按 request_id 幂等；worker 用持久队列、租约与检查点恢复，无新增模型或底稿费用。

Python 按文字序列对齐，而非按变化后的段落序号硬比较；新增段落不会使后面所有编号错位。表格任一表头、单位、期间或单元格变化扩展到整张表的依赖。通过生成时保存的链接返回具体底稿、目标位置、字段/期间/单位和前后披露。不适用说明使用其已验证的适用性判断引用定位。

- `needs_update`：已定位该底稿关联披露变化，需重新编制或核对。
- `manual`：新增或未关联变化、旧文件缺少映射、部分读取等，需要进一步核对。
- `current`：本次未发现已关联披露变化，不是专业一致性签认。

新版取代当前募集书后，旧检查标记失效。旧底稿和旧检查仍保留；重新编制入口加载任意历史批次和目录，预选受影响/需核对项目，重新走范围判断与既有费用确认。不会静默改写或覆盖文件。

## 项目文件页与接口

项目文件页新增底稿库，独立于只取最近10批的任务面板。支持编号/名称/目录搜索、两分类、检查状态、50条分页、历史批次、Word正文文本预览、单份和批次下载。文本预览转义显示，不执行上传的OOXML或HTML。每次读取/下载均核对项目归属。

公共 DTO 与请求 schema 在 `packages/contracts`，接口位于 `/api/v1/projects/:project_id/workpapers`：

- `GET /library`：search、category、status、history、offset、limit。
- `GET /checks`、`POST /batches/:batch_id/checks`：历史检查和固定新版检查。
- `GET /batches/:batch_id`、`GET /catalogues/:catalogue_id`：精确恢复历史选择。
- `GET /batches/:batch_id/items/:item_id/preview`：转义前纯文本。
- 复用 #762 的目录上传、范围判断、批次控制、说明下载和ZIP。

## 集成与验收边界

依赖 #762、迁移0117/0118及本次0119；API、worker、contracts、web和模板库须一起集成，Dockerfile已纳入中性格式库。没有新第三方依赖，不连接生产。历史生成任务保留原固定输入，不能用新版知识冒充旧任务的编制依据。

真实API/PostgreSQL验证使用合成模型与合成文件；浏览器操作使用mock API。真实用户审核表仅在本地只读解析，识别尽调248项，原件不提交。真实模型的相关性判断、OCR、各类完整生成稿和Word/WPS排版需由统一本地集成版单独验收。扫描材料不能承诺自动获得完整可定位事实。大项目库列表在服务器筛选元数据后分页，尚未验证长期多万文件性能。
