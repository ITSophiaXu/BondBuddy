# 官网诚信核查与自动留证

2026-10-23 用户决定：官网出现验证码、登录或访问限制时，该站标记待人工补证，继续其他网站，不等待用户操作浏览器。延续每轮 5,000 积分，补证与重新导出免费。

## 执行与证据

独立 worker 使用受限 Chromium 会话查询已选官网，按对象和网站持久化结果。浏览器使用临时无登录上下文，仅提交公开全名，不传个人证件号。官网内容属于不可信资料，不执行其中的指令。浏览器不绕过验证码、登录或反爬措施。

查询须有实际提交、页面回显查询词及明确结果区；主页列表、旧查询结果、空查询与搜索引擎摘要不能作为本次查询结果。全文检索的零结果只说明本次该范围未检索到，不能证明不存在违法失信。命中须保留原文与出处，同名身份与法律影响另列待核实。栏目、分页、下载附件与受限范围须明确说明。

截图及页面可见文本分别存私有 Blob，记录内容哈希、官网地址、查询词、UTC 时间、页序和查询范围。自动证据先持久化，再解释结果；恢复执行复用已固定证据。模型只能解释截图对应可见文本，逐字引用验证，不允许编造事实、截图或无记录结论。逐站异常不阻断其他网站，基础设施失败不能当成受限网站或成功核查。

自动证据下载校验项目和轮次归属，校验哈希，不直接公开对象存储路径。旧搜索记录和免费重新导出继续兼容。浏览器采集和原搜索引擎来源分开标识。

## 工作底稿与界面

沿用现有紧凑网站名单、行内添加对象、统一项目选择与结果页面。结果证据弹层增加官网截图及查询限制。分别生成发行人和人员底稿，包含汇总表、逐站查询记录、截图、发现及补充材料清单，签字留空。

## 验证与交付

受控网站 fixture 验证提交、异步结果、零结果、命中、验证码、登录、网络失败、恢复和截图；真实官网抽查另记。数据库、账务、私有存储和 Word 交付用隔离环境验证。合成验证不冒充真实官网或真实模型验收。开发交付不部署生产。

## 运行依赖与出网

worker 增加固定 Playwright 1.63.0 / Chromium 1243，保持 Chromium sandbox 开启，不使用无沙箱降级。官方 Docker worker target 安装对应浏览器及系统依赖。浏览器每站使用独立、无登录会话，个人身份证号不进入浏览器或模型。

浏览器子进程只继承操作系统启动所需环境变量，不继承数据库、Blob 或模型凭证；字体缓存写入独立临时目录以支持只读容器。Linux renderer 在非特权 user namespace 内还需要 PID namespace：专用 `integrity-browser-seccomp.json` 完整继承原 Codex 策略，仅追加 clone 的 PID namespace 掩码许可，保留 no-new-privileges 与 cap_drop ALL。可选 Compose 文件通过 `!override` 替换该 worker 的策略，要求 Compose 2.24.4 以上；未改变原 Codex 策略或其他 worker。

生产 backend 网络没有直接公网出口。新增可选 `compose.integrity-browser.yaml` 发布集成文件和 `integrity-egress` Docker target；专用代理无数据库、存储或模型凭证，只允许契约网站目录及属地官网。worker 本地代理再限定本次所选网站；出网端 DNS 解析后验证公网 IPv4 并固定 TCP 连接目标，拒绝私网/元数据地址、非标准端口和其他域名。保留原模型代理范围。运行时配置 `BB_INTEGRITY_EGRESS_PROXY_URL`，不依赖 Chromium 忽略 Node 的 HTTPS_PROXY。

发行人与人员按站点顺序查询，最多 3 页结果及 3 篇可打开正文；截断、附件和受限范围均写入底稿。不自动下载和解释附件，不将同名命中认定为主体已匹配。暂不支持的搜索控件、第三方搜索域名或变化后的页面明确待补证。后续扩站应增加真实站点样本与回归测试。

迁移 `0116_integrity_browser_evidence.sql` 只新增自动取证表。新轮次锁定 `collector=official-browser-v1`，原无该字段的轮次保持旧搜索引擎证据语义。数据、截图和原模型用量记录不可混淆。若整轮没有实际提交任何查询，保留原不扣费失败口径，用户仍可免费导出已保存的待补证记录；访问官网本身不算完成查询。

本次未操作生产网络、服务或数据库；发布负责人在本地集成版验收后按固定版本组合迁移、API、web、worker 和专用代理，核对内存资源（浏览器 worker 建议至少 1536 MiB）与现有 Codex seccomp/AppArmor 沙箱支持，再统一发布。
