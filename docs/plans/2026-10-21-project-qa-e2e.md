# 项目问答 E2E

本批在项目、文件、诚信核查前置分支上实现，不部署。基线 9b274d0a；依赖 PR #713、#715、#717、#719、#721。原型为 BondBuddy-project-overview-design-20261020 的 35da7b8c，apps/web/src/project-design/qa-view.ts、qa-model.ts。选择项目遵守用户后续统一 UI 要求，复用 ProjectEntry。

用户确认：按识别后确认的问题数每题 60 积分；知识库先做录入公开来源、人工审核及检索，真实案例后补。

实现范围：

- 统一项目选择、新建项目、BondBuddy 项目对话与 Word 问题清单。
- 免费解析 Word，展示定位与候选问题，用户确认本轮问题及总价。固定原件、项目材料和案例快照后开始。
- 后台逐题作答，回答引用必须能在固定项目材料定位；证据不足明确标记，原文旁回填回答、依据与待补材料。旧原件不变。
- 项目文件 4.2 保存历次成果；下载、补充材料、下一轮、暂停恢复及取消；成功交付后收费，失败取消释放。
- 知识库案例录入、审核、撤回、中文检索与可追溯来源；仅已审核案例用于回答思路，不用于本项目事实。
- 合成端到端测试涵盖真实本地 API、数据库、存储、worker、Word、权限、幂等、计费与历史版本。真实模型调用和用户验收另行记录。

本批开发交付到 develop 的 draft PR，未经用户确认的设计偏离记录在验收文档，不自行合并发布。
