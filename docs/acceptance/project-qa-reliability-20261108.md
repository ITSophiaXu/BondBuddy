# 项目问答空白引用与失败后恢复

状态：开发和自测完成，尚未部署，待统一发布。没有客户任务重跑或新增真实模型调用。

## 问题与行为

七题问答任务的第七题两次生成均带有空白位置的证据编号，结构校验通过，但引用物化拒绝输出并终止整个任务。此前六题已保存。首题也曾因四个空单元格引用触发一次额外模型调用。

1. 新提示词使用 `project-qa-evidence-refs-v2` / `project-qa-direct-answer-v7`。空白单元格保留位置和空文本，引用编号为 `null`，不再表现为可选证据。零、横线及完整表格结构保持原值。
2. v1/v2 输出兼容处理仅移除在绑定材料中确认为空白的规范编号。正文、状态、资料缺口、其他引用不改写。未知编号、未选入的非空原文、跨未授权材料、重复编号及只有空引用的事实回答仍拒绝。旧逐字引文协议继续按原规则校验。
3. 用户再次提交同范围任务时，可复用此前因模型输出校验失败的任务中已经完成的答案。必须同账号、同项目、同执行环境，且源文件、准备稿、选定募集书版本、全部问题、材料、要求、案例与项目名称一致；仅忽略不改变内容的报价/预占元数据。旧输入与答案哈希、兼容模板、已完成模型调用及当前原文引用再次核对。只接受明确兼容的 v6/v7 模板。
4. 复用先持久化来源任务、问题、答案哈希、模板及语义范围哈希，再在有效租约下保存答案。原失败任务、模型观察及积分释放不改写；新任务继续走正常报价、Word交付、授权下载和结算。来源不满足条件时正常重新生成，不猜测可复用。
5. 项目问答接口在任务表错误码为空时回读该任务的最终失败事件，避免模型错误被显示成没有原因的失败。公共响应结构和页面布局不变。
