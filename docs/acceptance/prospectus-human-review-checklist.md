# 固定候选募集书金样：独立人工复核清单

本清单用于候选成果实际就绪后组织复核，**不是验收通过记录，也没有代填任何人工结论**。按 `scripts/verify-prospectus-acceptance.mjs` 与 `scripts/prospectus-financial-policy.json` 准备资料。原件、成果及私有验收记录留在授权私有目录，不上传GitHub/CI artifact。模型生成、脚本检查、人工复核和发布授权分别记录。

## 先准备可审阅成果

由发布任务填写真实候选 commit、tree、`prompt_tools_sha256`，以及实际 run ID、input hash、模型调用ID、开始/结束时间和模型准确ID。版本变化后不得移用旧候选结论。当前状态保持“待候选输出就绪／待人工复核”，不预置 `status:passed`。

| 材料 | 就绪时应提供的内容 |
| --- | --- |
| 金样与授权输入 | `rq-202509`：任丘市建设投资集团有限公司，历史截止2025-06-30，目标2025-09-30；manifest全部原件及SHA-256，不只取募集书 |
| 锁定输入 | `codex-file-input-v1`原始快照，目标主体/期间、材料引用与原稿hash |
| 真实调用记录 | 当前候选、run/input、双Word hash，实际provider/model/request/actor，真实时间和测得input/output/total tokens；未知用量不能填写为0或测得 |
| 三份Word | 准确原稿、修订稿、清洁稿；文件名、字节数、SHA-256及私有可打开路径 |
| 三份PDF | 同一受控渲染环境输出的原稿、修订稿、清洁稿PDF；对应DOCX/PDF hash、实际页数、renderer版本 |
| 服务端质量记录 | 与上述原稿/双稿hash一致的原始 `word-quality-v1` 报告，包含实际问题及正文/页数规模检查 |
| 审阅导航 | 完整章节清单和输出定位；21项财务组合、43个必查位置的来源/输出定位；未解决疑点及已知限制 |

代理可以计算hash、渲染、提取原始事实、整理逐项对照和标出问题；这些准备均标记“自动整理，待人工核实”。不能把脚本通过、模型自述或旧成功稿当作人工事实/版式结论。

## 独立人工需要实际确认的内容

- [ ] 审阅者确认真实姓名、独立身份及实际审阅时间；审阅者不是模型/机器人，也不是该provider调用的actor。最终记录中 `actor_type:human`、`independent_from_model:true`、`generated_by_model:false` 必须来自真实事实。验收器要求审阅发生在真实调用结束之后，且距验证时不超过7天。
- [ ] 逐章核对原稿全部章节与对应输出位置，记录保留/更新、必要事实更新、表格完整性和结论。标题/正文允许按目标主体及市场品种改写，不要求旧句相似度或逐章字数比例；不能用“保留结构”代替语义归属与事实正确性。
- [ ] 核对主体、合并/母公司口径、目标期与历史比较期、金额和单位、公式及适用前提。原始未披露信息保持待确认，不以缺失推定不存在；不为满足篇幅保留母公司或旧市场的不适用事实。
- [ ] 至少完成下表21个指标/口径组合与固定43处输出位置的独立核查：28个表格金额、14个正文金额和1个正文比例。准确来源单元格、可见表头/行标签/主体/期间/单位和原始缓存值均应核对；相同数值的其他单元格或新增正确副本不能覆盖旧正文错误。
- [ ] 按原稿、修订稿、清洁稿分别检查每一页。逐份记录已看页码1…N、对应DOCX/PDF hash，核对模板、字体/字号、页眉页脚、表格/跨页表头、无裁切、无缺字、图片及修订显示。渲染成功和页数统计只证明机械条件。
- [ ] 对分页变化写明实际观察。已批准页数规则为：实际源稿至少50页、清洁稿低于70%、减少至少20页，三条件同时满足才按页数骤减拒绝；正文总量和其他质量规则独立继续适用。页数满足规则不等于页面视觉合格。
- [ ] 登记全部发现及严重度。major/critical必须有实际解决证据并重新复核后才能关闭；minor亦如实保留。审阅说明应具体涵盖本次文件，不能复制泛化“通过”文案。

## 最小财务核查范围

以下是固定政策的索引摘要，准确单元格与43处角色列表以候选的 `scripts/prospectus-financial-policy.json` 为准；不得用本表取代该机器可核对清单。金额来源固定为授权 `rq-202509-02` XLSX及其hash。存量指标截止2025-09-30，流量指标期间2025-01-01至2025-09-30。

| 口径 | 指标 | 项数 |
| --- | --- | ---: |
| 合并与母公司各一套 | 总资产、总负债、净资产、净利润、经营活动现金流净额、营业外支出、应付债券 | 14 |
| 合并 | 递延收益、销售费用、管理费用、财务费用、投资收益、归母净利润 | 6 |
| 合并 | 应付债券占非流动负债比例：分子 `01合并资产负债表!D116`，分母 `D127`，独立计算并按两位百分数舍入 | 1 |

21项只是最低回归清单，全文其他金额/比率、法律时点、主体身份、附注、风险与待确认事项仍须业务复核。真实调用、机械验算和格式保护不替代这些独立判断。

## 实际复核后才可形成记录

由受控发布流程整理人工确认内容，保留审阅者、真实时间、逐章定位/结论、财务来源与输出值、三份PDF全部页码、分页说明、发现及处理记录。`review_record`须绑定本次source/tracked/clean/render-report hashes，包含完整章节ID及全部财务检查键；`render_report`与同一审阅者一致。只有真实人工确认后才能填写 `facts_verified_by_human:true` 或各项通过状态。

最后由 `BB_PROSPECTUS_ACCEPTANCE_FILE` 指向该私有记录，执行当前候选验收器及完整质量门禁。验证失败保持具体错误与原始证据，不能手工补pass、借用旧hash或让模型冒充审阅者。本清单的完成也不自动代表已部署或用户已对其他功能验收。
