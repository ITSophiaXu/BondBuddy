## 已实现行为

- 底稿章节与文件来自本次真实目录；章节下文件默认全部显示，可按章节或单份勾选并调整章节顺序。
- 前八个所选章节各取首份选中文件试生成，不足八章按实际数量。每份完成即可预览、下载，关闭页面后仍可恢复批次。
- 试生成结束持久等待用户确认。普通“继续”不能越过确认关卡；确认请求可幂等重放。
- 确认后按固定章节顺序自动续跑，同批最多两份并发。完整来源提取复用一次；其余文件按章节分成最多八项的小组共享审阅，再独立校验、缓存和交付。
- 单份内容、计算和 Word 渲染失败不阻塞其余文件；仅重试失败项，成功成果和账务保持不变。公共来源、权限、服务能力、租约或供应商对账问题保留阻断。
- 暂停/停止阻止新文件启动，已开始的至多两份继续收尾。下载不会冻结进度；停止后的未开始文件不被计为失败或已完成。
- 旧批次保留原执行模式；自有模板和补充材料沿已有作者路径，仍遵守新批次的试生成关卡和逐份调度。

## 验证环境与边界

本机独立 PostgreSQL 16、独立 Azurite；使用本工作区构建的 contracts/API/worker/web。数据库从完整迁移集创建，测试文件再克隆隔离库，未连接生产数据库或存储。

浏览器使用真实网页与合成 HTTP/材料/支付状态；worker 使用合成模型返回、真实 API、队列、PostgreSQL、Python 提取和 Word 编制，私有存储 adapter 为测试 Map，账务为历史固定价格夹具。自动积分和支付恢复另由 API 测试覆盖；专门的 248 文件 ZIP 测试使用真实 Azurite 存储。模型测试没有调用真实 Copilot/DeepSeek，因此不构成真实模型内容质量或耗时验收。

开发服务器端口 5313 仅供自动化页面测试，并非包含 API、worker、登录的统一本地验收入口；不能将该地址交付为可用集成版。
