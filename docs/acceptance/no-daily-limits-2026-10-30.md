# 取消每日限额：开发验证与发布交接

## 行为

API 不再检查每日任务数、项目数或上传字节数，API/worker/助手不再按每日 token 用量拒绝新调用。四项旧环境配置被忽略，即使仍配置为正值也不能恢复每日限额。管理状态的兼容字段返回 0；原始用量、未知用量、历史事件和账务保留。

并发容量、短时间请求频率、管理员停用、紧急停止、归属、幂等与现有积分检查仍生效。已被旧每日额度拒绝的提交可使用原请求重试；旧 token 限额暂停的任务由现有 sweep 恢复，已完成模型结果复用。

无网页代码、布局、文案或交互步骤修改，沿用 `product-prototype/public/authoring-materials-entry.html` 的开始操作及现有进度页面。旧错误解析仅兼容旧服务/历史记录，当前服务不再生成每日限额错误。取消该业务门槛依据用户本次明确要求。
