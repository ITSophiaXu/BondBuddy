# Issue #947：上传恢复与声明限读开发验证

日期：2026-11-11。基线：`0c533ffc17cbca6b2fb6cf064339b0e115b4558d`，目标分支：`develop`。本记录是开发自测，不是用户验收或生产发布凭据。

## 修复范围

- 直传恢复先确认原对象仍未到达、再续签原票据期间，原 PUT 可能完成。仅当续签返回 `409 IDEMPOTENCY_CONFLICT` 时，恢复层再次 complete 原上传 ID 和原不可变声明；必须取得合法材料回执才接受成功，不新建上传、不重传字节。其他错误仍原样处理。
- 直传完成核验先比较 HEAD 长度与声明大小，长度不符时在预留暂存和下载前拒绝；实际读取上限也绑定声明。保留现有租约、归属核验、终态回执和原 ETag 条件清理。代理上传继续使用原有读取边界。
- 历史代理上传过期且服务端确认没有字节时，参考稿组件将用户显式重选的同一 File 传给恢复层，允许沿用原声明替换缺失会话。只点击确认不能替换；大小相同但哈希不同的文件不能继续；文件改名不改变原声明文件名。

没有契约、迁移或依赖变更，没有页面结构、样式或产品文案变更。
