# 复核结果与正文双向定位（2026-11-10）

状态：开发和自测完成；代码完成，尚未部署，待统一发布。用户尚未验收。

用户反馈：结果页左侧已选中问题，右侧仍停留在募集说明书封面，两侧没有连贯的跳转逻辑。

原实现只在点击问题按钮后执行一次 `scrollIntoView`。首次打开、类别筛选和预览版本切换没有重新定位；重绘会丢失正文滚动位置；正文及批注没有反向选择问题的入口。

## 交互

- 初次打开定位首个选中问题；点击问题、上一项／下一项及类别筛选，在当前成果的正文中高亮对应段落。
- 原文、修订版、清洁版共享同一问题选择，切换视图重新定位该段。预览上方持续显示对应问题和正文段号，段号不冒充 Word 页码。
- 点击正文段落、批注内容或问题标记，回到左侧问题详情。同段的多个批注分别绑定问题；跨类别点击会显示全部类别，避免详情属于一个被筛掉的问题。
- 桌面两侧独立滚动，自动定位只滚动正文容器；用户手动滚动后可用“定位正文”返回。手机纵向布局提供同一定位按钮和批注返回入口。
- 处理选择、手动输入和普通重绘保留阅读位置；手动输入保留光标。原文／清洁版中的跳转控件为图标，不把问题名称、类别或复核说明写进正文文本。
- 缺少有效段落关联时显示“无法自动定位”，禁用定位按钮并要求人工核对；不会跳到其他段落或保留错误高亮。
