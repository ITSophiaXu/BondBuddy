## Human 准备与剩余门槛

1. 固定修复后的运行版本、范围/市场、required 子例、owner、授权材料和有效价格。先定向重生成 AQ-06，核对实际原文复读 trace 和正文/说明的准确引用；当前不宣称全部缺陷已修。
2. Human 独立尝试代表旅程，记录帮助次数、困惑、完成/恢复/费用理解；手机实际触摸菜单、收起与退出。按 #646 使用顶部可见入口，不采用旧完全隐藏标准。
3. Human 抽查发行人、市场、期间、关键数字/条款、原文批注和来源位置；按 #643 检查新正文标题，旧成果不追溯改写；实际 Word/WPS/PDF 打开、编辑与批注检查另留证据。
4. UX-A03“暂停 → 补材料 → 继续原任务”仍缺主动 pause 和同 run 采用新材料协议，业务目标 fail / functional_gap，依赖步骤 blocked，费用 design_gap；取消重建或下一稿不能判通过。
5. 真实 M1/M3/其余 M4 文种、QA/续改闭环仍有未执行范围。受控 JSON 的 selection 未冻结，Human 三项 not_run，U ready=false。正式 Human/U 需按适用 required 子例逐项判定。
