# 诚信核查加载等待、地区条件与精确结果状态

本批程序修复开发和自测完成，尚未部署，待统一发布。用户尚未验收；**不能据此认定所有官网已达到“仅无结果或验证码/登录”这一验收要求。**

## 已完成的修改

- 首页从导航提交开始等待查询控件和页面脚本就绪，首页与查询结果各给 90 秒；支持动态表单、可见 iframe、查询链接及另开的结果页。允许初始非 200 响应后的官网自动导航完成。信用中国首页未能加载时，第二次尝试进入其搜索按钮实际使用的 `/xinyongxinxi/index.html` 页面。
- 加载失败或结果未确认最多自动尝试两次；验证码和登录立即停止该站，继续其他站点。不识别、填写或绕过验证码。两层出网代理的空闲限时从 30 秒统一调整为 120 秒，避免浏览器还在等待时网络先被断开。
- 只接受成功的本次查询响应、查询词回显以及已变化且稳定的结果内容。页面其他区域（例如时钟）变化不能证明结果更新；显示加载中的结果容器不能作为已完成查询。空白和纯加载页不保存截图。技术失败保留 HTTP 状态或安全的错误分类，不改写为无结果、登录或验证码。
- 复用已填省份、城市及企业名称中明确的省份前缀，例如“河南…”。不从人员姓名推测地区，不覆盖已填省份；这不是从所有项目材料抽取并核验营业执照地址。法院下拉框按实际选项选择，有“全国”时优先保留全国范围，避免漏掉外省案件；只能选省时使用已知省份，并在查询范围中说明未覆盖其他地区。
- 新查询的技术失败/未确认不再分类为缺少人工信息。保留网站已经返回的相关搜索结果，即使模型未解读成功，也不要求上传证据。结果页以“查看查询记录”为入口，删除补证上传表单，保留历史证据下载、原始截图校验、免费重新导出。历史数据及其原始原因不重写；旧访问拦截也不统一改标为验证码。
- Word 的未完成提示同步去除强制补证要求；继续排除失败/未确认截图作为结果插图。

## 结果状态细分（2026-10-26 用户补充要求）

- 新采集保存结构化原因、发生阶段、HTTP 状态、可见错误摘要、尝试次数及实际耗时。分别显示搜索无返回结果、搜索返回结果、页面空白、页面加载超时、查询结果加载超时、查询页面尚未就绪、本次结果未确认、网站拒绝访问、网站响应错误、网络连接失败、验证码、登录及操作未完成。没有具体失败原因的历史记录明确标注未记录，不推测 HTTP 状态或认证要求。
- 客户文案使用“网站拒绝访问”“网站响应错误”等中文说明。HTTP 状态码、Forbidden、GeoBL 和网络错误代码只保留在后台诊断及原始证据中，不拼入列表、详情或 Word 的状态说明；旧记录也经过相同展示处理，不修改已保存事实。原始官网截图和引文保持原样。
- 结果页与 Word 共用 contracts 中的状态展示函数。无结果使用中性状态；明确不利记录突出显示。未执行网站在任务结束后显示未执行，不继续显示等待查询。
- 新版解读将具体事项、逐字引文、来源截图、事项性质及主体匹配情况持久化。企业全称匹配的不利记录、身份未确认的不利线索、一般信息与其他主体记录分别展示；人员同名不能标为身份已确认。模型给出的每条引文必须实际存在于指定截图文字中，企业全称匹配的引文必须包含企业全称。原文未载明的处罚状态、整改、日期和金额不能补写。
- 增加可选 browser.diagnostic 和 findings，不重写已哈希保存的记录，无数据库迁移。由不可变采集批次决定模型解读版本：历史无诊断批次沿用 v1，新批次使用 assessment-v2，暂停恢复不会额外切换版本或重复解读。
- 仍不要求上传补充证据。具体原因用于说明查询边界，HTTP 错误和空白超时不会变成“无结果”。

## 真实官网观察（2026-10-26，北京时间）

查询对象为公开企业名称“河南投资集团有限公司”，没有使用用户账号、私人识别号、真实模型或生产核查任务。

- 应用内实际浏览器能打开信用中国首页，搜索会另开官网信用信息查询页，然后出现验证码输入框（`vcode`，提示“请输入验证码”）。未处理验证码。
