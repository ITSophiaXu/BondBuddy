对一轮正式任务只读核对：选择54站，已保存26项记录、25张原图，其余28站未执行；2项无结果、9项失败、15项待人工。原图逐张检查，图片与文本 SHA-256 全部重验。终态为 failed / DATA_UNAVAILABLE，任务尝试3次；历史内部异常已脱敏，不能确定整轮停止的唯一历史根因。客户项目、对象及原始证据仅留私有 work 目录。

隔离官网诊断覆盖54站，使用公开企业“河南投资集团有限公司”，不重跑用户任务、不修改账务、不调用真实模型、不处理验证码。最新实测34站取得可确认的搜索结果（20站有返回、14站明确无结果）；其余20站的实际限制详见下表。搜索返回结果不等于本企业存在不利记录，也不等于所有页面、附件及专项数据库均已核查。

## 代码修复

- 等待 iframe、defer/async 脚本与实际查询响应，识别交易所无文字按钮和商务信用企业名称条件。未发出查询时不再写成已查询。
- 补齐官网真实结果表述；新查询文档可返回与空查询相同的0条，但隐藏 iframe 或原地未更新的旧0条不能通过。
- 空白、加载中、截图时查询条件丢失的页面不作为结果证据。样式加载失败不再把未隐藏的反馈表单误判为验证码。
- 修复远端字体永久加载造成的截图超时；通过 CDP 同步真实 compositor 后，仍用未编辑的 scrot 整屏图。首次展开窗口没有捕获表面时有界重试。
- 站点浏览器启动/清理异常记录为该站失败后继续；取消、存储/hash、归属及租约错误仍阻断。桌面启动仅在浏览器查询前有限重试；compose 增加 init 回收子进程。
- 交通部、农业部外部搜索资源按实际域名、本站资源路径及查询 API 放行；worker 仍强制使用既定国内代理，无直连回退。聚合国内代理也识别依赖，需随 worker 一并升级。
- 导出轮查询详情读取不可变原记录快照，修复 records=[] 时空白；保留旧版未保存补证草稿恢复，普通详情不重新开放上传入口。
