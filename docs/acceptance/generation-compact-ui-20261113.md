# 文件生成：分类全展开、章节选择与进度精简

代码和开发自测完成，尚未部署，待统一发布；用户尚未验收。

## 当前要求与实现

用户于 2026-11-13 提供四张截图，明确以图 2 的结构展示全部文件类型，章节选择不展开内部文件，取消图 4 的全量逐份状态。该明确要求是本次 UI 依据，没有对应的原型 commit。

- 13 种文件类型始终可见。底稿包独占一行，其余按尽调与内核、申报文件、定期报告、专项说明分类；桌面左侧分类、右侧四列，窄屏适配两列/单列。支持分类计数、全选/取消全选和清空。
- 章节选择只渲染真正章节的勾选、数量和顺序。250 份文件仅显示 10 个章节行，没有子文件 checkbox 或逐文件要求长列表。旧的部分选中集合和章节顺序经保存、刷新、排序、提交保持不变。
- 试生成进度显示整体和章节汇总，移除“逐份成果与状态”全量清单。已完成试生成文件可查看和下载；全部已完成成果仍可下载 ZIP。批量失败重试、暂停/续跑、试生成确认及需人工处理的受阻任务入口保留。失败原因去重，最多展示 3 条摘要。
- 高级自定义模板匹配清单和旧的非渐进批次兼容路径保留。普通章节选择不再进入该逐文件匹配编辑器。
