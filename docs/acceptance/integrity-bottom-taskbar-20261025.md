# 诚信核查截图：底部系统工具栏与实时日期时间

用户在 2026-10-25 明确要求截图底部必须有工具栏，时间戳必须显示在工具栏里，并拒绝顶部黑色面板。本决定替代前批“原样使用发行版默认 XFCE 布局”的呈现约定。

## 修正

旧实现直接复制发行版默认配置，实际得到顶部深色面板和底部自动隐藏的小 dock。旧测试只在顶部裁取时钟作 OCR，因此通过测试仍不满足用户要求。

现在只启动一个固定于底边、不自动隐藏的浅色 XFCE 系统工具栏，保留原生应用菜单、显示桌面、窗口按钮、托盘和时钟插件。时钟按 Asia/Shanghai 显示 YYYY-MM-DD 与 HH:mm:ss，读的是运行环境的实时系统时间。浏览器最大化时为底栏保留空间，标签栏和地址栏完整保留。每次截图前检查只有一个全宽底栏；位置不符时拒绝产出该截图。

截图仍由 scrot 直接保存独立 Linux 桌面根屏幕，未在图片上补画工具栏、叠字或改写时间。桌面不是用户本机的 Windows 会话，系统时钟也不是第三方时间戳认证。
