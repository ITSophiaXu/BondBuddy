# 更新募集书：材料保存完成后才允许开始

状态：开发修复，尚未部署，待统一发布；不代表用户已经验收。

用户反馈材料进度尚未到 100% 时，页末“开始更新”已可点击。本次保留材料分区、原稿信息要求、显式开始和现有收费方式。

## 改动

- 页面刷新按钮状态和启动入口共用当前项目的材料就绪状态，包含本机排队、计算摘要、传输、保存、失败、取消及未确认上传，以及募集书版本的保存／采用状态。
- 上传未完成时按钮禁用并显示“等待材料保存完成”；旁边继续显示具体文件和进度。100% 字节传输后仍等待服务器保存确认，全部保存完成才恢复原开始动作，且不会自动执行。
- 创建输入快照前和提交任务前直接重读材料状态，防止依赖过期的页面状态。异步保存项目信息、读取版本或准备执行请求期间出现未完成上传时，不提交遗漏材料的输入／任务。
- 同步材料列表与就绪标志后再更新按钮，避免渲染旧材料状态。

## 复验步骤

1. 在已有材料的更新项目中再选三份文件，并限制上传速度。
2. 在排队、进度未到 100%、100% 后等待保存三个阶段检查页末按钮，均应禁用并显示等待提示。
3. 让一份文件上传失败，其他文件完成后按钮仍应禁用；重试成功或明确移除失败文件后才可继续。
4. 所有文件确认保存后不会自动开始；点击开始一次，锁定输入应包含全部采用材料。
5. 已成功任务点击“继续修改”后重复上述流程，旧任务与成果保持原有语义。

本地开发测试使用独立 5278 端口和合成接口，不提供为统一本地集成验收版。交付后由集成／发布 chat 纳入固定版本并按用户规则验收与发布。
