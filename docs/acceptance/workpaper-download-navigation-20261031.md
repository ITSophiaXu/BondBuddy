# 底稿下载期间导航被锁定

用户反馈批量底稿 ZIP 显示“成果文件暂时无法读取或校验未通过”，并且其他页面无法跳转。

## 已确认原因与修复

`WorkpaperPanel.download()` 与保存、提交共用 `busy`。`beforeLeave()` 返回 `!busy`，通过 `FileWorkspace.beforeLeave()` 传递到全局路由，导致等待下载和接收文件期间所有页面跳转都被拒绝。前端 ZIP 请求最长等待 20 分钟。修复前的流式下载回归已复现点击“项目文件”后地址回退到原成果页。

下载改用独立的 `downloading` 状态，继续禁止重复点击并暂停进度轮询重绘。离开页面不再触发未保存保护；已有 `dispose()` 中止当前读取，保留后台任务和成果。保存和提交的离开保护保持原行为。
