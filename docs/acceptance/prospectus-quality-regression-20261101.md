## 发布门禁

固定清单包含构建、公共契约、门禁反例、数据库迁移、API 原稿选择/自动采用/格式绑定、worker 编制与交付、授权原稿固定编辑及双稿、强制 LibreOffice 渲染、部署脚本反例。任何失败、skip、TODO、空测试、缺样本或缺 renderer 都拒绝。机械 `validate` 不签发凭据。

完整 `run` 另要求当前 commit/tree、提示及工具 hash 对应的真实模型三季报金样和独立人审。验证器实际读取锁定 XLSX 原始单元格、DOCX 数值位置、全部原章节和三份 PDF 页数，检查主体/期间/合并与母公司口径、单位换算、模型用量及人审覆盖。已修复“历史比较数撞中本期预期值”的漏检；表格要求同行指标、同列期间及同表主体，拒绝日期、百分比、括号负数等碰撞。

凭据只绑定完整 commit/tree、Linux、干净源码和固定清单，正常发布有效期 24 小时；四个镜像必须带同一完整 OCI revision。回滚只能使用曾成功部署版本的原通过凭据，并核对部署记录内同一凭据 hash。凭据及 JSON 不提供人的身份或供应商数字签名认证，信任边界为受控发布者，模型不能写人审证据或发布者凭证。
