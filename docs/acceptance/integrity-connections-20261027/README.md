## 问题与修复

- 旧采集器会把前一页面或弹窗来源页的样式失败带入结果页，并将带查询词的统计图片失败当成查询失败。现在按当前可见文档、仍在使用的样式及最新请求判断；查询响应只接受官方范围内的 document/xhr/fetch。
- 人民银行真实结果页正常展示，但模板引用的 `fuwuxiang.css` 返回404，导致整次查询被判失败。仅在精确官方主机、模板、资源路径、404、服务项组件不存在、主样式有实际规则且结果容器可见时，允许这一附属资源缺失。成功诊断保留 `OPTIONAL_PBC_WIDGET_STYLESHEET_HTTP_404`，查询响应、条件回显、稳定结果及截图后检查仍全部执行。未修改网页或截图。
- 样式重定向以最终响应判断；新的成功加载可替代旧失败；仍必需的样式及 `@import` 失败继续阻断。主样式缺失、组件出现、模板变化均不能套用人民银行例外。
- 已结束的HTTP错误及时结束无效等待。证书错误、拒绝访问及确定性4xx不原样重复；408/425、5xx和瞬时网络故障保留有界重试。原有412自动过渡页继续等待。正在进行的查询不会被重复提交。
- Web与Word共用的展示层区分“网站证书有效期异常”“网站证书校验失败”“查询页面样式加载失败”“网站限制访问频率”。原始错误与URL仍只用于诊断，不进入客户文案；历史保存数据不改写。
