# #959 助手回复停止与后续提问

本次修复前端回复状态恢复，不将原始慢响应、服务端中断原因或线上效果记为已解决。关联 [#959](https://github.com/ITSophiaXu/BondBuddy/issues/959)，PR 使用 `Refs #959`。

## 已修复行为

- 取消请求返回非终态时显示“正在停止”，等待服务器确认。请求失败时显示“停止结果尚未确认”，保留草稿和查询/重试入口，不显示“已停止”。
- 刷新先核对上一轮任务。确认已结束后可继续提问；状态未知或仍在运行时保留新输入，不重复提交上一轮。
- 新消息被接受后清除上一轮全局停止提示，旧消息卡仍保留停止记录。接受回执立即保留在时间线，后续读取失败不会让已接受消息消失。
- 同会话查询按请求顺序应用；取消/新提交会作废旧查询。切换会话后，旧请求的成功或失败均不能覆盖当前状态。
- 读取成功后清除连接中断提示。任务终态优先于滞后的消息状态，不再永久卡在“请等待本轮回复”。
- 消息已接受、随后清空输入的保存失败时，保留保存错误并继续轮询已接受任务，不重复发送。

没有修改公共契约、数据库、计费规则或模型配置。沿用服务端 `submission_request_id` 幂等协议，未将未确认的业务提交擅自判为失败或自动重发。
