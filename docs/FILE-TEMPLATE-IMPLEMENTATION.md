# 文件生成与私有模板库：开发交接

2026-10-29。开发代码与定向自测已完成，尚未部署，待统一发布。本文件不代表用户已验收，也不把原型地址当作后端集成测试入口。

## 行为与实现

默认文件生成入口从募集说明书进入统一准备页。底稿包、年报、核查意见、申请书、法律意见书和立项报告可混选，其他现有文种继续保留。底稿目录与 Word 模板包分别显示当前选择、预览与更换操作；更换一方保留另一方。支持内置光大套装、XLSX、DOCX、ZIP 和文件夹。Word/PDF 同名时采用 Word，仅有 PDF 的事项会提示补充。原有链接、历史任务、下载、暂停与重试入口保留。

目录解析包含 #806 的无表头恢复与灵活列/行/工作表映射。准备页沿用上传恢复协议，保留原始上传声明、人工映射、未保存清单和未确认提交请求。确认前展示文件、遗漏目录与价格；请求结果未知时可核实原请求，或停止尚未提交的请求。停止记录在服务端阻止迟到请求再次创建批次。

`packages/contracts/src/file-generation.ts` 统一定义准备、模板引用、导入、匹配、报价、父批次与 OpenAPI。`apps/api/src/file-generation.ts` 在同一 PostgreSQL 事务中创建底稿和其他文种的子批次及父回执；相同请求先读取回执，再检查当前准备状态。保留现有计费规则，不因采用模板或保存清单伪造扣费。

模板原件按 owner/project 私有存储。执行固定模板版本和 SHA-256，worker 复制到可编辑工作副本后编制；显式选择模板的底稿不走清空正文的 shared renderer。模板原件不进入普通材料列表、项目事实采用、问询资料或公共下载；worker 的 authorized_sources 同样排除模板。模板正文只能提供格式，不能成为本项目事实或执行指令。

结构预览由服务端流式解析，只有完整通用标签白名单保留，其余内容替换为占位。版式预览对独立脱敏副本转换为 PDF；正文、表格、页眉页脚、元数据、修订、批注、图片、外链与嵌入内容均经过清理。原件不下发浏览器。复杂 Word 的正文 XML 可按流式读取上限处理，原有 ZIP 路径、CRC、压缩比和总解压大小检查仍生效。

原件、完整 intake、实际页面和 bundle 不进入 Git。私有交接目录位于本机项目的 `work/file-template-implementation-20261029/`，包含 `guangda-20261029-v1/`、`previews/audit.json` 和预览审计页。构建工具为 `scripts/build-file-template-bundle.py`，每个新版本使用新目录并校验原件哈希。

发布/集成负责人需要安装私有只读 bundle，并设置 API 的 `BB_FILE_TEMPLATE_BUNDLE`。可选 Compose 覆盖文件为 `deploy/m1/compose.file-templates.yaml`，通过 `BB_FILE_TEMPLATE_HOST_DIR` 指定宿主机目录；不要把该目录加入公开静态站点。未安装时页面明确提示，仍可上传自己的模板。API 镜像增加 LibreOffice Writer、中文字体及独立 Python 预览依赖；预览在磁盘暂存目录运行，每个 API 进程同时最多 1 个转换，超时可重试。worker 不需要额外挂载原件，使用私有 Blob 中固定的模板。

数据库新增迁移 `0122_file_generation_templates.sql`、`0123_file_template_privacy.sql`，依赖现有 0121。2026-10-29 核对 `origin/develop` 为 `c7d0c42a`，没有同号迁移。API、worker、web、contracts、迁移及私有 bundle 应作为同一集成批次交付。

回滚须保留 `internal_template` 字段及对应下载/资料隔离保护；不能直接回到不识别该字段的旧 API，让内部原件恢复为普通可下载材料。项目删除清理模板 Blob；存储盘点识别模板资产，其孤立资产不会被本次改动自动删除。
