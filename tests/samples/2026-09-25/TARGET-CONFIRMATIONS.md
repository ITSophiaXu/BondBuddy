## 清单字段约定

`manifest.json` 的案例新增可选对象 `target_confirmation`，用于保存本次测试任务的确认记录；这是测试清单元数据，不是新增生产 API 契约，沿用 `manifest_version=1`。

- `status`：`confirmed` 或 `pending`。
- `confirmed_by` / `confirmed_on`：实际确认人和确认日期；待确认时为 `null`。
- `market` / `offering`：目标市场与发行方式，值沿用公共契约；待确认时为 `null`。
- `reporting_periods`：完整目标年度/中期集合，采用现有清单的 `YYYY`、`YYYY-MM/YYYY-MM` 格式；待确认时为 `null`。
- `latest_cutoff`：从已确认目标集合确定的最新财务截止日；待确认时为 `null`。
- `record_path`：相对本批目录的业务确认记录及锚点。

原有 `source_reporting_periods`、`source_latest_cutoff`、`market`、`offering`、`classification_status`、逐文件证据与 `industry_acceptance` 继续保留原义；`requested_target_cutoff` 为兼容既有清单保留。四组该字段均与已确认目标截止日相同。
