# 任务进度与结果入口（2026-10-29）

用户要求项目列表优先展示任务进度和结果，把项目文件、一致性检查等操作降低层级，并将“全部项目”改为易懂的名称。本次按该要求实现；用户尚未实际验收，代码完成，尚未部署，待统一发布。

## 交付

- 开发基线：`c7d0c42a`（develop）；页面、设计快照与同尺寸截图：`f8c68f51`。后续提交仅完善验证记录和旧测试定位器。
- 侧栏、面包屑、页面标题、返回入口统一为“任务进度与结果”。原 `#tasks` 路由和历史链接兼容。
- 项目行保留两个明显按钮：执行中突出“查看进度”，已有成果突出“查看结果”。无成果显示禁用的“暂无结果”。项目文件、一致性检查、开始各项工作和归档放入“更多”。
- 最近成功任务直接打开对应 run / artifact / report / batch。最新任务失败时，结果入口筛出已有结果，自动跨过无结果的较新任务页；允许查看全部历史任务。底稿部分完成时保留结果入口。失败、取消和内部测试记录不被冒充为成功成果。
- 展开记录的结果操作改为实体按钮，保留后台刷新、分页、阅读位置、键盘焦点、返回恢复与账号隔离。
- 无 API、worker、契约、数据库迁移或依赖变更。集成只需更新 web。
