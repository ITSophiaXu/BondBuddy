# 募集书参考稿与误上传纠正

基线 develop 859e7ada；本 PR 的实现与原型同批交付。原型：product-prototype/public/prospectus-reference.html；实现：apps/web/src/prospectus-panel.ts。截图均为合成数据，视口 1440×960 与 390×960，截取面板。empty / saved 分别覆盖无原稿继续及未采用稿件删除入口。

人工查看 desktop/mobile 实现截图：无横向溢出，文件名可换行，采用/下载/删除操作可见。修正移动端保存提示文字被按钮挤窄；去掉更新页中重复的未选择提示卡。

原型以简化文件图标及版本详情展示交互；实现保留已有只读文件版本记录，并在已保存提示中继续提供定位发行人材料的入口。更新页使用历史／参考稿文案，项目文件页保持项目当前稿语义，文件生成和一致性检查各用原流程。

验证边界：浏览器使用合成 HTTP；API 使用本任务独立 PostgreSQL 16 / Azurite，实际上传、读取、删除、版本选择和输入锁定。更新任务及双 Word 交付使用合成结果，未调用真实模型，不构成用户验收。无生产操作。

最终测试结果和命令见 validation.json。
