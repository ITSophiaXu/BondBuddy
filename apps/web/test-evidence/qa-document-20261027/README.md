## 复验与集成

1. 从任一项目进入问答，确认项目只显示一次、首页只有清单上传，无页面内聊天；通过全站右下角图标打开/收起 BondBuddy。
2. 上传 DOCX 或可检索 PDF，核对候选题与所用材料，再确认费用开始生成；PDF 查看转换警告。上传中断后只恢复原文件/原请求。
3. 下载 Word，核对原问题、回答和依据；在页面查看每题需补充的材料。扫描 PDF 无可识别问题时不能开始收费回答。
4. 点击准备下一轮，选择对应问题并补料；确认费用后再生成。历史版本仍能独立下载，查看结果不发起任务。
5. 使用 1440×960、390×844 及右侧助手展开状态复验布局。

API、worker/Python、web 必须同批集成才能开放 PDF 上传。PDF 仅提取可检索文字，扫描页无自动 OCR；不保证 PDF 表格、图片和分页完整复原。Word/WPS 桌面及真实模型专业内容本次未验收。

本机临时测试入口 `127.0.0.1:5237` 仅用于夹具浏览器测试；独立测试依赖监听 `127.0.0.1:15457` / `127.0.0.1:10037`。交付后均停止，不作为可用用户验收入口。运行日志及合成 Word 位于仓库外 `work/qa-document-runtime-20261027/`。统一本地验收由集成测试 chat 汇总本 PR 后提供；本 chat 未广播消息、未连接生产数据库、未部署。
