# 误传历史稿删除与替换（#624）

新上传成功的本地行原先只有保存状态，缺少删除入口；恢复的服务器行才有删除。现两类行使用同一删除 API。删除确认后清理当前会话及原稿元数据并保存草稿，失败可重试；运行中保持只读，重复点击不会重复发出删除请求。已提交输入快照保持不可变。没有 API 契约或数据库迁移。
