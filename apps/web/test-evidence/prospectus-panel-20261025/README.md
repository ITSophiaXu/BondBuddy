## 行为

空状态显示明确的上传按钮和可继续提供材料的说明，不显示空版本历史。选择文件后显示文件名、大小、保存、取消和重新选择，明确保存不会开始生成或扣费。已有版本展示文件名、版本号、来源、日期和直接下载，历史版本默认折叠、按版本倒序展示。当前页重新读取材料保留待保存文件和历史展开状态；文件格式错误始终有提示，上传/保存失败可重试且复用已有上传和请求标识。
