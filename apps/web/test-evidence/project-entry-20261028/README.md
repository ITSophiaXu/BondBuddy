# 项目选择页：操作入口常驻

2026-10-28 用户截图指出：项目较多时，所有功能入口的底部按钮难以找到。本次按该要求调整五个入口。实现、共享样式和交互原型来源提交：`27ce8ab4c82e6e5f13ec4f92c5952dde03a318fa`，基线 develop `5d24d5d85a0c9fb7551354b437d832f9a475867e`。

## 行为与范围

- 文件生成、复核募集书、诚信核查、项目问答共享 `ProjectEntry`；更新募集书的“继续已有项目”使用相同布局规则。
- 页面按视口分配高度，只有项目列表滚动；搜索、当前选择和主操作保持可见。操作栏占据自己的布局空间，不覆盖最后一项或“加载更多”。
- 项目卡片收紧间距；手机标题与新建按钮同排，选择摘要和主按钮纵向排列，并为 BondBuddy 图标留出空间。
- 分页保留选中项目，搜索清空旧选择并回到列表起点；无结果、读取失败和打开失败仍显示操作及反馈。募集书入口继续保留“新建优先”，展开已有项目时将新建卡片收紧。
- 未改变接口、归属、执行、费用或业务规则；无新依赖、迁移或 API/worker 交付要求，仅需后续统一发布 web。
