# 底稿文件库界面验证

截图为1440×960和390×960视口，使用 `apps/web/tests/workpaper-library.spec.ts` 的合成项目、61条底稿和mock API。截图不含客户材料。页面实际使用 `ProjectFiles` 和 `WorkpaperLibraryPanel`。

覆盖：50条分页、历史批次、编号/名称搜索、两分类、关联变动的前后值及目标位置、文本预览转义、说明下载、检查请求固定当前版本、网络失败重试复用request_id、旧检查失效。两种宽度没有页面水平溢出。

本功能按用户本次要求在现有项目文件页增加底稿库；该新增区域没有既有独立原型，截图作为本批实现供视觉验收。既有批量生成页按 #762 原型回归，9项通过。新文件库3项通过。此记录不代表用户视觉验收、真实后端浏览器验收或真实模型生成验收。
