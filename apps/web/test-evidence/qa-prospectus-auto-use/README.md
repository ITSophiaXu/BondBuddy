# 项目问答：上传募集说明书后自动使用

2026-11-09。起始版本 `ba512475`；原型、实现与本目录证据同在本次修复提交，完整提交号登记于 PR。关联前端任务 #361。

## 行为

上传成功后调用既有版本选择接口，随后把准确的募集书引用加入本轮可编辑草稿、替换本轮已选的原当前稿，自动关闭材料弹窗。没有“使用此版继续”或再次“用于本轮回答”的步骤。问题、要求和其他补充材料保留；已经提交的任务输入不变。

旧版本仍可在历史中主动选用。上传失败保持原选择；采用回执丢失沿用原请求重试；并发版本冲突不静默覆盖；已采用但问答资料刷新失败时可重试同步，不重复上传和切换版本。材料达到 50 份且无旧稿可替换时，保留已有材料并提示先移除一份补充材料。
