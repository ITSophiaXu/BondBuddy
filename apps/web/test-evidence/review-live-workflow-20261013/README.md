## 手动验收

新版纳入本地入口后，在复核材料页检查左侧对齐，输入要求并点击“开始复核”，应直接进入“正在复核”。观察扣费及可用余额、复核日志，刷新应保持同一任务；暂停后扣费停止、继续后续跑。零余额时出现充值入口，补充积分后保留原处理结果。已有任务沿用开始时的计费规则，动态计费只适用于新版创建的完整/差异复核。

本次无新增数据库迁移或依赖。API 和 worker 必须一同更新。现有本地任务运行时不能直接换 worker；在任务结束后（或用户明确同意结束该任务后）切换，再补真实本地入口验证与版本清单。
