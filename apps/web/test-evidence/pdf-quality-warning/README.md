# PDF 扫描清晰度提醒

关联需求 #1584，Refs #1567。用户于2026-11-18要求检测上传PDF分辨率并提示更换材料。原型：`product-prototype/public/pdf-quality-warning.html`；实现：`apps/web/src/material-processing.ts`、既有`material-processing.css`。原型与实现属于本PR同一提交，基线develop为92221bf331ebf0e2eed138f8921d888944e77209。

截图为1440×900及390×900同尺寸组件对照。真实Vite模块中的MaterialProcessing读取合成API结果并渲染；浏览器验证具体页码、更换建议、部分覆盖说明及无横向溢出。均为synthetic，不冒充真实上传/模型生成。只增加现有材料行的提示，不增加页面、步骤或导航；无布局偏离。真实持久化和权限另由PostgreSQL/Azurite用例验证。

Windows原件探测：东营107页，8.906秒完成；第5—15、98—102页约144 DPI，第103—107页约150 DPI。Linux受控容器：遵守18秒内部/20秒外部预算，完成前55页，识别第5—15页144 DPI；返回部分检查，不声称全文通过。原件SHA保留在原样本清单，未将客户正文或截图加入本目录。
