# 文件生成选项取消分组

2026-10-30。用户在本次会话明确要求去掉“其他文件类型”，文件选项不再分类。此要求是相对于旧原型的本次布局变更确认。

实现提交：`77d9eb0c`，基于 `develop` 的 `6819bb742bc650e4b5dd10d70ebe1571e1487f0e`。实现文件为 `apps/web/src/file-generation-panel.ts` 和同名 CSS。

- 尽职调查底稿包与公共文件目录的 12 个选项统一显示在一个网格内，无主次分组、分隔线或折叠入口。
- 文件按公共目录顺序排列；说明文案改为“可以同时选择多种文件，使用同一份募集说明书”。
- 多选、保存、模板配置、费用和生成逻辑沿用现有实现。无新增依赖、接口或数据库迁移。
