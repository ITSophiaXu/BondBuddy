## 验证

运行环境：Windows，Node 22+，本工作区的 Vite `127.0.0.1:5187`，Playwright + Edge。页面使用合成 HTTP fixtures；没有生产连接、实际模型调用、真实扣费或真实 Word 生成。

- 按依赖顺序编译 contracts、domain、rule-pack-registry、rule-applicability-context、API、worker；Web TypeScript 和 Vite build 通过。Vite 原有大包体提示保留。
- 合约测试 72 项通过；179 份公开合成示例、12 份内部资料库示例、4 份生命周期示例通过。
- 六组相关浏览器套件共 94 个场景：首次 93 项通过；旧“延迟轮询”测试错误地在上传进度重绘前设置 DOM 标记，已改为在上传等待期间设置标记，以单独验证延迟 GET 不覆盖准备内容。该场景与 5 个受最后调整影响的场景定向复验，6 项全部通过。
