## 复现

从仓库根目录安装依赖、构建并运行公共样例及表单测试：

```sh
npm ci
npm run build
npm run check:contracts
npm run test:unit -w @bondbuddy/web
```

按 `apps/api/README.md` 创建独立 PostgreSQL 16 测试库，设置 `DATABASE_URL` 运行全部迁移（含 `0013_m1_update_project_details.sql`），再用同一库设置 `BB_TEST_DATABASE_URL`：

```sh
npm run migrate:api
node --test apps/api/dist/update-project.test.js
```

测试使用唯一合成 owner；输入快照不可删除，记录保留在可整体销毁的测试库中。不要指向生产数据库。启动真实 API 和 `apps/web` 后，用合成账号按表中步骤验收；账号、密码和数据库文件不入库。
