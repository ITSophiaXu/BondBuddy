# 审计报告科目之间的勾稽关系.docx

[S009:1] 审计报告科目之间的勾稽关系
[S009:2] 一、资产负债表内部勾稽关系
[S009:3] （一）基本恒等式（核心）
[S009:4] 第1项：会计恒等式
[S009:5] 资产 = 负债 + 所有者权益
[S009:6] （二）大类汇总勾稽
[S009:7] 第2项：流动资产汇总
[S009:8] 流动资产合计 = 货币资金 + 交易性金融资产 + 应收票据 + 应收账款 + 应收款项融资 + 预付款项 + 其他应收款 + 存货 + 合同资产 + 一年内到期的非流动资产 + 其他流动资产（各明细科目相加）
[S009:9] 第3项：非流动资产汇总
[S009:10] 非流动资产合计 = 债权投资 + 其他债权投资 + 长期应收款 + 长期股权投资 + 其他权益工具投资 + 投资性房地产 + 固定资产 + 在建工程 + 使用权资产 + 无形资产 + 商誉 + 长期待摊费用 + 递延所得税资产 + 其他非流动资产（各明细科目相加）
[S009:11] 第4项：资产总计
[S009:12] 流动资产合计 + 非流动资产合计 = 资产总计
[S009:13] 第5项：流动负债汇总
[S009:14] 流动负债合计 = 短期借款 + 交易性金融负债 + 应付票据 + 应付账款 + 预收款项 + 合同负债 + 应付职工薪酬 + 应交税费 + 其他应付款 + 一年内到期的非流动负债 + 其他流动负债（各明细科目相加）
[S009:15] 第6项：非流动负债汇总
[S009:16] 非流动负债合计 = 长期借款 + 应付债券 + 租赁负债 + 长期应付款 + 预计负债 + 递延收益 + 递延所得税负债 + 其他非流动负债（各明细科目相加）
[S009:17] 第7项：负债合计
[S009:18] 流动负债合计 + 非流动负债合计 = 负债合计
[S009:19] 第8项：所有者权益合计
[S009:20] 所有者权益合计 = 实收资本（股本）+ 资本公积 + 其他综合收益 + 专项储备 + 盈余公积 + 未分配利润
[S009:21] （三）具体科目之间的勾稽
[S009:22] 第9项：固定资产净值
[S009:23] 固定资产净值 = 固定资产原值 - 累计折旧
[S009:24] 第10项：固定资产账面价值
[S009:25] 固定资产账面价值 = 固定资产原值 - 累计折旧 - 减值准备
[S009:26] 第11项：在建工程转固
[S009:27] 在建工程期末余额 = 在建工程期初余额 + 本期增加 - 本期转入固定资产 - 本期其他减少
[S009:28] 第12项：无形资产账面价值
[S009:29] 无形资产账面价值 = 无形资产原值 - 累计摊销 - 减值准备
[S009:30] 第13项：应收账款净额
[S009:31] 应收账款净额 = 应收账款账面余额 - 坏账准备
[S009:32] 第14项：其他应收款净额
[S009:33] 其他应收款净额 = 其他应收款账面余额 - 坏账准备
[S009:34] 第15项：存货净额
[S009:35] 存货净额 = 存货账面余额 - 存货跌价准备
[S009:36] 第16项：长期股权投资
[S009:37] 长期股权投资账面价值 = 初始投资成本 ± 损益调整 ± 其他综合收益调整 ± 其他权益变动 - 减值准备
[S009:38] 第17项：未分配利润（表内）
[S009:39] 未分配利润期末余额 = 未分配利润期初余额 + 本期净利润 - 提取盈余公积 - 分配股利/利润
[S009:40] 二、利润表内部勾稽关系
[S009:41] （一）利润形成链条（核心）
[S009:42] 第18项：营业利润
[S009:43] 营业利润 = 营业收入 - 营业成本 - 税金及附加 - 销售费用 - 管理费用 - 研发费用 - 财务费用 + 其他收益 + 投资收益（损失以"-"号填列）+ 公允价值变动收益（损失以"-"号填列）- 信用减值损失 - 资产减值损失 + 资产处置收益（损失以"-"号填列）
[S009:44] 第19项：利润总额
[S009:45] 利润总额 = 营业利润 + 营业外收入 - 营业外支出
[S009:46] 第20项：净利润
[S009:47] 净利润 = 利润总额 - 所得税费用
[S009:48] （二）其他表内勾稽
[S009:49] 第21项：毛利
[S009:50] 毛利 = 营业收入 - 营业成本
[S009:51] 第22项：主营业务收入与成本配比
[S009:52] 主营业务收入与主营业务成本之间通常存在一定的配比关系
[S009:53] 第23项：净利润归属
[S009:54] 净利润 = 归属于母公司所有者的净利润 + 少数股东损益
[S009:55] 第24项：综合收益总额
[S009:56] 综合收益总额 = 净利润 + 其他综合收益税后净额
[S009:57] 三、现金流量表内部勾稽关系
[S009:58] （一）基本勾稽（核心）
[S009:59] 第25项：现金净流量
[S009:60] 现金净流量 = 现金流入 - 现金流出
[S009:61] 第26项：现金及现金等价物净增加额
[S009:62] 现金及现金等价物净增加额 = 经营活动现金流量净额 + 投资活动现金流量净额 + 筹资活动现金流量净额
[S009:63] 第27项：期末现金余额
[S009:64] 期末现金及现金等价物余额 = 期初现金及现金等价物余额 + 现金及现金等价物净增加额
[S009:65] （二）间接法勾稽（重要）
[S009:66] 第28项：间接法核心
[S009:67] 经营活动现金流量净额 = 净利润 + 不影响经营活动现金流量但减少净利润的项目 - 不影响经营活动现金流量但增加净利润的项目 + 与净利润无关但增加经营活动现金流量的项目 - 与净利润无关但减少经营活动现金流量的项目
[S009:68] 第29项：间接法展开
[S009:69] 经营活动现金流量净额 = 净利润 + 资产减值准备 + 信用减值损失 + 固定资产折旧 + 无形资产摊销 + 长期待摊费用摊销 + 处置固定资产/无形资产/其他长期资产的损失（收益以"-"号填列）+ 固定资产报废损失（收益以"-"号填列）+ 公允价值变动损失（收益以"-"号填列）+ 财务费用（收益以"-"号填列）+ 投资损失（收益以"-"号填列）+ 递延所得税资产减少（增加以"-"号填列）+ 递延所得税负债增加（减少以"-"号填列）+ 存货的减少（增加以"-"号填列）+ 经营性应收项目的减少（增加以"-"号填列）+ 经营性应付项目的增加（减少以"-"号填列）
[S009:70] 四、三张报表之间的勾稽关系
[S009:71] （一）资产负债表 ↔ 利润表
[S009:72] 第30项：净利润与未分配利润（证监会表述）
[S009:73] 资产负债表年初数"未分配利润" + 利润表中本年累计数"净利润" = 资产负债表期末数"未分配利润"
[S009:74] 第31项：净利润与未分配利润（含分配）
[S009:75] 期末未分配利润 = 期初未分配利润 + 本期净利润（± 以前年度损益调整）- 提取盈余公积 - 分配股利/利润
[S009:76] 第32项：动态会计方程
[S009:77] 资产 + 费用 = 负债 + 所有者权益 + 收入
[S009:78] （二）资产负债表 ↔ 现金流量表
[S009:79] 第33项：现金及现金等价物（证监会表述）
[S009:80] 现金流量表中的"现金及现金等价物净额" = 资产负债表中的"货币资金"期末金额 - "货币资金"期初金额（企业不存在可划分为现金等价物的短期投资及不影响变现的定期存款时）
[S009:81] 第34项：期末现金余额
[S009:82] 现金流量表"期末现金及现金等价物余额" = 资产负债表"货币资金"期末余额（须扣除受限货币资金）
[S009:83] 第35项：受限货币资金
[S009:84] 资产负债表"货币资金" - 现金流量表"现金及现金等价物" = 附注中"受限货币资金"
[S009:85] 第36项：扩展恒等式
[S009:86] 现金及现金等价物净增加额 + 非现金资产净增加额 = 负债净增加额 + 所有者权益净增加额
[S009:87] 第37项：现金净增加额推导
[S009:88] 现金及现金等价物净增加额 = 负债净增加额 + 所有者权益净增加额 - 非现金资产净增加额
[S009:89] （三）利润表 ↔ 现金流量表
[S009:90] 第38项：净利润→经营现金流（间接法）
[S009:91] 净利润 ± 经营活动非现金的资产和负债的变化 = 经营活动现金流量净额
[S009:92] 五、附注与报表之间的勾稽关系
[S009:93] （一）税费勾稽
[S009:94] 第39项：支付的各项税费
[S009:95] 支付的各项税费 = 附注中应交税费本期减少 + 直接计入管理费用中的税费
[S009:96] （二）薪酬勾稽
[S009:97] 第40项：支付给职工的现金
[S009:98] 支付给职工以及为职工支付的现金 = 附注中应付职工薪酬本期减少 + 直接计入管理费用中的与职工相关的费用 + 支付的个人所得税
