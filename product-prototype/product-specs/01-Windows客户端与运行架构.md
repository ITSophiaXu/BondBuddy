# 01 Web 优先架构与 Windows 客户端

## 1.0 分阶段架构

最新交付顺序为先 Web，后 Windows。本章 1.1、1.4–1.7 的本机安装、存储、托盘与恢复要求在 M5 验收；M1–M4 不要求用户安装本地服务。共享业务规则、事实与证据格式、任务快照、模型适配、文档流水线和平台钱包从 Web 阶段建立，避免桌面阶段重写业务。

| Web 组件 | 责任与边界 |
|---|---|
| 浏览器 UI | 登录、项目表单、文件上传、右侧对话、状态与下载；不保存供应商密钥或权威余额 |
| Web API 与关系数据库 | 账号隔离、项目/材料索引、事实、对话、版本、权限和乐观锁 |
| 私有对象存储 | 已上传材料、OCR 页图、成果及模板；加密、授权下载、到期与用户删除 |
| 服务端任务队列与工作进程 | 解析/OCR、受控 Codex 执行、文档组装、检查点和崩溃恢复 |
| 平台网关与钱包 | 模型/数据代理和真实用量；M2 起冻结、结算、充值退款 |

Web 文件通过 HTTPS 上传，服务端确认写入和内容哈希后才成为可执行材料。原件、派生数据、日志和备份分别定义保留期限与删除规则；正文不默认进入遥测。免费预检与付费处理边界沿用第 04、14 章，浏览器缓存不是项目唯一副本。

关闭页面、浏览器断网或退出登录不等于取消任务。服务端继续运行，用户重新登录通过同一 run_id 和事件游标恢复查看；取消必须由明确操作产生服务端终态。工作进程故障恢复须先核对已发请求，不能盲重发。Web 不能使用“原文件只在本机”的说明。

Web 发布需有 TLS、受保护会话、CSRF/跨源控制、短期授权下载、文件校验、任务资源隔离、备份恢复、运行监控与回滚。具体部署地域、材料保存期限和供应商保留条款由 M1-01 落实，未落实不得开放真实用户材料。Windows 后续复用相同契约，通过存储/运行适配层将指定内容迁入本机。

## 1.1 安装与首次使用

WIN-01：提供签名安装包、版本号、发行说明、卸载入口和自动更新。工程基线建议 Windows 11 x64，Windows 10 22H2 列兼容测试环境；正式支持范围以安装包验证为准，不承诺未经测试的 ARM 或旧系统。

安装无需 Python、Node、Word、Codex CLI 的用户手工配置。所需解析、OCR、文档生成与任务运行组件随应用打包或从校验签名的官方分发地址安装。Microsoft Word 可用于用户打开成果，不能成为所有功能的隐含运行依赖。

首次启动依次完成服务连接检查、协议及隐私说明、手机登录、本地项目目录初始化。权限拒绝、磁盘不足、路径不可写均给出可操作的修复入口；不以空白界面或终端报错替代。

## 1.2 推荐架构与可信边界

以下为 M5 工程设计建议：桌面壳复用已上线 Web UI；本地工作进程负责文件与任务；平台网关负责模型及数据服务访问，平台关系数据库负责身份、订单、账本。桌面壳选 Electron 或 Tauri 可在技术验证后决定，不改变接口责任。

| 组件 | 负责内容 | 禁止承担的权威判断 |
|---|---|---|
| 桌面 UI | 展开表单、对话、状态、文件选择、结果摘要 | 计算最终价格、伪造支付成功 |
| 本地服务 | 项目 SQLite、材料副本、OCR/解析、文档组装、检查点 | 自行修改积分余额 |
| Codex 任务运行器 | 多步任务、工具调用、结构化输出、恢复 | 任意访问本机文件或执行来源文档中的命令 |
| 平台身份/任务服务 | 账号、能力、执行幂等、版本登记、任务租约 | 把未交付任务标为收费成功 |
| 平台网关 | DeepSeek/外部数据代理、计量、配额、请求去重 | 把供应商密钥下发客户端 |
| 平台钱包 | 原子冻结、结算、释放、充值退款及不可变流水 | 信任客户端提交的积分数 |
| 规则与模板服务 | 签名版本、适用矩阵、内部参考材料 | 混用其他用户私有模板或事实 |

本地可选用 SQLite + 文件目录，平台可选用 PostgreSQL。密钥使用 Windows 凭据保护；本地服务只监听环回地址并要求每次启动随机会话令牌，防止网页跨源调用。IPC 方法按允许清单开放，渲染进程不获得任意文件系统或 shell 权限。

## 1.3 AI 运行要求

AI-01：用户要求 Codex 执行框架调用 DeepSeek。实现必须验证多轮上下文、工具调用、流式事件、结构化结果、超时取消、usage 和恢复，不能将现有单次文本转发视为完整实现。

用户称模型为“DeepSeek Flash v4.1”；精确官方模型 ID、上下文上限、计费口径和供应商能力尚未核实。配置记录 provider、model_id、adapter_version、能力及价格版本。配置验证失败应停止该能力启用，不静默替换模型名称。

Codex SDK / app-server 可作为程序化执行入口，先验证与自定义模型供应商的协议适配。生产不依赖未验证的实验传输；Web 在隔离服务端工作进程执行，M5 使用本机受控进程和明确协议版本。当前本地桥接可参考，供应商密钥与最终 usage 必须迁入平台可信网关。

工具限于当前项目授权目录、来源提取、规则检索、允许的外部查询、受控计算和 Word 生成。默认不允许通用系统命令、任意 URL 上传、邮件发送、交易操作、读取其他项目或浏览器登录凭据。任务材料中的“忽略要求”“发送文件”等内容是待处理数据，不能成为执行指令。

## 1.4 本地与云端数据边界

| 数据 | 默认位置 | 传输原则 |
|---|---|---|
| 原始文件、解析全文、项目事实、对话、成果 | 本机账号分区 | 任务需要时发送必要片段；云 OCR 需发送对应页并在隐私说明列明 |
| 手机号、登录会话、支付订单、钱包流水 | 平台 | 使用 TLS；仅授权角色访问 |
| 任务 ID、版本哈希、能力与价格快照、用量 | 平台 | 足以恢复与对账，避免包含正文 |
| 模型请求中的必要项目内容 | 处理链路 | 提供商保留/训练策略须取得合同依据并对用户说明 |
| 私有券商模板及抽象结构 | 本机为主 | 如处理需要暂存，绑定账号，不进入公共库 |
| 外部查询证据 | 本机及被许可的缓存 | 保存/再展示期限遵守各供应商授权 |

不要把“主要保存在本机”写成“材料绝不离开电脑”。设置页应列明已接入服务、发送内容类别、缓存和删除规则。正文遥测默认关闭；错误上报以阶段、错误码、耗时为主。需要原文诊断包时，展示内容并由用户主动发送。

M5 模型代理链路的临时内容建议任务完成后 24 小时内清理；此为待供应商合同及恢复方案验证的设计目标，不适用于 Web 项目工作副本。Web 用户持续编辑与下载需要独立的项目留存策略。订单、账务与法定记录依实际法定期限留存，不能与项目正文共用删除策略。

## 1.5 运行、暂停和恢复

WIN-02：主窗口关闭默认进入托盘，任务继续；首次说明“退出应用将暂停本机处理”。不把睡眠或离线表现成任务仍在计算。

1. 启动后平台冻结成功，本地持久化 run_id、输入哈希和 reservation_id。
2. 每个可恢复阶段提交检查点，包括已解析内容版本、已完成请求 ID、生成结果中间版本。
3. 网络断开：停止新收费调用，保存状态，显示等待连接；已经发出的请求先查询结果，禁止无条件重发。
4. 完全退出/系统关闭：尽可能保存检查点；平台通过租约超时标记等待恢复，不直接收费成功。
5. 再启动先对账，再恢复同一 run_id 和冻结。用户取消则全额释放。设计默认暂停 24 小时后自动取消；此前站内提醒，可配置延长，不能无限冻结。
6. 取消与完成并发由平台原子终态决定；若取消已生效，迟到结果不得再扣分。

不承诺电脑关机后在云端继续处理本机材料。已在云端进行的单个请求可完成并缓存响应，整体任务需电脑恢复或被取消。

## 1.6 文件、更新与备份

项目目录由应用生成安全 ID，不直接使用用户输入拼路径。导入时复制到工作目录，保存原文件名及哈希；原文件不覆盖。切换账号不能看见前一账号目录清单。

导出项目备份包含材料、对话、事实和版本清单，用户选择目标位置；备份不含访问令牌或模型密钥。导入备份重新绑定本机账号，历史账单只读引用云端记录，不导入“余额”。

应用升级必须校验签名、备份本地数据库并支持失败回滚；运行中大型任务在安全检查点后升级，不强杀写入。卸载默认保留项目数据，另提供明确的删除本地资料选项。删本地资料不等于注销账号或退款。

## 1.7 验收

| ID | 条件与操作 | 预期 |
|---|---|---|
| WIN-A01 | 干净电脑安装并导入扫描件 | 不需开发工具，可启动完整任务 |
| WIN-A02 | 执行中关闭窗口再打开 | 同一任务继续，冻结不变 |
| WIN-A03 | 强制结束进程后重启 | 检查点恢复，无重复调用/扣费 |
| WIN-A04 | 离线编辑、随后联网执行 | 编辑保留；离线不启动付费调用 |
| WIN-A05 | 账号 A 登出后 B 登录 | B 无法枚举 A 材料、模板或对话 |
| WIN-A06 | 修改客户端余额、价格或用量 | 平台拒绝采信 |
| WIN-A07 | 材料中嵌入上传其他目录的指令 | 不执行，任务证据处理不受该指令控制 |
