# 03 首页与项目管理

## 3.1 导航与首页

HOME-01：主导航依次提供首页、更新募集书、复核募集书、材料生成、QA 问答；全部项目入口与账号/积分/设置保持稳定。普通用户端不出现募集书库、蓝图推荐、内部业务匹配结果。

以上是完整产品导航。M1 仅开放已验收的更新入口和项目内对话，M2 增加钱包/充值，复核及材料/独立 QA 分别按后续里程碑开放。未上线入口隐藏或明确不可执行，不显示虚假余额、成果或演示数据。

首页先展示用户的项目和可继续的工作，提供四个核心功能入口。推荐结构：

1. 顶部简短欢迎信息、可用积分和充值入口。
2. 四张任务入口卡，描述分别为全文更新、三维复核、五类文书、债券专业问答。
3. 运行中/待补材料的工作，可恢复至正确位置。
4. 最近项目与最近成果，展示类型、发行人、更新时间、状态。

不以宣传横幅、充值套餐或内部资源库占据主要首屏。统计区按 update、review、generation、qa 独立计数，不把 QA 和材料生成归为一个“生成”数。

## 3.2 项目列表与详情

| 项目属性 | 展示/规则 |
|---|---|
| 名称 | 可编辑；为空可由发行人+任务类型生成 |
| 类型 | 更新、复核、材料生成；QA 会话单独管理，可关联项目 |
| 发行人 | 已填/已识别全称，主体冲突需标记 |
| 市场与品种 | 识别或用户选择的当前值，不显示未经确认的猜测 |
| 状态 | 草稿、待补材料、处理中、等待恢复、已完成、失败、已取消 |
| 最近成果 | 最新成功版本、生成时间、下载 |
| 存储位置 | Web 云端工作区；M5 本机项目标明所在设备，不在本机的文件不可伪装可下载 |

列表支持名称/发行人搜索、类型及状态筛选、最近修改排序；空状态提供创建入口。工作进程与平台状态短暂不同步时显示“正在同步”，不以刷新将进行中任务变成新草稿。

项目详情左侧为结构化信息及材料，右侧为对话。完成后增加结果摘要、下载区、历次成果和账单入口。没有应用内逐条 Word 接受/拒绝 UI。

## 3.3 项目、版本、任务关系

PRJ-01：一次项目可以多次执行。每次执行锁定项目字段、材料文件哈希、对话需求版本、规则/模板版本及输出目标。编辑不改变已运行任务的输入。

运行时允许查看与编辑“下一版草稿”；明确提示“修改将在下一次执行时生效”。同一项目避免同时两个写作任务竞争“最新成果”，设计默认串行执行；跨项目云端钱包仍做并发保护。

用户在 Word 中自行修改后，如需继续处理，应导入该文件为新的输入基线，系统显示其与上次成果不同。不能认为本地导出文件被编辑后项目事实已经自动更新。

成功版本具有 v1、v2 等可读名称，并保存不可变 artifact_id、哈希及来源快照。旧版本不覆盖。下载失败可重试，重新导出同样内容免费；改变内容属于新任务或平台纠错。

## 3.4 项目操作

| 操作 | 规则 |
|---|---|
| 创建/重命名/修改字段 | 免费，自动保存；Web 提示服务端保存状态，M5 提示本机保存状态 |
| 复制项目 | 新项目 ID，可复用同账号材料解析；不复制冻结或消费记录 |
| 归档 | 隐藏默认列表，仍可恢复、下载 |
| 删除 | 先处理运行任务；分别显示云端或本机材料/成果影响范围，保留法定云账本 |
| 关联材料生成 | 锁定所选成果版本，不随原项目后续变化漂移 |
| 关联 QA | 显示项目范围，可切换；不自动把所有项目全文放入上下文 |
| 从失败恢复 | 区分系统重试同任务与用户新需求重新执行 |

材料与模板有共享引用时采用引用计数/依赖清单；删除一个项目不应破坏其他项目已锁定的材料和成果。已成功版本至少保留可重建的来源快照，用户主动清理时告知后果。

## 3.5 结果摘要规范

更新摘要：处理范围、实际新增/替换期间、章节变化、多品种联动、材料冲突与待核实项、成果文件。

复核摘要：三类已执行范围、问题数量与级别、未覆盖项、资料截止日/查询时间、报告和批注文档。

生成摘要：文种、来源募集书版本、模板/券商、完成章节、待确认项、成果文件。

M2 起所有结果提供最终积分消耗和可用余额；结算对账中时显示“成果已生成，积分结算处理中”，禁止显示猜测的扣分。M1 受控试用不展示伪造账务。摘要不披露内部参考库条目或他人文件名。

## 3.6 验收

HOME-A01：新账号空状态能直接进入当前已开放任务；已存在项目的账号首先能找到项目。

HOME-A02：筛选、刷新、应用重启后状态一致，四种业务计数不混淆。

PRJ-A01：修改运行任务的草稿后，当前成果仍对应启动快照；下次执行才采用新值。

PRJ-A02：复制、归档、删除、恢复不会重新收费或破坏其他项目。

PRJ-A03：Web 同账号跨设备可访问云项目与云账务；M5 不得显示不存在于该设备且未显式迁移的本地文件为可下载。

## 3.7 通用交互规范

设计默认宽窗口左侧表单约占可用工作区 2/3、右侧对话约 1/3，对话最小宽度约 320px；低于约 1,100px 时切换上下布局，保持字段顺序和输入不丢失。具体断点由设计稿与可用性测试定，不把侧栏压到不可读。

所有输入有可见标签，示例使用 placeholder 且不作为真实默认值提交。必填、可选、金额单位、时点、错误文字直接可见；不只依赖颜色、悬停或小问号。输入错误定位到字段，保留其他内容。

支持键盘焦点、清晰聚焦状态、合理 Tab 顺序及 Windows 显示缩放；错误/进度变化向辅助技术提示。对话 Enter 发送、Shift+Enter 换行可作为默认，中文输入法候选确认不得误发送。

长任务按钮防重复点击，但不锁死全应用；用户仍可查看其他项目、取消任务及保存下一版需求。删除资料、注销、真实支付等有实质影响的操作需清楚展示对象；普通保存、导航和生成前不添加无意义确认。
