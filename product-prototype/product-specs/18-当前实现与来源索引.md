## 18.1 快照说明

仓库发布说明：本章“当前实现”和 47 项回归记录是本地 BondBuddy 的规格编写快照。本次提交范围为产品说明书，未把本地 DFI 应用代码一起提交到本分支。下方可用的源码链接指向本仓库版本；它们用于定位模块，不能单独证明本章所列全部功能已合入。尚未同步的 DFI 文件已标明，原始指纹见[本地来源记录](references/本地规格来源指纹-v1.1.json)。

本次在编写前和编写过程中读取当前工作区。产品主目录为 bondbuddy。本轮 DFI 修订时 package.json 为 1.9.0，服务已有积分 v1.1 标识；近期文档与代码正在迁移，不能用单一版本号判断所有功能。文件指纹及读取时的修改时间记录于 spec-manifest.json，后续代码变更不自动更新本文。

尤其是积分：早期调查看到月费套餐，后续读取已存在 credit-pricing、credit-wallet、credit-account 等本地积分原型。本说明书按最新观察更新实现清单，但没有将它当成生产可用服务，本次 DFI 修订已同步修改应用选项、项目上下文、内部处理指导、原稿识别及计费路由。

源码检查是实现证据，不等于已执行真实 API、支付、浏览器或专业成果验收。本次已运行 DFI 相关自动化回归（47 项通过）和 package.json 检查脚本所列的 32 个语法检查，并对说明书进行结构/链接/一致性检查。回归含模拟模型的 Word 导出，不代表真实模型或专业验收；未重新运行无关应用全套测试。

## 18.2 实现与目标差异

| 模块 | 已观察到的实现 | 首发还需完成 |
|---|---|---|
| 项目工作区 | 创建、材料分区、展开选填、市场联动、DFI 储架选项及条件提示、补充说明、项目恢复 | 真正多轮任务、目标版本接口、完整恢复 |
| 一键流程 | 前端已出现点击直接执行文案/流程；内部仍有旧 assessment/quote/confirm 状态 | 将旧状态收敛为后端内部准备，不保留用户报价门槛 |
| 账号 | 手机验证码演示与本地账号隔离 | 真实短信、云身份、会话/找回/注销 |
| 钱包 | 本地 JSON 批次、冻结/结算、示例费率、赠分/邀请/活跃、演示退款 | 生产事务账本、真实费率/用量、商户回调、对账与风控 |
| 计费分类 | 有新增期间差集、各业务系数与缓存拆分的原型 | N=0、实质重述证据、分工作项特殊加成及真实成本校准 |
| 计费默认 | 代码有示例模型名/参考费率与启发式分类 | 不把示例 DeepSeek 名称/价格当用户已定模型；能力及真实价格验证 |
| 材料 | DOCX/PDF/XLSX/CSV/TXT、文件进度、提取记录 | 4320 主应用的扫描 OCR、图片、复杂跨页、低置信确认、容量扩展 |
| Word 输出 | 可编辑文档、修订及批注生成工具 | 基于历史有效原文逐处修订、接受/拒绝还原校验、PDF 重建基线，以及完整章节/多品种/复杂表格/目录的保真验证 |
| 更新 | 工作量估计、源材料处理、内部业务匹配 | 全面事实模型、规则映射、N 与历史完整性可靠判断 |
| 后台参考募集书库 | 原型建库/导入设计与内部业务匹配入口 | M1-32 真实可用首批库、市场/方式/品种/三业务证据索引；M1-33 增量更新、审核发布与退役；旧用户端库页设计不作为上线要求 |
| 复核 | 三维范围展示、来源检查、规则/检索入口 | 确定性财务核对、完整格式规则、真实商业数据验证 |
| 行业库 | 交易所若干知识包，上交所私募有更细研究资料 | 大公募独立包，银行间正式规则，最新效力与专家验收 |
| 生成 | 五类章节提纲、立项私有模板、Word 输出 | 五类完整专业模板、输入缺口与程序证据约束 |
| 项目对话 | 多条说明收录、编辑与提交上下文 | 真实持续讨论、意图路由、工具调用与版本化改稿 |
| 统一使用日志 | 规格中已有任务状态及用量事件约定，尚未验收统一日志实现 | M1-34 的 prompt/job/call/token/error 全链路、持久化恢复、检索看板及限权清理；新增 issue 不代表功能已实现 |
| 外部查询 | Web/工商/连接器抽象及访问策略 | 启信宝、Wind、企业预警通真实授权接入 |
| 桌面形态 | 本地 Web 应用和启动方式 | 签名安装包、更新、托盘、安全 IPC、运行恢复 |

观察到的计费原型仍有与目标规则不同的启发式，例如 changedPeriods 最少取 1、某些跨市场/无稿默认重构、分类主要据入口/文字。这里作为待替换的实现差异记录，不要求工程沿用它们。

DFI 当前实现：更新/复核可选择 nafmii-dfi；服务器推导内部注册安排；恢复项目保留选择；原稿标题优先识别 DFI 与具体一期；银行间内部指导新增注册阶段和未定条款约束；无历史稿走既有材料与内部参考流程；材料生成继承/识别 DFI 上下文；计费采用 dfi-v1，不新增独立工具价或覆盖数量倍数。该实现尚不含现行 DFI 完整法规模型、可靠结构化阶段抽取和专业样本验收。

本轮官网页面的浏览器核验被自动审批服务错误阻断（model_not_supported），未将内部摘录升级为现行官方核实结果。浏览器交互截图亦未作为本轮验收证据。
