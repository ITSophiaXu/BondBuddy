# [M1] 网页版注册/登录与募集书更新上线

一个项目入口填写目标、上传发行人材料及可选原稿、保存补充要求；原始材料和目标知识 MD 直接交 worker 编制，保留修订版和清洁版。原稿可为同企业、母公司、子公司或相似业务企业，也可不上传。

## 上线门槛

按 UNIFIED-A01—09 验统一流程、真实编制及 Word；复用现有身份/上传/任务能力。没有历史稿、财务预提取或规则发布平台不构成启动前置，M1 成本由平台承担。

统一日志 {{M1-34}} 必须先于首个用户更新任务（含受控试用）开放：prompt、job 类型、每次调用/token、业务结果及错误可查询；日志缺失或未验收时禁止开启更新能力。

发布验收任务：{{M1-30}}

## 协作规则

- 子任务归入同一 GitHub milestone，并关联本跟踪 issue；优先认领依赖已满足的任务。
- 认领通过 assignee 或评论完成；PR 引用子任务，验收通过后关闭。
- 跟踪 issue 仅在全部必要子任务和发布门槛通过后关闭；不使用演示成功代替真实接入。
- 不设置未经团队确认的日期或个人负责人。
