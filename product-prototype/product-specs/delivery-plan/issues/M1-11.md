# [M1-11] 验证 Codex 框架调用 DeepSeek 的生产接入

里程碑：M1 · 建议角色：AI 工程师 · 优先级：P0

前置任务：无硬依赖，可先认领。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 核实用户指定模型的准确 API ID、协议和真实费率，不将示例模型名当成确认结果
- 验证多轮、工具、结构化输出、流式事件、取消、恢复和 usage
- 将密钥与请求计量放平台网关，工具限制在当前任务授权资源
- 从 M1 起每次真实模型尝试记录 call_id、provider_request_id、prompt 快照引用、模型/请求参数版本、耗时、finish_reason、分项 token 和 usage 状态，对接 M1-34；失败/重试也保留，原始消费不等于向用户扣费

## 验收标准

- [ ] 提交真实接口兼容记录及匿名 usage 样本，失败明确列阻碍
- [ ] 无效 JSON、超时、断流和工具拒绝有稳定恢复路径
- [ ] 材料中的指令不获得 shell、任意文件、跨项目或任意外传权限
- [ ] 成功/超时/取消/重试均可按 trace 关联调用；流式缺最终 usage 标 pending/unknown，不能填 0 或仅报估算

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
