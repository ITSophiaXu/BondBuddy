# [M5-12] 扩展模板库管理、公募摘要及市场/机构适用范围

里程碑：M5 · 建议角色：服务端工程师 + 行业专家 + AI/文档工程师 · 优先级：P1

前置任务：{{M4-02}}、{{M4-03}}、{{M4-07}}、{{M4-11}}。各扩展与对应文种模板/编制能力联调：主承销商核查意见 {{M4-04}}、法律意见书 {{M4-05}}、推荐函 {{M4-06}}；其专业实现可并行，不反向要求它们在本 issue 基础管理能力开始前全部完成。专业最终验收归 {{M5-11}}。

本 issue 为本地 review 新增稿，尚无 GitHub issue 编号；不预设个人负责人或截止日期。

## 目标与范围

- 按[2026-10-06 M4/M5 优先级拆分](../../../../docs/product-decisions/2026-10-06-m4-m5-priority-split.md)，承接 M4 首发两文种以外的模板管理及适用范围。复用 BondBuddy 当前工作区和常驻助手，实际编制继续由现有 worker 的 Codex CLI 执行。
- 完整管理平台/私人模板：同用户、同券商、同文种的本人有效模板自动匹配建议、准确旧/新版选择、默认版本、上传新版及删除/退役。自动建议展示匹配理由/适用性并保留用户显式选择，不能把“最近”覆盖已选旧版。首发上传/选择能力由 M4-02 保留，不因延期管理要求重新建设一套数据模型。
- 模板作用域、原件/结构/授权/hash、章节/字段/表格/样式、市场/发行方式/用途、券商、适用日期和正式发布记录完整可追溯。保留同授权作用域内容去重，不能跨账号泄漏私有模板存在性、名称、结构或统计；未批准、过期、错市场或结构不可读提供具体原因/修复，不静默替换。
- 修改默认、上传新版、删除/退役只影响可选状态及新草稿，不能换掉运行中快照或重写旧成果。历史固定引用按已确认保留/授权策略回查，权限撤销立即生效；无法合法读取时明确原因，不用缓存绕过。删除/退役的引用关系和恢复路径须有审计，不以“删模板”静默损坏历史任务。
- 小公募和大公募募集说明书摘要 G06 分别匹配准确源稿、适用模板/规则，形成独立完整正文及编制说明。小公募保留专业投资者条件，大公募独立确认普通投资者相关要求、重要提示、风险和发行条件，不能回退小公募。保留 M4 普通私募 G05 的完整忠实性、准确来源锚点、审计意见、重大风险、条件及数字约束。
- 摘要类型与源稿冲突先确认来源/任务，不暗中转换募集书；银行间/DFI 不因此新增“DFI 摘要”文种、独立工具费率或必备摘要承诺。若实际要变更整份募集书市场/品种，承接至更新业务。
- 立项报告、主承销商核查意见、法律意见书、推荐函按实际规则/模板扩展沪深小公募/大公募及银行间适用范围，文件身份、市场/用途/申报对象/机构角色正确变化，不能只换标题或地名。适用性未确认的分支保持未开放，有已有资料也不生成错误文书。
- DFI 四文种分别判断注册安排、统一注册申报或具体一期的实际用途，明确注册文件、覆盖工具、有效期间/限制、授权/决议、实际一期条款、已完成程序和缺口。立项稿说明本次立项对象；核查意见分注册/一期程序和结论；法律意见分注册/一期法律用途和事实；推荐函分协会文本、申报对象、推荐范围及签署主体。受理、注册完成及已发行不同，不伪造已完成程序；DFI 不是额外独立工具费率。
- 多主承销商按实际牵头/联席/其他职责确认共同或分别出具；各机构事实、程序、推荐/签署权限及证据分别追溯，不能给只有一家记录的其他机构代作声明。单承销商不追问无关机构信息；分别出具多文件复用 {{M5-08}} 的组合/失败重试/一次结算契约，不静默只交一份或增加隐性费率。

## UX、执行与版本

- 用户先选文种，再仅展示当前文种/市场/用途实际需要的模板、阶段或机构字段；DFI 或多承销商信息仅在相关场景由助手澄清并回填，不新增普遍必填大问卷或补充意见 textarea。
- 自然字段更正覆盖原值，写作要求与系统默认规则区分，切文种保留各自草稿且专属证据/要求不串用。补齐只保存，明确执行才启动；未开放/不适用信息清晰，材料与草稿保留。
- 锁定准确来源/采用清单、模板/规则版次、文种/市场、注册或一期用途、机构职责及要求，制作中新增材料/更改模板进新任务草稿。工作区显示“正在制作”，助手显示实际执行事件，正文/说明独立 artifact tab，保留旧版本及阅读位置。
- 注册信息保存、模板上传/去重/选择/默认管理和已有文件重新导出不启动编制或另收生成费用；实际任务沿用原 G01～G06/工具类别及现有账务契约，不发明新价。

## 验收标准

- [ ] 私人模板旧/新版、自动建议、默认、删除/退役均有准确版本/理由；本人选择旧版不被自动新版覆盖，当前运行及旧成果不换版，历史引用状态可回查，撤销权限不越权。
- [ ] 同券商用户 A/B 模板全面隔离，重复同内容复用准确版次，同名不同 hash 可辨；过期、市场/文种不匹配、结构不可读分别保留草稿并显示原因，研究/测试模板不冒称已批准。
- [ ] 小公募和大公募各用匹配源稿生成完整 DOCX 与独立编制说明，分别有真实专业验收样例；大公募不由小公募或合成摘要替代，投资者范围、重大风险、审计意见、数字/条款、源版本均准确。
- [ ] 同一私募稿请求公募摘要先处理冲突，不转换源稿；银行间/DFI 请求交易所摘要时说明适用性和正确业务入口，不生成“DFI 摘要”或声称注册必备。
- [ ] 四文种的 DFI 注册/一期用途、覆盖工具、注册有效期间、授权、条款和阶段程序一致；受理不写注册完成，注册安排不写已发行，银行间文本无交易所挂牌措辞残留。
- [ ] 两家承销商只有一家真实程序记录，不代另一家声明已履行程序；共同/分别出具时各机构职责、正文/说明集合和签署主体正确，分别出具遵循组合全范围交付/结算，单一机构不被追问无关名单。
- [ ] 沪深私募/小公募/大公募及银行间扩展分别有适用性、正式模板/规则及独立实质结果，跨市场不只替换标题，不把内部阈值当市场规则、不虚构机构签发。
- [ ] 运行中修改模板默认/上传新版/补充机构资料不改变固定输入；刷新和恢复采用原准确版次及真实任务/账务，不重新编制或收费。删除/退役不能导致静默清空草稿/历史。
