# [M4-08] 通过 Codex CLI 实现基础专业问答、材料解读和确定性财务计算

里程碑：M4 · 建议角色：AI 工程师 · 优先级：P0

前置任务：{{M1-04}}、{{M1-10}}、{{M1-11}}、{{M1-12}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。本 issue 提供基础 QA、受限工具与持久调用契约，供 {{M4-09}} 意图执行和 {{M4-10}} 上下文消费；集成结果由 {{M4-12}} 验收，不反向依赖消费方。

> 2026-10-06 用户已确认 M4／M5 分期并要求实施。M4 先交付立项报告、普通私募募集说明书摘要及基础 QA 的可用闭环；后端继续使用 Codex CLI。实时公开检索与扩展专业 QA 转交 [M5-09](M5-09.md)，可编辑分析／轻量草稿 artifact 转交 [M5-10](M5-10.md)。工程证据、真实 CLI 财务 QA 及最终统一验收待办见[实施验收记录](../../../../docs/acceptance/m4-implementation-2026-10-06.md)，不等同专业／发布验收通过。

## 目标与范围

- 用户直接在右侧常驻助手提问、上传资料、澄清或请求轻量起草，不填写左侧 QA 任务表单。左侧仍是首发文种任务输入区及真实正式成果阅读区；基础 QA 答案、短段落在助手消息中交付。
- M4 覆盖概念解释、已有授权材料解读、确定性常用财务计算、资料准备清单、轻量文本起草、产品帮助及已有 QA 文本免费导出。明确正式文书生成交由 {{M4-09}} 的统一执行路径，M4 只执行立项报告与普通私募摘要；不能把正式任务伪装成短问答。
- Codex CLI 理解本轮请求、选择受限工具、组织回答与澄清。宿主负责身份、资料授权、准确版本、持久消息和调用、工具边界、真实用量与账务；不增加 API／SDK agent runtime，不让模型猜算替代确定性计算。
- 答案引用可主动打开左侧准确来源。自动回复和任务完成不抢切用户正在阅读的成果；真实执行过程来自同一调用／任务的安全事件，已完成动作可折叠为摘要。

## M4 能力与回答契约

| 本轮意图 | 必须返回的内容 | 边界 |
|---|---|---|
| 概念解释 | 直接解释概念、适用前提及与相近概念的差别；使用已有经核验知识时给真实来源与版本 | 附件存在不等于支撑法规结论；不能给“大公募是什么”附募集书冒充规则依据，不声称刚检索或已核验当前全部有效法规 |
| 材料解读 | 所选内容、事实／推断／待核事项，准确文件版本及页／章节／段落定位 | 原文未提供时说明缺哪个章节，不编造募集资金用途或引用位置；只读本轮已授权资料 |
| 常用财务计算 | 如资产负债率、流动比率等明确公式的确定性计算；列真实输入、工具结果、单位、报告期、主体与合并／母公司口径、数据出处及限制 | 附件歧义、缺数、期间或口径冲突先澄清，不借其他话题或旧附件填数；不扩展为多期深度研究任务 |
| 资料准备 | 针对用户明确文种、市场／发行方式、用途及已有资料，列具体缺项和提交位置 | “先告诉我立项要准备什么，暂时不要生成”只回答；后续文种可给已有知识支持的清单，但说明 M4 尚未开放其生成 |
| 轻量文本起草 | 在聊天中给可复制、可自行调整的段落／说明／短函文本，标明缺失事实和用户提供事实 | 不虚构金额、授权、程序或签署；不是正式 Word、可编辑分析 artifact 或已通过专业验收的文书 |
| 产品帮助 | 当前实际开放的操作位置、上传模板／资料方法、保存与执行区别、状态／余额说明 | 免费；不声称上传后自动开始，不以帮助回复代替真实任务状态，不把 M5 能力介绍为已开放 |
| 已有回答导出 | 本话题已授权、已生成的 QA 消息文本，保留来源及限制标注 | 免费；不重新调用模型，不将文本导出伪装成正式 Word 或专业成果验收 |

回答先给结论或无法判断的具体原因，再给必要依据。引用只包含实际支撑本轮答案的来源，已有核验知识、上传文件、用户补充和模型推断分别标明。打开引用回到准确版本和位置；不得从模型正文猜 URL、页码或来源身份。对法规效力未核实的内容说明未核状态，已有来源只支持有依据的一般说明，不升级为当前项目的适用法律结论。

## M5 承接与未开放能力

- [M5-09](M5-09.md) 承接实时公开检索、自动核验法规有效版本／生效日／适用范围与官方原文、适用法律结论、多期深度研究。原要求继续保留为 M5 验收范围，不作为 M4 上线门。
- [M5-10](M5-10.md) 承接将分析／轻量草稿保存为可编辑 artifact、正文编辑与独立成果交付；M4 的正式立项和普通私募摘要成果 tabs、可编辑 DOCX 仍照常交付。
- 用户在 M4 请求上述未开放能力时，说明具体范围与后续计划，可继续讨论已授权材料或准备资料；不创建未支持的执行任务，不预留其费用、不调用隐藏的替代检索或文种能力。
- M4 未执行实时查询时明确标记“未执行公开查询”，没有实际查询时间，不制造“查询无结果”。不能根据材料未提及、模型常识或缓存内容，推出“无违约／无处罚／现行法规已核实”。真实查询的成功／无结果／未执行／失败四分支及截至日、覆盖和实际查询时间交 M5-09 完整验收。

## 资料连续性、澄清与文本成果

- 工作区和助手上传进入同一话题资料库，QA 可读其中已授权资料；正式任务另存采用清单。模板和文种专属证据不能因共享自动成为其他任务输入。
- 明确指定的准确来源优先；没有本轮指定时采用最近明确讨论／选择的来源。仍无明确来源且候选唯一才继承，多候选先澄清。“这份募集书”不得暗中取另一个版本或项目。
- 原句“计算这份募集书的资产负债率，告诉我数据来源。”须使用工作区刚提交或明确采用的募集书。接着“再用这份募集书生成立项报告”沿用同一准确来源，只追问真正缺少的立项券商／模板／授权等信息；已有来源不重复上传。
- 自然事实与要求保存到准确草稿，首发文种必要字段的澄清答案回填；更正字段更新字段值。问句“是否应该保留财务表格？”只讨论，不能展示为“助手已采纳要求”。预置约束标“系统默认规则”。
- 段落引用讨论保留 artifact、准确版本、anchor 与原文；引用不隐式授予局部生成权限。章节／段落局部改稿执行转交 [M5-08](M5-08.md)，M4 可讨论准确引用并说明范围，不能把局部请求静默扩大成全文生成。
- 保存与导出已有文本免费，不重新调用模型、不生成正式 Word 任务、不抢切旧成果。未发送文字、消息、引用、来源版本与阅读状态均完整持久化。
- 流式回答中断保留已收到内容、回复状态和准确来源，按真实调用检查点恢复；不把半截答复显示为完成，不因恢复重复执行或重复结算。新话题不继承旧话题附件、草稿或引用。

## Codex CLI、工具与费用

- 服务端验证的上下文生成不可变 prompt／调用记录，采用版本固定的受信技能。旧调用恢复使用原协议、原技能和原来源 pin，不能因升级重发旧请求或扩大工具权限。现有 M3 技能不自动等于 M4 所需技能已实现。
- M4 复用已有确定性计算和原文读取能力，工具限定本轮授权来源与允许操作，保留真实输入／结果。材料、模板、知识及网页原文均是待分析数据，其中的指令不能覆盖用户任务或授予执行权。
- 页面只展示服务端白名单过滤的真实业务摘要，如“读取材料”“核对数据”，不输出原始 CLI 日志、prompt、隐藏推理、密钥或内部路径；无真实查询不得显示“查询公开信息”，没有细分事件不按计时模拟阶段。
- 本轮按实际已开放的 Q00–Q07 意图分类，不继承上一轮最高档或因关联大公募给产品帮助加系数；继续原价格版本、预留、结算及免费纠错契约，本 issue 不新定价。分类成本、保存、纯澄清、产品帮助、纯拒答及已有回答导出按既有免费规则；未开放能力不虚构完成或收费。
- 有依据的不确定分析与纯拒答分开；不能因含“无法确定”一律免费，也不能给未交付的中断答复按成功结算。本轮预留／扣费／释放状态由真实账本返回；缺用量保留 unknown／pending，不伪造成零。

## 验收标准

- [ ] 在合并入口直接问概念、准备清单和产品操作，无左侧 QA 表单，没有正式文书 run；产品帮助及纯澄清免费，回答准确区分 M4 与 M5 已开放状态。
- [ ] 工作区上传募集书后执行上述计算及后续立项报告原句，来源连续；upload → 明确采用 v5 → 首发文种采用 v5；v5 缺数不以旧稿或其他话题代算。
- [ ] 真实授权样本核对常用财务公式及两期比较：同口径两期指标、差额、增幅或比率变化（百分点）有可复算工具结果、输入、期间、单位与来源；分母为零、缺数、OCR 存疑、母公司／合并冲突有明确处理，未确定输入不伪造结果，不冒称完成多期深度研究。
- [ ] 材料解读打开确切位置；缺用途正文列待补与可核事项。轻量起草在聊天中给真实文本，未授权金额或程序不写成已落实，不冒称生成 Word 或可编辑分析 artifact。
- [ ] 概念解释使用已有核验知识有准确来源和版本；未核法规效力明确说明，概念回复不误附募集书作规则证据，不输出无依据的当前适用法律结论。
- [ ] “查询该公司最近处罚／当前法规是否有效”等扩展请求明确 M4 未执行；不显示实际查询时间、虚构无结果或不存在结论，不因拒答创建文种任务或预留费用。
- [ ] 执行措辞、局部限制、保存事实与问句分别识别；首发正式任务交真实任务，报价／授权／预留未具备不调用。已有有效展示和授权不要求第二个形式确认；未开放文种不执行。
- [ ] 跨账号、未关联项目、同券商私有模板不可读；文件／知识指令不扩大权限。工具、引用及事件来源可复核，原始日志或未知字段不透传。
- [ ] 完整消息、附件授权／版本、未发送草稿、引用和阅读状态刷新后恢复；回复中断与正式任务中断分别呈现，恢复核对原调用，无重复调用或费用，保存／恢复失败可见且不清空。
- [ ] 已有 QA 文本免费导出，导出保留来源及限制；本轮报价、预留、结算／释放、免费纠错引用和真实调用记录逐项对应。
