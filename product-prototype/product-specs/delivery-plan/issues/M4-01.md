# [M4-01] 交付材料生成工作区、来源选择和右侧对话

里程碑：M4 · 建议角色：前端工程师 · 优先级：P1

前置任务：{{M1-04}}、{{M1-07}}、{{M1-13}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 默认上传最新版募集书，第二选项关联本账号具体项目版本
- 五类材料入口、必要模板/补充资料分区和真实进度
- 右侧标题为补充说明与写作要求，支持多轮补充不隐藏主表单
- 本阶段对话须自行完成，不把已改为单行补充的 M1-13 当作真实助手/多轮能力已交付

## 验收标准

- [ ] 关联优先已完成更新稿，未完成稿明确实际来源
- [ ] 切换文种/来源不丢对话或挪用其他项目材料
- [ ] 注册/一期 DFI 背景保留，不把交易所摘要强套银行间

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。

- 认领时设置 assignee（权限不足请评论认领并请维护者分配），写明方案及依赖；完成后附 PR 与验收证据。
- 本 issue 不预设个人负责人或截止日期；多个成员可按组件协作，避免重复实现。
