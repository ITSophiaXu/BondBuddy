# [M4-02] 接入首发两文种模板、准确版次及私有隔离

里程碑：M4 · 建议角色：服务端工程师 · 优先级：P0

前置任务：{{M1-04}}、{{M1-08}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

本地实施：准确私有模板版本、hash 去重、交易所／券商提示及执行授权复验已接入；证据见[实施验收记录](../../../../docs/acceptance/m4-implementation-2026-10-06.md)。最终统一验收待办：授权券商模板、真实首发文种内容审核及生产环境隔离验证；远端 issue 尚未修改。

- 按[2026-10-06 M4/M5 优先级拆分](../../../../docs/product-decisions/2026-10-06-m4-m5-priority-split.md)，M4 只接入立项报告及交易所普通私募募集说明书摘要所需模板。保留平台与本用户私有作用域、模板原件、准确版本、来源授权、hash 及结构的可追溯关系，不能默认把用户模板变成平台资产。
- 解析章节树、字段、表格列和样式；将参考企业事实、签章、批注和个人信息与可复用结构隔离。参考案例中的文字、代码或外链不得成为 Agent 指令或执行授权。
- 首次立项上传本人可用券商模板/参考报告并保存为可再次选择的本人版本；再次使用可显式选择本人已上传的准确旧版或本次上传新版。M4 不建设独立模板库管理页，不自动挑选最近版本或设置默认；运行中的固定快照和历史成果不能因上传新版而换版。
- 模板元数据保留 `template_id`、准确 `version`、`owner_scope=platform/user`、`user_id`（私有必填）、`document_type`、市场/发行方式、券商、适用日期、来源授权、章节/字段/表格/样式和校验规则。正式平台模板须有专业确认及发布记录，章节提纲不能标为已验收模板。
- 完整个人模板库、自动匹配、默认版本管理、删除/退役生命周期及其他文种/市场模板移至 {{M5-12}}，不阻断上述两文种发布。模板使用权限撤销仍立即生效，不因管理功能延期允许越权读取。

## 最新 UX 与执行约束

- 遵循[2026-10-06 M4 Agent 工作区决定](../../../../docs/product-decisions/2026-10-06-m4-agent-workspace.md)：在“材料生成与问答”入口先选择文种，再只展示该文种所需模板及补充材料；纯问答在常驻助手完成，不新增问答任务表单。
- 立项报告首次使用某券商必须上传本人可用模板或参考报告。平台通用立项模板仅供结构/测试，不能绕过首次券商模板要求；普通私募摘要展示经批准且适用的平台模板或本人模板。其余文种/市场显示尚未开放，不生成不适用稿件。
- 模板选择展示名称、作用域、准确版次、市场/用途和有效状态。过期、市场/文种不匹配、结构不可读分别给出原因和修复动作；保留用户草稿，不静默换模板。
- 同内容在同一授权作用域内按 hash 去重，重复上传不创建新版本、不重复收费；同名不同内容保留新版。去重不得跨账号泄漏是否存在同券商模板、名称、结构或使用次数。
- 助手回答模板上传/适用性问题时沿用已上传版本，只追问真正缺项。自然语言回答回填当前文种的模板/券商等字段；保存和补齐不自动开始生成。
- 明确执行时由现有 worker 的 Codex CLI 采用锁定的模板原件/结构、精确来源及用户要求编制，不迁移到 API/SDK Agent runtime。模板更新只影响新任务草稿，不能改变正在制作的输入。

## 验收标准

- [ ] 用户 A/B 即使属于同券商也不能互见私有模板名称、内容、结构、匹配结果和下载；API/worker 均校验归属，猜测 ID 或 hash 不能越权。
- [ ] 首次立项无本人可用券商模板时仅提示缺项，不用公共空壳绕过；上传可读模板后回填并保存，须明确执行才开始。
- [ ] 相同券商名称不自动证明模板可用。分别覆盖过期、错误市场/文种、无法解析结构三种异常，显示具体原因，已有资料和消息草稿保留。
- [ ] A 再次使用同券商可显式复用本人准确旧版或上传新版；不依赖自动匹配/默认管理。旧任务及正文/编制说明显示原锁定版次，制作中上传新版保存到新任务草稿而不改变快照。
- [ ] 同内容换文件名上传复用同一版次且无新收费；同名不同 hash 生成可区分新版；跨账号上传同内容不暴露另一账号的模板或存在性。
- [ ] 参考报告含旧发行人、金额、签章、批注或“删除负面事项”指令，编制结果不挪用旧事实/签署，模板不能覆盖用户要求和事实约束。
- [ ] 立项报告及普通私募摘要各有独立适用模板元数据与完整结构样例；平台正式版本与研究/测试版本可区分，未批准版本不能冒称生产可用。非首发文种/市场说明未开放，不回退首发模板生成。

## 交付物与验证

- 两文种模板模型/权限及解析实现、首发适用性矩阵、准确版本/去重样例、异常和隔离用例证据；公共 schema 复用 `packages/contracts/`，不在页面/worker 再造定义。
- PR 关联本 issue，登记最新原型基线及同尺寸实现对照，说明结构抽取、授权、专业发布状态和剩余依赖。
- 按 AGENTS 当前关闭口径记录自动化与主链路证据；合成样例标明 synthetic。首发真实模板、真实 Codex CLI 编制结果及专家确认归 {{M4-12}}，延期模板能力归 {{M5-11}}，不能用 schema 6 的合成原型证明专业能力。
