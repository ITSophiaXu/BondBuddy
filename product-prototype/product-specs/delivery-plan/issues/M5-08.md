# [M5-08] 扩展组合材料生成与准确章节/段落改稿

里程碑：M5 · 建议角色：AI 工程师 + 文档工程师 · 优先级：P1

前置任务：{{M4-11}}、{{M4-09}}、{{M4-10}}，以及实际请求文种已交付的模板/编制能力。立项报告＋普通私募摘要组合可基于 {{M4-03}}、{{M4-07}} 先交付，不硬性等待 {{M4-04}}～{{M4-06}}；其余组合随文种开放。依赖是交付验收前提，方案和单元开发可先并行。

本 issue 为本地 review 新增稿，尚无 GitHub issue 编号；不预设个人负责人或截止日期。

## 目标与范围

- 按[2026-10-06 M4/M5 优先级拆分](../../../../docs/product-decisions/2026-10-06-m4-m5-priority-split.md)，承接原 M4 中的多文种组合及准确章节/段落改稿。沿用已确认的 BondBuddy 左工作区/右常驻助手框架、真实 artifact tabs 和 Codex CLI 后端，不增加独立 Agent runtime。
- 同一次明确组合请求锁定共享来源和公共事实，以及每文种的模板、采用证据、专属要求、目标/期间/用途；准确来源相同的事实提取只做一次。用户模板及专属程序证据不因组合而跨文种全量采用。来源不同、证据冲突或文种未开放先澄清/提示，不能把不可完成组合悄悄缩成单文种。
- 各文书独立编制正文和编制说明，保持各自状态、artifact、准确版本和失败原因；仅重试失败分支，可靠事实与成功产物可复用。状态未知先核对已有 CLI 调用，不能重新执行已完成子文书或丢失成功成果。
- 一个组合执行只形成一次预留和一次最终结算。默认全部关键成果实际可交付才成功，部分失败先在同一组合内重试；最终无法完成全范围则释放全部预留。已完成子文书可如实展示其文件/组合未完成状态，不能提前扣费、静默拆费或伪造全组合成功。用户显式选择独立任务才按独立任务执行/计费，不发明新费率。
- 整份继续改稿沿用 M4；本 issue 扩展明确章节及真实段落引用范围。锁定编辑 `artifact_id`、准确版本、变体、章节或段落 `anchor`、引用原文/hash、获准范围和数字/条款限制；原募集书生成来源单独保存，连续版本仍可追溯。
- 显式选定的底稿优先于旧讨论引用。底稿与“这段”引用版本冲突、anchor 失效或原文不一致时先说明冲突并澄清，不启动、不悄悄使用旧版。有效局部任务只改变获准范围；获准的必要关联变化须提前显示并明确纳入范围，不能以全篇重写替代局部请求。
- 对实际 DOCX 比较获准范围内/外正文、表格、数字、条款和允许的格式变化，保存验证证据；若工具无法可靠定位/保留范围，反馈限制和可选择的明确替代任务，不默默扩大范围。专业正确性由 {{M5-11}} 对真实模型结果验收，不能只验证 scope 文案或合成正文。

## UX、执行与恢复

- 组合准备时左侧只出现已选文种及其必要字段/材料，显示共享来源及各自采用清单；自然语言组合意图先确定目标文种再回填。补齐材料只保存，明确执行才调用同一任务入口，未开放文种保持草稿并说明限制。
- “与助手讨论”带入组合或准确局部改稿草稿、来源/模板/期间/范围并聚焦；不发送、不执行，保留未发送文字和引用。局部禁止只约束对应内容，不取消整句主执行动作；“如何生成”“先别生成”不执行。
- 工作区显示整体“正在制作”及各文书真实状态，助手展示实际阶段/工具事件，不按计时伪造过程。制作中新增资料/要求进入新任务草稿，当前组合/局部快照及 hash 不变；同项目仍互斥，无自动排队。
- 正文与编制说明各为独立 artifact tab，关闭 tab 不删成果。阅读旧版时开始/完成任务不抢切；阅读制作页时完成原位转正文。保留旧版本、范围及原文引用，部分组合失败不覆盖旧有效成果。
- 刷新、断线、worker 恢复和重复事件恢复原 run、各文书分支、调用检查点、预留和成果引用；不会重复执行、重复事实提取或收费。取消/失败按原计费契约释放，已有文件与失败证据保留，不能恢复成虚假成功。

## 验收标准

- [ ] 首发立项报告＋普通私募摘要明确组合请求可生成各自完整可编辑 DOCX 和独立编制说明；共享事实提取一次，两文种模板/要求/证据正确隔离。
- [ ] 组合包含尚未开放文种时提示并保留请求，未创建部分收费任务；用户明确改为可用单文种或独立任务后才执行。
- [ ] 制造一文书正文或说明失败，仅重试失败分支；成功后一次最终结算，无法交付全范围时全部释放。已成功文件显示真实状态，无子文书临时扣费；组合取消/恢复不重复预留或执行。
- [ ] 保留 v1 段落引用后打开 v2 点击整份继续改稿，采用 v2；v4 底稿配 v3 引用并请求“这段”先澄清，不启动（U4）。
- [ ] 引用第三章 `section3-p1`，发送“压缩这段，保留数字，并生成新版本”，固定准确版本/anchor/原文；真实文件只改获准段，数字、否定词、范围外正文/表格和必要格式符合锁定边界（U5）。
- [ ] 明确“精简第二章”仅修改第二章；anchor 失效、引用原文不一致、无有效引用或有歧义时具体追问，不全篇重写。实际 Word 内容差异与输入范围能一一核对。
- [ ] 先保存“补充要求：禁止新增风险承诺。”再请求局部续改，固定输入及实际输出保留限制；重复选择同底稿不清空要求，制作中新增资料只进新草稿（U3）。
- [ ] 刷新/断线/worker 恢复保留同一组合及所有子文书真实状态、准确局部范围、草稿、旧成果及阅读位置；未知调用核对后恢复，模型调用数和收费不重复（U7）。
