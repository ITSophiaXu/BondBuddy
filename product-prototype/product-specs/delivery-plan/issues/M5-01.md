# [M5-01] 确定桌面壳并建立安全的 Web 复用层

里程碑：M5 · 建议角色：Windows 客户端工程师 · 优先级：P0

前置任务：{{M4-12}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 验证 Electron/Tauri 方案后记录取舍，复用现有业务 UI 与平台契约
- 隔离渲染与本地工作进程，IPC/环回接口允许清单和随机鉴权
- Windows 安全存储令牌，禁用任意文件/shell 访问

## 验收标准

- [ ] 网页或材料不能借 IPC 访问未授权目录
- [ ] 供应商密钥和钱包权威逻辑不落客户端
- [ ] 窗口会话、登录退出、版本与错误说明可用

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
