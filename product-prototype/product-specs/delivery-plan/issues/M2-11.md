# [M2-11] 完成积分支付上线及更新任务商业闭环验收

## 目标与范围

- 执行真实支付、小额退款、并发冻结与灾难恢复验收
- 验证注册→充值→全文更新→下载→账单→退款/纠错完整链路
- 影子计量与真实扣费比对后按能力开关启用商业收费

## 验收标准

- [ ] 支付/余额/积分差错为零，不由浏览器决定结算
- [ ] 失败/取消释放、超额平台承担、迟到 usage 对账可复现
- [ ] 生产演示收款入口关闭，监控和回滚方案完成

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
