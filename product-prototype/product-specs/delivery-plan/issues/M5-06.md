# [M5-06] 实现 Web 到本地迁移、项目备份和用户支持

里程碑：M5 · 建议角色：Windows 客户端工程师 · 优先级：P1

前置任务：{{M5-03}}、{{M5-05}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 本人 Web 项目可显式导出/下载后导入桌面，材料和版本哈希校验
- 备份包含任务资料不含密钥/令牌，账单只引用平台
- 处理离线冲突、重复导入、故障诊断包和本地删除

## 验收标准

- [ ] 迁移不覆盖原项目、不默认删除云端副本
- [ ] 其他账号备份不能越权读取；余额不从备份恢复
- [ ] 诊断包先展示内容并由用户主动提交，日志默认无正文

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
