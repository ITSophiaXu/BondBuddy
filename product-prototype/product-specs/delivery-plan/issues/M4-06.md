# [M4-06] 实现推荐函模板及市场/用途适配

里程碑：M5 · 建议角色：行业专家 + AI/文档工程师 · 优先级：P1

前置任务：{{M4-02}}、{{M4-11}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。准确章节/段落改稿与组合执行依 {{M5-08}}，扩展模板/市场管理依 {{M5-12}}，专业最终验收归 {{M5-11}}。

## 本轮排期

- 按[2026-10-06 M4/M5 优先级拆分](../../../../docs/product-decisions/2026-10-06-m4-m5-priority-split.md)，本 issue 整体移至 M5，保留 M4-06 ID、原同步 marker 和 GitHub issue 身份，不另建重复 issue。
- M4 首发显示“推荐函尚未开放”，助手可说明所需信息/材料并保留已上传资料与草稿；不执行正式推荐函、不预留该文种费用、不把轻量文本当作正式推荐文书。以下完整专业范围和 UX 作为 M5 实现/验收要求，不阻断 M4 发布。

## 目标与范围

- 基于明确版次募集书/项目、推荐机构、市场/发行方式及推荐事项，生成供机构审阅的推荐函草稿。收件方、申请环节与机构角色可从材料提取，无法确认时追问；主承销身份不自动证明任意市场推荐权限。
- 模板覆盖标题/收件方、推荐事项、发行人/发行概况、推荐依据、主要风险/落实条件、推荐意见、附件/签署。推荐委托、职责、条件及核查程序必须有实际证据，不写营销宣传或保证发行成功。
- 建议采用机构模板、已完成核查意见、尽调/程序记录、批准文件及待落实事项。财务/偿债、授权、披露、规模/品种/期限/用途与准确来源一致，多品种条款分别处理，不新造指标。
- 交易所发行/上市与协会注册分别匹配文件名、收件方、事项和依据；跨市场转换重新确定适用性，不只换地名。私募、小公募、大公募的投资者及申请范围依有效规则处理。
- DFI 按统一注册或具体一期用途选择协会文本，申报对象、推荐范围、承销商团及签署主体与项目文件一致；注册安排不是已完成发行，阶段不明先澄清，不套交易所上市推荐函。
- 篇幅按模板，可依自然语言简洁或扩展；不能删掉改变结论性质的重大风险/限定。依据缺失至无法提出有效意见时先索取资料，签署日期等非关键缺口可标待确认。

## 最新 UX 与执行约束

- 遵循[2026-10-06 M4 Agent 工作区决定](../../../../docs/product-decisions/2026-10-06-m4-agent-workspace.md)。先选“推荐函”后只展开来源、推荐机构/事项/收件方、适用模板及建议补充材料；纯问答在常驻助手进行。
- 助手沿用同话题最近明确来源的准确版次，澄清答案回填字段。回答“收件方是上海证券交易所，推荐事项是A公司普通私募公司债发行挂牌。”更新对应字段，仅追问剩余缺项，不要求重填已有信息、不自动执行。
- 跨文种指令先确定“推荐函”再回填字段，不写入立项等旧草稿；更正收件方覆盖字段值，不追加成写作要求。切文种保留各自草稿，专属职责/要求不泄漏到其他文种。
- 自然语言写作要求左侧只读展示“助手已采纳要求”，预置要求分标“系统默认规则”。“与助手讨论”只带入准确文种/来源/范围/期间/模板和机构上下文并聚焦，保留现有草稿及引用，不发送或执行。
- 明确执行锁定来源、模板、机构/用途/阶段、证据和要求，由现有 worker 的 Codex CLI 编制；补齐只保存。左侧 tab 显示“正在制作”，右侧显示实际阶段；新增要求不改变固定快照。
- 正文/编制说明为独立 artifact tab，交付可编辑 DOCX；说明列来源、条件、缺口及专业签发边界。继续改稿显示底稿与原募集书来源，保留旧版本，结果完成不抢切正在阅读的旧稿。

## 验收标准

- [ ] 缺推荐机构/事项/收件方时精确追问，字段答案回填后只问余项、不自动开始；不选择软件平台为推荐人。更正字段覆盖原值，跨文种回填目标正确。
- [ ] 沪转深时收件方、事项、模板/规则依据共同适配，无旧市场残留；来源与目标市场冲突先澄清，不暗中转换源募集书。
- [ ] DFI 注册与具体一期用途使用正确协会文本及主体，不将注册安排写已发行；共同/分别出具时推荐职责与相关机构文件一致。
- [ ] 两品种期限不同，正文分别保留；篇幅减短仍保留重大风险及必要条件，未经证据确认不代机构作无条件保证。
- [ ] 只有募集书无程序记录，不宣称已履行全部尽调；模板的固定保证语须按证据调整并列待确认，不伪造签章/委托/任命。
- [ ] 制作页、固定输入和正文/说明采用相同准确来源、模板及机构/用途；制作中补要求进入新任务草稿，当前任务不变。
- [ ] 生成正文、待核条件及来源说明可在独立标签阅读、授权下载可编辑 Word；实质内容及推荐边界纳入真实样本最终验收。
