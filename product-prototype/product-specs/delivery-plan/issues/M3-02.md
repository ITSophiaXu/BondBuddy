# [M3-02] 实现审计证据财务复核与确定性勾稽

里程碑：M3 · 建议角色：AI 工程师 · 优先级：P0

前置任务：{{M1-10}}、{{M1-14}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 正文/表格数值对应审计报表及附注，匹配主体/期间/单位/口径
- 确定性复算合计、比率、增长率及跨表勾稽
- 区分明确错误、口径差异、待确认和未覆盖

## 验收标准

- [ ] 少一位数、元万元混用、合并/母公司误配有可追溯发现
- [ ] 时点不同不能简单判金额错误，低置信数字不直接定性
- [ ] 问题含原文位置、证据、计算、差异及建议

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。

- 认领时设置 assignee（权限不足请评论认领并请维护者分配），写明方案及依赖；完成后附 PR 与验收证据。
- 本 issue 不预设个人负责人或截止日期；多个成员可按组件协作，避免重复实现。
