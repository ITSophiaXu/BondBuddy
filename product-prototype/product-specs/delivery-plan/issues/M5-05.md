# [M5-05] 统一 Web/Windows 账号、钱包和跨端任务边界

里程碑：M5 · 建议角色：服务端工程师 · 优先级：P0

前置任务：{{M5-01}}、{{M2-04}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 共享平台身份、会话撤销、价格与账本，保留本地/云任务归属
- 跨端并发执行使用平台事务，不以客户端数值定价
- 明确 Web 项目与本地项目不会在未授权时自动同步全文

## 验收标准

- [ ] 在一端消费/退款另一端余额一致
- [ ] 伪造客户端余额/usage/任务成功被拒绝
- [ ] 跨端重试不重复扣款，不因迁移导入一份额外钱包

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
