# [M1-02] 接入真实手机验证码注册、登录与 Web 会话

里程碑：M1 · 建议角色：服务端工程师 · 优先级：P0

前置任务：无硬依赖，可先认领。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 接入短信供应商的挑战、验证码校验和重发限制
- 实现协议版本记录、账号创建幂等、登出与会话撤销
- Web 使用受保护 Cookie 或等效安全会话；注册事件为 M2 欢迎赠分预留幂等键

## 验收标准

- [ ] 正常、过期、错误、重放、限流用例通过，生产不回显验证码
- [ ] 不泄露号码是否注册，同一公司共享 IP 不一律封禁
- [ ] 登出会话不能继续读取文件；M1 不显示尚未真实发放的积分

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
