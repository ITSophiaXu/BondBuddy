# [M1-04] 建立项目、材料、任务、成果版本与账号隔离 API

里程碑：M1 · 建议角色：服务端工程师 · 优先级：P0

前置任务：{{M1-01}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 实现 Project、MaterialVersion、InputRevision、Run、ArtifactVersion 持久化
- 所有对象绑定 owner，读取、关联、下载和删除都校验权限
- 乐观锁、幂等请求、不可变任务快照和数据库迁移

## 验收标准

- [ ] 猜测其他账号 ID 无法枚举或下载材料
- [ ] 修改草稿不能改写运行中或已完成快照
- [ ] 重复创建、编辑冲突和备份恢复用例有稳定错误码

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
