# [M4-04] 实现主承销商核查意见模板

里程碑：M5 · 建议角色：行业专家 + AI/文档工程师 · 优先级：P1

前置任务：{{M4-02}}、{{M4-11}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。准确章节/段落改稿与组合执行依 {{M5-08}}，扩展模板/市场管理依 {{M5-12}}，专业最终验收归 {{M5-11}}。

## 本轮排期

- 按[2026-10-06 M4/M5 优先级拆分](../../../../docs/product-decisions/2026-10-06-m4-m5-priority-split.md)，本 issue 整体移至 M5，保留 M4-04 ID、原同步 marker 和 GitHub issue 身份，不另建重复 issue。
- M4 首发显示“主承销商核查意见尚未开放”，助手可说明材料清单和延期范围，保留已上传材料及草稿；不执行正式核查意见、不预留该文种费用、不以复核报告改标题替代。以下完整专业范围和 UX 作为 M5 实现/验收要求，不阻断 M4 发布。

## 目标与范围

- 基于明确版次的募集书/项目、适用市场/品种及出具意见的主承销机构，生成供机构审阅的草稿；建议提供尽调/程序记录、财务、决议、用途证明、信用/重大事项、机构模板和问询回复。
- 模板覆盖文件身份/范围、核查依据/方法、主体/治理、发行条件/条款、财务/偿债、用途/项目、披露/重大事项、增信/保护、发现/整改/意见、签署/附件。核查范围与材料截至时点明确，核心数字、机构及品种与来源一致。
- 逐项核查矩阵保留 `item_id`、`rule_id`、`requirement`、`applicability`、`procedure_required`、`procedure_performed`、`procedure_evidence`、`factual_evidence`、`finding`、`pending_action`、`draft_conclusion`；规则、程序和事实证据分开追溯。
- 实施程序只从真实记录获取。模型阅读可称“材料核对”，不能改成主承销商已访谈、函证或现场走访。待补证允许形成有限意见草稿，关键条件无法判断时不得交付整体肯定结论。
- 沪深私募、小公募、大公募及银行间分别适配规则、文件名、申报对象和机构职责；大公募不得直接复制小公募，银行间不得残留交易所挂牌措辞。
- DFI 区分统一注册核查与具体一期发行核查，核对注册文件、覆盖工具、有效期间/限制、本期安排；记录承销商团及牵头/联席实际职责，分别列各阶段程序缺口。多家主承销商须确认共同或分别出具，不能将全部参与机构自动并成同一出具方。

## 最新 UX 与执行约束

- 遵循[2026-10-06 M4 Agent 工作区决定](../../../../docs/product-decisions/2026-10-06-m4-agent-workspace.md)。先选“主承销商核查意见”后只展示该文种所需来源、出具机构/用途、适用模板和建议材料；DFI 阶段或多承销商分工仅在相关场景澄清，不新增普遍必填问卷。
- 助手沿用话题内最近明确来源及其准确版本；机构、阶段、共同/分别出具等澄清答案回填草稿，只追问剩余缺项，不因回答完整而自动执行。程序记录是该文种采用证据，不能因存在于话题就无条件用于其他任务。
- 要求经自然语言采纳后左侧只读显示，预置约束单独标“系统默认规则”。“与助手讨论”携带文种、来源、范围、期间和模板/机构上下文，仅聚焦，不发送、不执行、不丢草稿或引用。
- 明确执行由现有 worker 的 Codex CLI 根据不可变采用清单、适用规则、模板和要求编制，不能用内部复核报告改标题作为机构核查意见。左侧显示“正在制作”，右侧显示实际阶段/工具事件；新资料保存到新任务草稿。
- 正文与编制说明独立 artifact tab，均可读/获取，正文交付可编辑 DOCX；说明集中列程序缺口、条件及专业签发边界。继续改稿锁定显式选择底稿，分别显示原生成来源，保留旧版本。

## 验收标准

- [ ] 只有募集书无程序记录，仅输出有依据的资料核对与待实施程序，不虚构尽调、签字、批准或“经全面核查不存在任何重大问题”。
- [ ] 每项结论回查规则、事实和真实程序；缺规则不得写符合该条规则，主体评级与债项评级分别引用正确对象。
- [ ] 两家承销机构只有一家程序记录时，不代另一家作程序声明；选择共同出具和分别出具，职责、签署主体及产物集合各自正确。分别出具遵循组合任务的既有交付/结算契约，不静默只交一份。
- [ ] DFI 注册与一期核查使用正确阶段/用途、覆盖工具和本期安排；尚未完成注册或一期程序不能写成完成，缺口分阶段可见。
- [ ] 用途证明与募集书冲突时显示冲突并追问，不能同时保留冲突和“全部符合”结论；补资料只保存，明确执行才建立快照。
- [ ] 制作页和固定输入采用同一准确募集书/模板/程序记录版次，后续上传不改变旧任务；正文/说明及历史版本在工作区独立可读。
- [ ] 输出可编辑 Word，机构审阅稿状态清楚；正文的实质内容、矩阵完整性和专业边界纳入真实样本最终验收。
