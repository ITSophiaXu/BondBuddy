# [M1-03] 实现账号设置、找回、会话管理和注销

里程碑：M1 · 建议角色：服务端/安全工程师 · 优先级：P1

前置任务：{{M1-02}}、{{M1-04}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 提供手机号掩码、会话列表、协议、支持入口和 Web 数据管理
- 换号验证与无法使用旧号码的人工找回流程
- 注销协调任务终态、数据清理，并预留 M2 余额/退款处理

## 验收标准

- [ ] 仅新号码验证码不能接管旧账号
- [ ] 撤销指定会话后令牌失效，A/B 账号无法跨读
- [ ] 注销不删除依法需留存的记录，导出到用户本机的文件不宣称已远程删除

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
