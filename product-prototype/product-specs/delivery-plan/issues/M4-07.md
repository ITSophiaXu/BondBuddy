# [M4-07] 实现普通私募募集说明书摘要

里程碑：M4 · 建议角色：行业专家 + AI/文档工程师 · 优先级：P0

前置任务：{{M4-02}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。真实 CLI 编制集成由 {{M4-11}} 统一交付，不将模板 producer 反向依赖流水线完成。

## 目标与范围

本地实施：普通私募摘要技能、正文／独立说明、准确全文底稿及真实 Word 预览／下载已接入；证据见[实施验收记录](../../../../docs/acceptance/m4-implementation-2026-10-06.md)。最终统一验收待办：本轮真实文书 smoke 超时未通过，仍需授权业务样本完整 CLI、Word／WPS 和专业审核；远端 issue 尚未修改。

- 按[2026-10-06 M4/M5 优先级拆分](../../../../docs/product-decisions/2026-10-06-m4-m5-priority-split.md)，M4 从一份用户明确采用、准确版本的交易所普通私募募集书有效正文提取忠实、完整、可编辑摘要，保留原 G05；不宣称所有私募均有同一法定摘要要求。小公募/大公募 G06、非首发市场和多承销商适用扩展归 {{M5-12}}。
- 模板覆盖重要提示/与全文关系、主要风险、发行概况、发行人概况、财务/偿债、资金用途、增信/投资者保护、发行机构/备查。必要要素由各分支正式模板控制，不机械按每章等长压缩。
- 每条核心数字/条款/重大风险关联来源准确段落或表格锚点。主体、数值、单位、年度/中期、合并范围、日期、否定词、上限、条件、拟定状态及公式不改变；带修订文档仅取接受修订后的有效内容。
- 普通私募保留非公开、发行对象、资格/转让限制。正文精确投资者措辞依据原文/规则，不把产品简写标签直接当法律术语；不将公募稿删除公开字样后当成私募摘要。
- 保留多品种/期限、含权条款、审计意见/强调事项、评级对象、用途合计及重大负面风险；不引入原稿没有的承诺/财务事实/绝对结论，不夸大保护机制，不编造机构联系人/网址。
- 来源内部冲突、关键风险或核心发行条款缺失时显示具体问题并请求确认/补齐，不默选数字或补造事实；极短篇幅不足承载必要内容时说明必须保留项，区分简版说明与完整摘要。

## 最新 UX 与执行约束

- 遵循[2026-10-06 M4 Agent 工作区决定](../../../../docs/product-decisions/2026-10-06-m4-agent-workspace.md)及本轮优先级决定。先选“募集说明书摘要”，再展示来源及匹配模板，M4 明示仅普通私募已开放；不把其他文种输入一起罗列，纯问答留在常驻助手。
- 可根据实际源稿建议分支，用户明确选择保留；类型与来源冲突先问是否选错稿或拟转换，不暗中把私募转公募。明确整份募集书转换请求承接至更新业务草稿，不作为摘要隐式执行。
- 同话题 QA 后生成摘要采用最近明确来源的准确版次，不重新索要已有附件；无明确选择且来源不唯一先澄清。已关联 v5 后选择该文种采用 v5，不能被旧上传稿悄悄覆盖。
- 篇幅/读者/重点及限制经助手自然语言采纳，左侧只读展示；系统默认规则独立标记。补充/更正字段只保存，明确执行才启动。“与助手讨论”保留输入草稿和段落引用，仅带入上下文并聚焦。
- 由现有 worker 的 Codex CLI 采用不可变来源、有效正文、普通私募适用范围、模板/规则及要求编制；源项目后续更新不污染运行快照。左侧显示“正在制作”，右侧显示实际过程；新增要求保存为新任务草稿。
- 完成后完整摘要正文与编制说明独立 artifact tab、可编辑 DOCX。整份继续改稿分别显示摘要底稿和原募集书来源，保留旧版本及正在阅读的成果。准确章节/段落改稿归 {{M5-08}}，M4 不将局部指令扩大为全篇执行。

## 验收标准

- [ ] 普通私募以匹配源稿生成完整正文及编制说明，关键语义、表格/数字、风险和限制完整；不因优先级收敛只生成片段或空壳。普通私募样例及真实专业验收独立留证。
- [ ] 公募、小/大公募、银行间/DFI 或非首发多承销商来源显示适用性限制与尚未开放，保留资料/草稿，不扣正式摘要费用、不默认包装成普通私募摘要或 DFI 注册必备文件。用户明确要求转换整份募集书时承接更新业务，不暗中转换。
- [ ] 带修订来源只采用有效内容，已删除旧数字不进入摘要；每项核心数据能定位所选准确版本，不混入其他上传稿/项目/新版。
- [ ] “不超过”、回售权、不同期限、单位/期间/合并范围和审计意见完整保留；要求减半仍保留重大负面、风险强度、条件及投资者限制，不新增承诺。
- [ ] 源稿数字/用途有冲突先说明和确认，不能把“尚待核实”压成确定事实；无关键条款/风险时不补造，无法有效完整交付则按原失败/释放规则处理。
- [ ] QA 转生成及上传→明确 v5→选择新文种均采用 v5；运行中源项目生成 v6，当前制作和交付仍显示锁定 v5，新任务可显式采用 v6。
- [ ] 可在工作区阅读正文和独立编制说明、授权下载可编辑 Word；旧版本保留，说明列准确来源/模板/时间/依据/待核事项，完成不抢切旧稿。
- [ ] 源稿一致性检查属于摘要生成内部质量，不另计一遍完整专业复核；模型实际保留限制与重大风险纳入 {{M4-12}} 最终统一验收，不能仅验证界面文案。局部范围真实执行归 {{M5-08}}/ {{M5-11}}。

## 交付物与验证

- 普通私募模板/规则映射、核心来源锚点及一致性检查、CLI 输入/产物/事件证据；沿用 G05 和原结算规则，不增加价格，G06 保留至 {{M5-12}}。
- PR 关联本 issue，登记最新原型及实现对照，提供普通私募匹配来源、修订有效正文、非首发/类型冲突、重要限制及源版本变化用例。
- 按 AGENTS 当前关闭口径记录自动化与主链路证据，标明 synthetic；真实 CLI 编制、真实 DOCX 与普通私募专业确认归 {{M4-12}}，公募及市场扩展归 {{M5-11}}，不把原型回归记作 M4 已实现。
