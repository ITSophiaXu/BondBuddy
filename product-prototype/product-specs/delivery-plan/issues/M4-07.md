# [M4-07] 实现募集说明书摘要的私募/公募分支

里程碑：M4 · 建议角色：行业专家 + AI/文档工程师 · 优先级：P0

前置任务：{{M4-02}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 支持交易所私募、小公募及大公募差异和适用模板
- 基于最新版有效正文提取关键条款、财务、风险及引用
- 保留影响决策的重要限制，不将正文未载承诺添加进摘要

## 验收标准

- [ ] 带修订文档只采用有效内容，摘要数字与原稿一致
- [ ] 重大负面风险与例外不能因压缩篇幅漏掉
- [ ] 银行间/DFI 不被默认包装成交易所公募摘要

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
