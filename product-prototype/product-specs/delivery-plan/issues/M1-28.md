# [M1-28] 使用用户自带相似募集书结构和本发行人材料编制新稿

里程碑：M1 · 建议角色：AI 工程师 · 优先级：P0

前置任务：{{M1-10}}、{{M1-12}}、{{M1-14}}、{{M1-31}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 无本企业历史稿时 M1/M2 接受用户上传相似稿；不要求库发布、三业务匹配或商业库授权
- 仅复用结构和写法，本发行人事实必须有本企业来源；参考企业名称、数字、风险、签章不迁入
- 锁定用户指定参考版本、目标、本企业身份/材料和补充要求；保留既有发行人绑定契约并接入真实 input lock
- 完全无自带稿时保留草稿并提示上传；自动库匹配/推荐转交 M3 的 M1-32/#77
- SCOPE-10：原始材料直接交 worker（Codex + DeepSeek）；不依赖预先结构化财务数据或独立财务提取服务，财务读取/核对在任务内部完成

## 验收标准

- [ ] SCOPE-01/07：库关闭时自带相似稿仍可产出可编辑新稿，不伪造对其他企业的修订轨迹
- [ ] 新稿来源、主体、口径、目标适用性和版本一致，越权/换料/身份冲突继续验证
- [ ] 旧自动匹配工程成果保留到 M3；两类自带稿缺失不创建虚假成功任务；私人稿不自动共享

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
