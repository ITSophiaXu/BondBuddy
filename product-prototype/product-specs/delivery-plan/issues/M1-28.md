# [M1-28] 在统一 worker 中支持非同企业参考稿和无原稿编制

里程碑：M1 · 建议角色：AI 工程师 · 优先级：P0

前置任务：{{M1-12}}、{{M1-31}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 有母/子/相似业务企业稿时参考结构，目标事实来自目标发行人材料
- 没有任何原稿时仍由目标知识 MD 和发行人材料编制，不依赖参考库
- 共用输入与任务入口；实际所用基线如实标明企业，不强制审核画像或财务预提取

## 验收标准

- [ ] 参考库关闭且无原稿时实际编制新稿
- [ ] 参考企业名称/财务/债务/评级不残留为目标事实
- [ ] 局部缺项准确标注；纯复制、空壳和虚构事实不能算完成

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
