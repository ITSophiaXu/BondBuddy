# [M1-28] 无历史稿时按前三大业务自动匹配参考稿并编制新稿

里程碑：M1 · 建议角色：AI 工程师 · 优先级：P0

前置任务：{{M1-10}}、{{M1-12}}、{{M1-14}}、{{M1-32}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 用户选择没有且未上传相似稿时，从本发行人最近完整年度审计报告/附注的同一合并口径业务收入提取前三大业务及原文证据，自动查询 M1-32 后台库；不要求用户自行寻找相似募集书
- 三业务标准集合全部一致为候选门槛，金额/顺位分别保存但顺序可不同；再检查目标市场、发行方式、实际品种、文书阶段与规则适用性，在可用候选中择优，不以同业宽标签代替
- 用户上传的可用相似稿优先作为指定结构参考，不能当本企业历史稿或自动入公共库；缺失/不适用时后台匹配继续，不把可选附件变为必填
- 只复用章节结构和写法，按本发行人材料、目标规则及用户补充生成全文新稿；其他发行人名称、财务数字、风险事实、签章和信用结论不迁入
- 持久化内部 ReferenceSelection 快照，记录目标业务证据、候选命中/排除原因、选定文书/画像/索引版本；前台不展示库、蓝图、候选名单或内部来源文件名
- 区分缺收入附注与后台覆盖不足、第三名并列/少于三项/无匹配；真实资料缺口追问，内部缺口交运营补库，不用无关参考稿交付假完整文书

## 验收标准

- [ ] 没有历史稿且没有相似稿，仅提供必要项目信息与本企业财务/业务材料时，已覆盖样本能够自动匹配并产出质量检查通过的完整可编辑新稿
- [ ] 相同三业务不同排名可匹配；只命中两项、业务口径不同或宽行业相同不得标完全匹配
- [ ] 用户指定参考与自动匹配分别通过，参考事实泄漏为零；无历史稿成果不带相对其他发行人的修订痕迹
- [ ] 相同三业务但目标规则不适用的候选被排除；跨市场参考仅在对应章节映射已有验收时使用
- [ ] 库无匹配不能被说成用户必须上传相似稿，不能虚报完成或收费；只向用户呈现实际材料缺口/当前编制能力状态

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
