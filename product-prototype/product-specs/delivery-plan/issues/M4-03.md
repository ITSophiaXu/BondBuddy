# [M4-03] 实现普通私募立项报告与券商规则适配

里程碑：M4 · 建议角色：行业专家 + AI/文档工程师 · 优先级：P0

前置任务：{{M4-02}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。真实 CLI 编制集成由 {{M4-11}} 统一交付，不将模板 producer 反向依赖流水线完成。

## 目标与范围

本地实施：受信立项技能和文件模式 Codex CLI、正文／独立编制说明双 Word 路径已接入；合成真实 DOCX 集成证据见[实施验收记录](../../../../docs/acceptance/m4-implementation-2026-10-06.md)。最终统一验收待办：本轮真实文书 smoke 超时未通过，仍需正式预算下完整 CLI、Word／WPS 和专业审核；远端 issue 尚未修改。

- 按[2026-10-06 M4/M5 优先级拆分](../../../../docs/product-decisions/2026-10-06-m4-m5-priority-split.md)，M4 首发限交易所普通私募、单一承销商的立项工作稿；报告的实质章节、财务/条件/风险表和专业边界均完整保留。小公募、大公募、银行间/DFI 和多承销商扩展归 {{M5-12}}，不以缩短正文代替缩小适用范围。
- 基于明确版次的募集书/项目、立项券商全称及本人可用券商模板/参考报告，生成内部立项工作稿；建议提供立项规则、尽调清单、部门要求、项目方案和新增风险资料。
- 模板决定顺序，以下语义均需映射：封面/项目摘要、项目背景/承揽、发行人/治理、业务/行业、财务/偿债、发行方案/用途、尽调、内部立项条件、风险/措施、立项申请、附件/签署。不适用项记录理由，不强行增加与券商模板冲突的正文。
- 项目概况表保存主体、券商、市场/发行方式、规模/期限、评级对象、增信、用途和拟定安排；财务表保存年度/中期、合并范围、单位及三表/债务/指标，各计算附公式和来源，不将中期当全年。
- 内部条件核查表保留规则名称/版本/条款、适用性及理由、证据定位、满足/差异/待补证/待判断、拟措施和用户提供的负责人。内部阈值不得升级为市场监管规则，其他券商的规则不得替代本券商规则。
- 风险要与本项目证据关联，未落实措施使用“拟”；承揽关系、人员、审批日期、尽调程序与立项/内核决定只来自实际资料，不能由模板或模型补造。

## 最新 UX 与执行约束

- 遵循[2026-10-06 M4 Agent 工作区决定](../../../../docs/product-decisions/2026-10-06-m4-agent-workspace.md)。先选“立项报告”，左侧仅展开该文种的来源、立项券商、模板及建议补充材料，不一次列出五种文书输入。
- 从同一话题 QA 转到立项时沿用最近明确采用的募集书准确版本，仅追问券商/可用模板等真实缺项；有多个未明确来源时先澄清。券商和团队/节奏/风险/称谓/篇幅可在助手中补充并回填，不增加“补充意见”表单。
- 首次无可用券商模板或结构不可读时请求模板/可读副本，不能自动交付平台空壳。缺内部规则仍可编制有实质内容的工作稿，但注明完整内部条件未核验；核心财务、发行方案或负面事项缺失到无法形成有效报告时先索取材料。
- 用户写作要求经助手采纳后在左侧只读显示；系统预置与用户要求分别标记。保存/补齐不执行；执行按钮旁“与助手讨论”仅携带当前文种、准确来源、模板/期间/范围并聚焦，保留未发送草稿及引用。
- 明确执行锁定上述输入，由现有 worker 的 Codex CLI 编制。左侧成果 tab 显示“正在制作”，右侧显示实际执行阶段；制作中的新增材料/要求进入新任务草稿，当前固定输入不变。
- 完成后正文与编制说明分别为 artifact tab，提供可编辑 DOCX。说明列准确来源/模板、规则、时间及待核位置；整份继续改稿显示编辑底稿和原募集书来源，保留旧版本及用户正在阅读的成果。准确章节/段落改稿在 {{M5-08}} 交付，M4 不将局部指令扩大为全篇执行。

## 验收标准

- [ ] 无可用模板不开始；补可读模板后草稿可继续，但补齐本身不执行。两家券商模板的结构/内部核查表正确变化，同一来源事实不随模板改变。
- [ ] 普通私募、单一承销商生成完整报告；请求非首发市场/DFI 或多承销商时提示未开放并保留资料/草稿，不改称普通私募、合并机构或生成错误市场文书。
- [ ] 只有模板没有完整立项规则，形成有用工作稿且说明核对限制；明确门槛不满足时列差异/拟措施，不输出“全部满足”或审批已通过。
- [ ] 旧参考报告中企业名称、金额、签章、合作关系不进入新稿；无现场/访谈记录不出现已现场核查/访谈陈述。
- [ ] 财务表列头、年度/中期、合并范围和单位一致，年化有显式公式；项目表及风险/条件矩阵可回查准确来源。
- [ ] 对助手说“请把偿债能力作为重点，保留财务表格，不要新增风险承诺。”，三项进入草稿与执行固定输入，结果保留表格和限制；真正问句不被冒称已采纳。
- [ ] 首次上传保存本人模板，后续选择原版/新版均锁定准确版次，不影响旧成果；制作中补要求后准备新任务仍保留，旧快照不变。
- [ ] 正文与编制说明均可在工作区独立打开/获取，正文可授权下载可编辑 Word；模板字段/表格/样式、来源及缺口纳入真实样本最终验收。

## 交付物与验证

- 券商模板映射、内部规则适配、准确输入与产物证据；保留原 G01 计价标识及既有结算规则，不新设价格，同内容模板重复上传不增加难度。
- PR 关联本 issue，登记最新原型基线、输入/制作/正文/说明的实现对照，列出两券商、缺规则和未实施程序用例。
- 按 AGENTS 当前关闭口径提交自动化与主链路证据，标明 synthetic；首发真实 CLI 编制、真实样本和专业确认归 {{M4-12}}，市场扩展归 {{M5-11}}，不以合成原型正文替代。
