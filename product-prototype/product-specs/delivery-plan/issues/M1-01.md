# [M1-01] 明确 Web 优先架构、数据生命周期与公共接口

里程碑：M1 · 建议角色：服务端工程师 · 优先级：P0

前置任务：无硬依赖，可先认领。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 明确浏览器、平台 API、任务队列、模型网关、数据库及对象存储边界
- Web 文件采用账号隔离的服务端工作副本，明确加密、保存时限、清理及用户删除；Windows 本机存储留到 M5
- 输出接口、错误码、输入快照和数据生命周期设计，为后续桌面复用保留适配层

## 验收标准

- [ ] 无需安装 Node/Python/CLI 即可访问 Web，供应商密钥不进入浏览器
- [ ] 关闭标签页不取消后台任务，重新登录可查询状态和成果
- [ ] 材料上传范围、云处理与保存/删除策略有明确产品文案；不宣传 Web 原件只存在本机

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
