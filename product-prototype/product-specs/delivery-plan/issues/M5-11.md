# [M5-11] 完成扩展文种、专业 QA、组合与跨业务的统一验收

里程碑：M5 · 建议角色：测试工程师 + 对应领域审核人 · 优先级：P1

前置任务：{{M4-12}}、{{M4-04}}、{{M4-05}}、{{M4-06}}、{{M5-08}}、{{M5-09}}、{{M5-10}}、{{M5-12}}。依赖是扩展范围交付验收前提；测试设计及授权样本可先并行。Windows独立由{{M5-07}}验收，两者不相互等待。

## 目标与范围

- 接收从上一版M4移入的全部专业及扩展验收，明确M4首发已交付、M5拟开放和未完成项。基于准确版本复用M4基础证据，变更影响的路径定向回归，不把新功能缺口反向变成M4上线前置。
- 核查意见、法律意见书、推荐函完整模板／事实／证据／程序／签发边界；小公募及大公募摘要独立匹配来源、完整结果与专业审核；大公募不回退小公募。
- DFI注册／本期、覆盖工具／实际条款、实际文种用途及多承销商共同／分别职责；不创造DFI法定交易所摘要，不由模板声称已完成另一机构程序。
- 完整模板库的有效性／作用域／精确版本／重复hash／匹配、默认及退役管理；同券商跨用户隔离、历史任务不静默换版。
- 专业QA实时检索／法规效力／深度分析的真实来源和状态、可编辑QA成果、组合共享与最终结算、精确局部改稿及跨业务执行。

## 验收标准

- [ ] 五文种及私募／小公募／大公募分别有授权真实样本、完整可编辑DOCX／独立说明、CLI调用／工具／成果hash及专业审核；原M4有效证据可复用，合成正文不能冒称通过。
- [ ] 模板过期、错市场／用途、不可读、重复上传及删退役可恢复，草稿保留；未授权文件／模板／来源无法在读取、恢复或下载路径使用。
- [ ] DFI阶段和用途及多机构职责准确；未落实程序、未取得授权、存疑法条和签署日期不写成确定结论；重大负面事实不无依据删除。
- [ ] U1～U4扩展文种自然回填／准确来源／续改底稿／冲突回归；推荐函收件方及推荐事项只回填，不自动执行；法律原句局部禁止不吞主生成请求。
- [ ] U5真实CLI局部改稿固定version＋anchor＋原文；仅改允许章节／段落并保数字，范围外内容／格式不意外改写，不只验页面scope。
- [ ] 多文种组合共享事实一次、各文书独立状态／重试，组合一次预留，全部关键成果交付才最终结算；最终失败释放，不按子成果临时扣费。
- [ ] 查询成功／实际无结果／未执行／失败及法规现行／失效／未来生效／错市场分别验证；主体、截至日、查询时间和实际来源准确，不把未执行叫无结果。
- [ ] 复核→报告修正／新期间更新、QA→复核／材料分别承接正确任务／价格；互斥、准确来源、用户授权、旧报告保留和不抢阅读成立。
- [ ] U6整句执行保护、U7完整消息／草稿／权限／任务／成果恢复跨扩展路径回归；无自动排队、重发未知调用、重复费或静默清空。
- [ ] 新旧技能／协议／模板及报价版本可追溯；真实web search文件模式兼容有探针证据，公开信息与材料不越权外传，日志／prompt／推理不透传。
