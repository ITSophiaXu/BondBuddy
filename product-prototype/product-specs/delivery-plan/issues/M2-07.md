# [M2-07] 实现支付对账、必要差错纠正和人工发票处理

里程碑：M2 · 建议角色：服务端/支付工程师（财务参与验收） · 优先级：P0

前置任务：{{M2-01}}、{{M2-04}}、{{M2-05}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 不提供未使用余额现金退款及比例退现流程
- 保留补单、重复支付/渠道撤销等必要纠错，追加原因和原订单关联，不覆盖账本
- 人工发票申请及实际处理状态；运营落实主体、凭证及差错红冲规则

## 验收标准

- [ ] 支付成功但发分失败可幂等补发，无需用户再次付款
- [ ] 纠错与冻结并发不重复使用积分，重复事件不重复发分/冲正
- [ ] 任务失败/取消释放和免费纠错可追溯；不以关闭退款功能取消差错处理

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
