## 必须验收的流程

- [ ] **按钮闭环**：不发聊天，完成上传→复核→覆盖/问题/解释/依据→补证→确认重核范围或选择修订→明确执行→真实成果下载，标准按钮不新增伪造聊天。
- [ ] **页面**：版本历史归工作台项目卡；复核页仅材料与要求/复核结果；助手默认收起，桌面并排/窄屏抽屉均不遮挡主操作；历史进入准确报告/成果。
- [ ] **助手**：业务口径、结论异议、材料说明、跨问题要求、运行中下一版补充五场景有真实回复与引用；M1 #18 user-only 接线不当成助手完成。
- [ ] **执行边界**：发送仅保存/讨论/计划提议；采纳计划才改范围，明确点击才执行；空修订不建任务，异议/补证/已修改不自动通过。
- [ ] **上下文**：F-001 未发送草稿下打开 F-004，旧补证后切换聊天、收起/刷新/关闭重登、流式中断，均不丢内容或串 report/finding/material 引用。
- [ ] **任务与版本**：运行中新说明/材料只进下一输入，原快照不变；停止/失败版本不复用；同项目复核/修订互斥，连点/跨入口并发/断线重试同一意图仅一 run，关闭浏览器不取消。
- [ ] **差异复核**：执行前有准确重核对象，结果区分本轮重核、沿用原报告和未覆盖；沿用保留来源，不能标为完整三维通过；完整再复核另行执行。
- [ ] **无收费环境**：零余额、计费/支付未配置时执行完整 M3，无报价、充值引导或用户账务事件；真实 usage/内部成本记录，缺失为 unknown；M2 既有计费路径不被改变。
- [ ] **既有排除**：库关闭、三家商业接口均未配置不阻断 M3；实际 worker web search 工具、URL/日期/主体证据可查，不以模型记忆或模拟响应冒充。
- [ ] **专业结果**：财务金额/单位/期间/口径、合规披露、公开证据冲突、同名主体、缺材料/OCR存疑/无结果/不可达/工具不可用均有样本；覆盖首发品种/大公募/DFI，未覆盖如实说明，无依据不硬改。
- [ ] **专业质量门槛**：对全部首发品种及 DFI 运行授权金标准集，形成误报/漏报/来源有效性报告；关键金额、主体、市场、条款错误不得无提示交付。按实际验证能力开放，专业检查不能被原型或文档检查替代。
- [ ] **Word/WPS**：真实 DOCX 问题报告/原生批注/修订版/清洁版；表格、跨段落、同处多问题、原批注/修订并存、文字移动删除后锚点、保存重开及 WPS↔Word 往返有 build 与证据。PDF 基线明确，无法定位留报告，损坏或错贴不标成功。
- [ ] **追溯/发布**：原稿、旧报告、旧成果、要求/计划与新 run 一致可查；资源归属、日志、任务恢复、真实部署版本与回滚有记录。严重发现与技术失败区分，零发现不保证合规。
