# [M1-12] 实现后台任务队列、进度、取消和检查点恢复

里程碑：M1 · 建议角色：服务端工程师 · 优先级：P0

前置任务：{{M1-04}}、{{M1-11}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 从不可变输入快照排队执行，记录任务租约和阶段检查点
- Web 用 SSE/等效事件推送真实状态，关闭浏览器不停止服务端任务
- 处理幂等执行、工作进程重启、取消/完成竞争和输出交付凭证
- 按 M1-34 记录 job_type/subtype、operation/job/run/trace、每个阶段与终态、输入和成果版本；状态提交与日志 outbox 原子持久化，创建 run 前的拒绝也留 operation/job 记录

## 验收标准

- [ ] 重复点击只产生一个有效任务
- [ ] 服务重启复用已完成调用，状态不明先查询再重试
- [ ] 取消与完成只有一个最终结果，失败保留可恢复材料
- [ ] 成功、失败、取消、拒绝和恢复都有完整可查询时间线；响应 200 或模型结束不等于成果交付成功，日志转发故障不静默丢终态

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
