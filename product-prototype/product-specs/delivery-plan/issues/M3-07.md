# [M3-07] 完成 Wind 真实授权接入及债券数据核验

里程碑：M3 · 建议角色：数据接入工程师（商务/行业参与验收） · 优先级：P0

前置任务：{{M3-04}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 核实 Wind 可提供的服务形态和再展示授权，不假设终端账号可当 SaaS API
- 适配许可的发行、存续、偿付、评级及相关市场数据
- 建立发行人/债券标识和历史/报告期末/当前口径映射

## 验收标准

- [ ] 真实已授权接口样本和费用记录可复查
- [ ] 应付债券余额不替代全部历史发行兑付记录
- [ ] 权限不足或字段缺失明确未覆盖，不用猜测填补

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
