# [M4-12] 完成立项、普通私募摘要、基础 QA 与真实 Codex CLI 的最终统一验收

里程碑：M4 · 建议角色：测试工程师 + 对应领域审核人 · 优先级：P0

前置任务：{{M3-10}}、{{M4-01}}、{{M4-02}}、{{M4-03}}、{{M4-07}}、{{M4-08}}、{{M4-09}}、{{M4-10}}、{{M4-11}}。依赖是 M4 已开放范围交付验收前提；测试设计、授权样本准备和工程自动化可先并行。移至 M5 的文种和扩展能力不再作为 M4 发布前置。

> 2026-10-06 用户已确认 M4／M5 分期并要求执行。M4 高优先级交付立项报告、普通私募募集说明书摘要、基础 QA 和最新统一助手交互。M5 承接其余专业文种、组合、深度查询、局部改稿与高级成果，并由 [M5-11](M5-11.md) 扩展验收。范围分期不降低 M4 的真实 CLI、专业内容、Word、权限、账务、阶段与恢复质量。当前工程实现和分层证据见[实施验收记录](../../../../docs/acceptance/m4-implementation-2026-10-06.md)，本 issue 的专业／发布门仍待完成。

## 验收层次与证据

1. 工程关闭沿用 AGENTS.md：各实现 issue 自动化测试通过、主链路可跑通后可关闭，附命令、pass／fail、commit／PR、环境和显式“最终统一验收待办”。synthetic 材料、模拟 CLI、模拟账本均标注，不替代真实证据。
2. 本 issue 汇总 M4 最终统一验收待办：真实配置 Codex CLI／工具、授权业务样本、可编辑 DOCX、专业审核、账务及发布条件分别验证。实现 issue 已关闭不等于本 issue 专业／发布验收通过。
3. schema 6 原型 U1–U7 是交互基线。M4 在实际产品重跑适用于本期的操作，核对固定输入、读取证据、成果、恢复与账本；U5 的局部执行部分及后续文种回填移交 M5，不把合成正文或界面文案当实际模型验收。

每例证据包含案例 ID、授权／synthetic 性质、项目／话题、来源／模板／知识／技能准确版本及 hash、输入范围、要求、编辑底稿、run／execution request／调用身份、操作步骤、预期／实际、截图或安全事件、成果 hash、费用状态与缺口。客户正文、敏感报告及私密原始日志不进入公开 issue／PR；保存授权的私有验收链接。

## M4 业务与能力覆盖

| 范围 | 必须运行的样本与边界 |
|---|---|
| 立项报告 | 首次上传可读券商模板／参考报告、本人准确版次复用；旧企业事实、签章、批注及金额不污染新稿；真实券商结构与表格完整；未提供内部规则如实列限制，不虚构已完成程序或已通过审批 |
| 普通私募募集说明书摘要 | 使用匹配的交易所普通私募来源与模板，生成独立完整正文及编制说明；核心事实、条款、负面事项、投资者限制、财务口径与来源一致；公募、银行间／DFI 不静默转成普通私募摘要 |
| 基础模板与来源 | 只显示当前文种输入；首用、本人复用、准确版本／hash 与采用清单可核对；同内容重复上传不增加难度；未授权、不可读或不匹配模板不能冒称可用，给具体缺项或下一步 |
| 基础 QA | 概念、已有授权材料解读、常用财务确定性计算、资料准备清单、聊天文本轻量起草、产品帮助、已有回答免费文本导出；来源、期间、单位、主体／合并口径与缺项处理完整 |
| 全文继续改稿 | 显式准确成果版本作为底稿，与原募集书生成来源分别展示；原有限制、模板和采用材料不丢失；全文新版本交付且旧版本保留；局部请求仅讨论／说明 M5，不静默扩大范围 |
| 跨业务共用 UX | 更新／复核／材料保留业务入口，工作区构建输入和展示成果，助手 always on；共用“正在制作”、真实阶段、讨论、恢复和项目互斥不破坏既有更新／复核执行协议 |

首发两个文种交付真实可编辑 DOCX 和独立编制说明，说明可回查实际来源、模板、依据、待核事项及专业签发边界。每种文书有对应领域专业审核记录；提纲、示意正文或“文件生成成功”不冒充完整专业验收。任务可交付状态与专业验收分别留证，不篡改已有任务的下载政策或历史验证证据。

- 多文种组合共享事实提取、各文书独立编制／失败重试及组合冻结／最终结算；M4 首用模板、准确版本选择、基础可读／适用性错误及私有隔离仍由本期验收，不以高级模板治理未完成推迟这些基本门。
- 章节／段落局部修改的 exact version＋anchor＋原文固定与真实模型范围验收（[M5-08](M5-08.md)）。M4 保留准确引用讨论和版本冲突保护。
- 实时公开查询成功／实际无结果／未执行／失败及真实时间／覆盖／截至日；自动法规效力检索／适用法律结论、多期深度研究（[M5-09](M5-09.md)）。M4 不执行时必须如实标记，不能伪造成查询无结果。
- 可编辑分析／轻量草稿 artifact 与高级成果（[M5-10](M5-10.md)），跨业务自动执行及其授权／报价／互斥回归。M4 先显式切换工作区，重新核对目标输入及报价后明确执行。

## M4 交互与状态验收

- 沿用业务导航与左右框架。“材料生成与问答”为一个入口，先选文种才出现对应输入／材料；M4 只开放首发两个文种。纯 QA 直接在常驻助手，无左侧 QA 表单、补充意见输入区、收起或全屏助手选择。
- 工作区是任务输入构建区与 artifact 本体阅读区；助手理解、澄清、展示真实执行和讨论。左侧只读展示“助手已采纳要求”，预置项标“系统默认规则”。
- 执行按钮旁“与助手讨论”带准确任务／来源／模板／期间／范围，聚焦输入框，不发送／执行；现有消息草稿和段落引用保留。
- 复核与材料生成后工作区显示“正在制作”，右侧显示同一 run 的真实安全阶段／工具事件；没有事件不编造查询、完成或百分比。重复／乱序事件不增第二张卡片、不使终态倒退。
- 阅读旧 artifact 时开始／完成不抢切或滚动；正在看制作标签时完成原位成为成果本体。正文、编制说明、来源及旧版本独立可打开。
- “准备新任务”打开已有后继草稿；“继续改稿”固定显式准确成果版本，重复点击同版本幂等。制作中新输入进后继草稿，当前快照不变；切文种分别保留草稿和专属要求。
- 同项目更新／复核／材料任务互斥，被阻断保留草稿，结束后不自动排队或启动；其他话题不绕过项目锁。恢复、充值、返回页面不算明确执行。
- 已展示有效报价、授权与预留具备的本业务首发文种，按钮和自然语言明确执行进入同一持久任务路径，无需第二个形式确认。资料／报价缺项只保存与澄清，回填不自动执行。
- 从复核页提出募集书更新等跨业务请求，先保留当前报告／草稿，显式进入目标工作区并核对准确来源、目标、范围、材料和报价，再明确执行；M4 不以原页面一句话暗中启动另一业务。
- 未开放文种、组合、局部执行或公开检索有明确能力说明，不启动替代任务、不收其费用、不丢原请求；可继续基础 QA 和资料准备。
- 桌面、窄屏、键盘、长会话完成上传、讨论、执行、阅读、全文续改与恢复；框架内输入可达、无横向溢出，完成任务聚合可展开摘要，执行中保持可见。

## 真实 CLI、专业与费用验证

- [ ] 服务端真实执行 Codex CLI，脱敏 runtime／身份及配置留证；资料、模板、知识、要求、来源／底稿／全文范围、技能 pin 与 prompt hash 一致。无替代 API／SDK runtime 或固定正文批次的第二业务编排。
- [ ] 技能受信加载、版本／hash 固定，变更、知识缺失、旧协议恢复可复核且不重跑；真实工具事件、确定性计算与文件来源可追溯。
- [ ] 原件／输入只读，本轮 scratch／output 可写；权限探针、注入、目录逃逸、符号链接、跨账号／项目、字节篡改、未知事件均测；原始 prompt／日志／推理不透传。
- [ ] 两个首发文种的 DOCX 可在 Word／WPS 打开并编辑，预览本体、下载及 hash 对应；正文和独立编制说明完整、来源与工作稿状态可读。HTML 示例或下载按钮不等于 Word 验收。
- [ ] 基础 QA 给确定性公式／期间／单位／口径／来源；两期同口径指标、差额／增幅与比率变化（百分点）按真实授权材料可复算，缺数／零分母／口径冲突明确处理，区别M5多期深度研究；已有核验知识有准确版本，未核效力明确说明；未执行实时查询无虚构时间／无结果／“无违约”结论，不声称法律适用性已自动核验。
- [ ] 断线、CLI 超时、租约丢失、有效取消、写入失败、usage unknown／pending、worker 重启分别测；已完成调用／文件复用，未知调用先核对，不盲目重发；关浏览器不取消。
- [ ] 原价格及已开放 Q／G 分类复用；保存、纯澄清、产品帮助、下载／已有文本导出、内部恢复、平台纠错保持原免费边界；报价／预留／结算／释放对应 run，无重复费。
- [ ] 余额不足无任务／调用、草稿保留；输入变化使旧报价失效；有效取消／最终失败按原契约释放，交付成功才结算；M5 未开放请求不新建替代任务或收费。
- [ ] 更新／复核积分遵循 10-06 决定；正式价格未确认／发布则不开放付费，不用 synthetic 价格，旧任务不追补；未接通支付不标可充值。
- [ ] 首发文种专业审核确认无他人事实、虚构现场核查／函证／签署／审批、无依据删除重大负面事实、错误引用或不适用模板；摘要保留原事实、条款及投资者限制，缺口有责任人及待核范围。
