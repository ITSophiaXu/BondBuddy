# [M5-03] 实现本地账号隔离的项目、材料与缓存存储

里程碑：M5 · 建议角色：Windows 客户端工程师 · 优先级：P0

前置任务：{{M5-01}}、{{M1-10}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 本地 SQLite/文件目录保存原件、事实、对话、版本和检查点
- 材料导入为复制而非覆盖原文件，云调用仅发送必要内容
- 权限拒绝、空间不足、路径长度、加密/隔离与删除策略

## 验收标准

- [ ] 账号切换不能枚举上一账号材料/模板
- [ ] 离线可编辑但不能伪造已完成远端处理
- [ ] 本机存储说明与 Web 上传说明分别准确，无绝不外传假承诺

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
