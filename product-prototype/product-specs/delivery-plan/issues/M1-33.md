# [M1-33] 实现后台募集书库的持续增量更新、审核与版本退役

里程碑：M1 · 建议角色：数据接入工程师（商务/行业参与验收） · 优先级：P0

前置任务：{{M1-12}}、{{M1-32}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。

## 目标与范围

- 为已获准使用的公开披露或授权来源提供独立接入适配器，运营批量补录共用入库流水线；配置定时发现、增量游标、去重、重试和断点恢复，实际周期按来源条件配置
- 新文件或正文变化进入待解析/待分类/待审核队列；重算市场、方式、品种及最新完整年度合并主营业务收入前三大业务，审批后原子发布正文、画像与检索索引
- 支持人工校正、同稿新版本、替代、撤回、失效和回滚，保留原因、操作者及审计日志；已替代/撤回/授权失效版本即时退出新匹配，缓存同步失效
- 任务锁定已选参考版本、业务画像、词典及索引版本；普通扩库不改写运行中任务/已交付成果，授权撤回按保留政策隔离且后续读取重新检查
- 运营查看新增/待审/失败/陈旧数量、来源最近成功时间、各市场及三业务覆盖和未命中汇总；失败/长时间未更新有告警，支持按记录重跑
- 全流程为后台工作，不增加用户更新库、选择库版本或等待人工选蓝图步骤；上传的个人材料不能借自动采集进入公共库

## 验收标准

- [ ] 至少跑通真实获准来源的首次及后续增量同步，发现新版/无变化/失败重试都有记录；不可达来源如实标缺口，不把定时器或模拟成功当持续更新能力
- [ ] 同一来源重复运行不重复入库，半途失败可恢复，迟到旧任务不覆盖已发布新版本，正文与索引不能一新一旧
- [ ] 第三业务收入排名变化触发新画像，未审核数据不可被选用，回滚后索引与正文一致
- [ ] 撤回后新任务不命中旧稿，已锁定历史版本可追溯；对授权已撤回内容不继续无条件使用
- [ ] 提供运营操作手册、告警样例与失败恢复演练，普通用户接口和交付中不泄露库清单、候选或匹配分数

## 交付物与验证

- 对应实现或规则/模板版本，以及能复现上述边界用例的测试/样本记录。
- PR 关联本 issue；标明当前原型复用项、新增能力、配置迁移与尚未关闭的阻碍。
- 涉及生产短信、模型、支付、供应商或专业规则时，提供真实接入/审核证据；模拟通过不能替代上线验收。
