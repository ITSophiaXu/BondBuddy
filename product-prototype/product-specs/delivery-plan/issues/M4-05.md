# [M4-05] 实现法律意见书模板和结论证据约束

里程碑：M5 · 建议角色：行业专家 + AI/文档工程师 · 优先级：P1

前置任务：{{M4-02}}、{{M4-11}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。准确章节/段落改稿与组合执行依 {{M5-08}}，扩展模板/市场管理依 {{M5-12}}，专业最终验收归 {{M5-11}}。

## 本轮排期

- 按[2026-10-06 M4/M5 优先级拆分](../../../../docs/product-decisions/2026-10-06-m4-m5-priority-split.md)，本 issue 整体移至 M5，保留 M4-05 ID、原同步 marker 和 GitHub issue 身份，不另建重复 issue。
- M4 首发显示“法律意见书尚未开放”，助手可回答已开放范围内的材料问题、说明法律意见所需材料并保留资料/草稿；不执行正式法律意见、不预留该文种费用、不把 QA 答案导出冒充法律意见。以下完整专业范围和 UX 作为 M5 实现/验收要求，不阻断 M4 发布。

## 目标与范围

- 基于明确版次的募集书/项目、发行人、市场/品种及适用模板形成可编辑法律工作稿。软件不能签发法律意见、冒用律师/律所，募集书自述不能直接称为独立核查事实。
- 模板覆盖标题/致送/释义、依据/声明、主体资格/存续、股权/治理、批准/授权、发行条件/条款、用途/项目、主要资产/债务、关联/重组/重大事项、法律披露核对、结论/条件、签署/附件。
- 法律事项保留 `issue`、`fact_evidence`、`legal_basis`、`applicability`、`procedure_evidence`、`analysis`、`conclusion`、`limitations`。事实与法律分别引用，结论有可解释的连接，不能只列法规名。
- 支持资料包括登记/章程、股权、决议/授权、批准/注册、合同、担保/权属、项目许可、诉讼/处罚、律师程序记录；逐项显示必要缺项，不要求一开始完成全套法律问卷。
- 法条名称、条号、原文、效力日期、适用范围与固定任务一致；未生效/失效/替代版本、研究线索和专家经验不能充当现行强制法。历史发生、持续影响、已解决与未知状态分别判断。
- DFI 区分注册申报与具体一期用途，分别核对条件、决议/授权、覆盖工具、有效期间及本期条款；受理不能写注册完成，未实施程序不能补成完成。

## 最新 UX 与执行约束

- 遵循[2026-10-06 M4 Agent 工作区决定](../../../../docs/product-decisions/2026-10-06-m4-agent-workspace.md)。先选“法律意见书”后展开该文种来源、模板及法律证据；律所、律师和用途可从资料提取或在常驻助手中澄清，签署未定标待确认，不新增“补充意见”表单。
- 同话题说“再用这份募集书生成法律意见书”，沿用最近明确的准确募集书版本，仅追问可用模板、授权等实际缺项，不重新索要已有来源。法律授权证据与允许软件生成草稿的执行指令分别记录，不能混作法律授权已完成。
- 自然语言要求回填草稿，左侧只读展示“助手已采纳要求”；系统默认规则独立显示。补字段/材料只保存；问句只讨论。齐备后须明确执行，缺关键事实时保存原请求并说明缺项。
- 明确执行由现有 worker 的 Codex CLI 采用不可变来源、证据、模板/规则和要求编制。`请生成法律意见书，保留待核事项，不要生成签署页。` 的正文执行与局部限制分别承接，不能因“不生成签署页”取消整个任务。
- 工作区显示“正在制作”，助手显示实际阶段/事件；正文与编制说明独立 artifact tab、可编辑 DOCX。工作稿和专业签发边界明确，说明列尚缺资料、未实施程序及律师待确认判断。
- 继续改稿以用户显式选择的底稿为准，原募集书来源另列。局部引用锁定准确成果/版本/anchor/原文，底稿与引用冲突先澄清；制作中新增要求只进新任务草稿，旧版本与阅读位置保留。

## 验收标准

- [ ] 无决议不写合法内部授权、无权证不由资产负债表推断全部权属无瑕疵、公开查询无结果不写无任何诉讼；引用对应实际查询覆盖与时间，未查询不伪装已查询。
- [ ] 受理通知与注册完成不同，DFI 注册/一期意见准确匹配用途及证据；诉讼撤诉、执行终结和债务清偿不能自动互相替代。
- [ ] 法条名称/条号/原文不匹配不能支持确定结论；旧法已替代时重新核验适用性，不静默沿用 latest 或研究版本。
- [ ] 核心主体/发行方案缺失或关键内容仅占位时不标完整收费交付；有实质内容的待核工作稿可交付，非关键缺口有位置清单，未核结论保持限制。
- [ ] 签署/律师/日期待确认，不伪造执业签名、印章或已签发状态；用户要求某律所风格不能升级为该律所真实签发。
- [ ] 从 QA 转生成只追问真实缺项；自然补充模板/授权只保存。资料齐备时，完整执行句含局部禁止签署页，正文只启动一次、保留待核事项且无签署页；“先别生成”不启动。
- [ ] 保留 v1 引用后在 v2 点“继续改稿”，采用 v2 底稿；“这段”引用与底稿冲突先澄清不启动。合法局部范围只修改所选段并保留要求和数字，不能仅验证 scope 文案。
- [ ] 正文/编制说明可读、授权下载可编辑 Word，准确来源、底稿、模板及规则版本可追溯，真实专业结论另行最终验收。
