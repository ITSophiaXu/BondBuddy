# [M4-10] 交付常驻助手、首批真实任务时间线、成果标签与完整恢复

里程碑：M4 · 建议角色：前端／平台工程师 · 优先级：P0

前置任务：{{M4-08}}、{{M4-09}}。依赖是交付验收前提；资料研究、方案和单元开发可先并行。本 issue 提供共享话题、草稿／引用、时间线和成果阅读契约；M4-01 消费以实现文种输入表单，M4-11 产出真实任务事件和成果。契约和独立 UI 可并行，不以 M4-01／M4-11 全部完成为本 issue 的倒依赖；完整生成联动在 M4-12 验收。

## 本期范围与后续范围

M4 交付基础专业 QA，以及立项报告、普通私募募集说明书摘要的单文种任务、全文新版本和真实成果阅读。完整历史恢复、准确版次、权限、幂等和账务关联是本期闭环，不移至后续。组合和精准范围改稿移至 [M5-08](M5-08.md)，法规检索与深研移至 [M5-09](M5-09.md)，跨业务自动执行及可编辑 QA 分析／轻量草稿 artifact 管理移至 [M5-10](M5-10.md)。阶段范围以[2026-10-06 M4/M5 优先级拆分](../../../../docs/product-decisions/2026-10-06-m4-m5-priority-split.md)为准。

## 目标与范围

本地实施：常驻助手、真实安全执行事件、完整话题／消息／未发送草稿／引用与阅读恢复已接入；证据见[实施验收记录](../../../../docs/acceptance/m4-implementation-2026-10-06.md)。最终统一验收待办：真实 API 登录及长会话／中断恢复、原生 CLI 生产隔离与发布验证；远端 issue 尚未修改。

- 用合并的“材料生成与问答”入口交付右侧常驻 Agent、输入框、附件、可选关联项目、最近话题与真实示例。纯 QA 在助手中完成，不提供独立 QA 页面或左侧问答任务表单，不新增收起／全屏助手模式。
- 同一话题内，工作区与助手共用资料库；正式任务保存独立采用清单，附件、模板、来源项目及准确版本均经服务端授权。新话题隔离消息、附件、任务和未发送草稿；已有项目只有被显式选择才进入上下文。
- 完整保留真实用户消息、真实 CLI 助手回复、待澄清内容与真实任务卡的类型区别。点击页面开始任务不伪造用户自然语言消息，浏览来源、引用、预览和下载不制造执行卡或逐点击聊天日志。
- 每个真实 run 一张稳定任务卡，消费独立 worker 的持久任务状态和白名单业务事件，如读取资料、提取事实、核对模板、编制正文、登记成果；左右关联同一 run／输入／artifact。没有细分事件时显示已有实际阶段，不按计时模拟进度、不额外调用模型生成进度、不透传原始 CLI 日志、路径、prompt、隐藏推理或未知字段。
- 工作区标签分别容纳任务草稿、制作状态和 artifact 本体。任务开始后显示“正在制作”，失败／停止／待处理按真实状态呈现；只有文件真实生成并按本期交付契约登记后才显示成果。当前正在读制作页时完成原位转成果；正在读旧 artifact 时不抢切，有准确新成果入口。首批文书正文、编制说明及历史版本各有稳定引用；已有更新／复核成果仍按原授权可读。
- 预览读取真实 artifact，预览失败保留授权下载和重新加载入口，不把已交付成果改成生成失败、不触发重跑；关闭标签仅关闭视图，不删除文件／历史。既有修订版和清洁版保持同一轮交付版本及各自变体，不虚构两次生成版本。
- 任务卡可打开准确固定输入、实际采用来源、全文范围、底稿和成果；成果及来源可带准确版本和段落引用进入讨论。引用由服务端保存的结构化元数据定位，不从模型正文猜 ID／页码，不把“存在附件”当答案引用依据。M4 的引用用于讨论与证据定位，不能借此启动尚未开放的精准范围改稿。
- 已完成任务集中为可展开摘要，保留展开状态和精确历史入口；执行中任务过程持续可见，输入框在多轮讨论中可达。回看历史或选择文字时不自动抢滚动，输入框的现有文字和引用不被快捷操作覆盖。
- 话题、完整消息、澄清和采纳记录、附件权限及准确来源、各首发文种／全文改稿草稿、未发送文字和引用、任务与成果引用、阅读标签及准确版本真实持久化。正文／文件存私有对象存储，元数据、关系及恢复身份由后台保存；浏览器缓存和示意主机压缩快照不能替代生产历史。
- 刷新、断流、关闭重开和重新登录恢复原调用／任务／成果，不重新发送用户消息、执行、调用模型或收费。流式中断区分部分回答与完整成功，保留可读状态，先核对已完成调用和任务再恢复，状态未知调用不得自动重发。
- 保存、容量或恢复失败有明确反馈和重试入口，保留上次完整记录及当前未保存内容，损坏记录不被空默认状态覆盖。恢复时重新校验归属和文件权限；不能从缓存绕过权限变化。
- QA 已有文本导出免费；基础文字起草在助手输出文本，不提前引入可编辑起草 artifact。本轮消费显示实际分类、预留／结算／释放或待核状态，与真实任务／调用身份关联，不另建消费流水页面。usage 不明如实显示待核，不伪造零费或成功结算。
- 对未开放文种、组合、精准范围改稿、跨业务自动执行和检索／深研请求，助手准确说明范围并保留相关意图，不出现虚构制作标签／任务卡或账单；跨业务需求提供现有目标工作区显式入口，跳转后由目标工作区核对执行。
- 助手理解、回复与执行仍通过 Codex CLI。平台负责持久上下文、权限、任务事件、租约、审计和恢复，不依赖一个无限续接 CLI 会话，不改为 API／SDK 模型运行时。

## 验收标准

- [ ] 从合并入口直接提问概念、解读材料、确定性计算、准备清单、产品帮助或基础文字起草；均在助手完成，纯问答不出现左侧任务输入。新话题不带旧话题附件、引用或任务。
- [ ] 工作区上传和助手上传互相可见；任务采用清单仅含实际所用资料。来源链接打开准确文件版本／位置；概念答案不乱引募集书，未执行的外部查询不附附件冒充查询证据（U1）。
- [ ] 操作“与助手讨论”，保留未发送文本及引用，只带当前上下文并聚焦；320px 及桌面键盘操作可达，切换首发文种／标签不清空草稿，不把原引用改绑到新 artifact。
- [ ] 页面执行和助手明确生成共用真实 run；左右显示同一固定输入和执行过程，任务卡按身份去重。重复／乱序事件及恢复不会新增卡片或让完成退回执行中。
- [ ] 制作中新增要求显示用于下一任务，当前固定输入不变；准备新任务和继续改稿可查看各自准确草稿；编辑底稿、原募集书来源和讨论引用分别显示。局部执行请求提示计划 M5，不擅自扩大为全文（U3–U5）。
- [ ] 观看旧 v1 时新任务开始／完成，仍在 v1；观看制作标签时完成原位变为真实正文。正文和编制说明独立、旧版本可回查；停止／失败保留旧有效成果，不用示例正文伪造新成功。
- [ ] 实际 artifact 预览失败可重新加载或授权下载，run 及结算状态不回退、无重跑；关闭再打开标签恢复准确版本和阅读位置。既有修订版／清洁版引用同一交付版本且变体明确。
- [ ] 建立至少8个话题、8个首发范围任务／成果，其中一个话题含至少46条消息及来源引用、附件和两个文种草稿，另一个保留未发送文字；刷新及关闭重开恢复全部准确关联与阅读状态，无新执行或费用（U7）。样本任务标签不扩大已开放文种。
- [ ] 执行中断线重连、worker 恢复、重复 SSE 和任务终态丢 ACK，恢复同一任务／调用／预留，不重复执行或收费；未知调用先核对。部分回答标中断，不能标完整成功或按成功结算（U7）。
- [ ] 超容量、保存失败和损坏历史场景均显示原因、保留当前内容及旧记录并可重试；默认空状态不会覆盖旧记录；附件权限撤销后恢复无法越权读取（U7）。
- [ ] 新旧 schema／提示／技能版本历史分别按原版验证和恢复，部署升级不重发旧消息／任务；停止和失败的输入版本不复用。
- [ ] 同项目跨话题／浏览器并发冲突显示原活动任务；草稿保留，无自动排队。跨用户／项目的消息、附件、任务、引用、成果和下载在所有读取及恢复路径被拒绝。
- [ ] 已有 QA 文本免费导出不产生新模型调用或账单；文字起草不产生虚构可编辑 artifact。本轮消费可对应真实预留、结算、释放和失败状态。
- [ ] 未开放文种／组合／局部执行／跨业务自动执行请求只显示范围反馈及适用的目标入口；无制作标签、运行卡、预留或收费，不把 M5 能力伪装成已完成的首发能力。
- [ ] 多轮任务摘要可展开到准确输入／成果，执行中过程可见；桌面和窄屏消息框、上传、讨论、停止／恢复及阅读路径可用，无内部提示、密钥或原始 CLI 输出泄露。
