# 募集书项目工作区（1.8.0）

用户先创建项目，随后上传材料、填写发行安排或通过项目对话补充要求。系统读取材料后给出点数明细，用户确认后才启动任务。上传和评估不预占任务点数；开始时预占已确认点数，成功结算，失败或停止释放。报价绑定材料内容、项目参数和补充说明，24小时有效，修改后重新评估。开始后不自动加价。

## 表单与项目对话

- 默认全文更新，移除更新范围、年度数量和原稿发行方式的手动提问；由材料识别品种及年度工作量。旧草稿的范围设置不再传入任务，旧报价需重新评估。
- 更新募集书的资金用途下拉提供六个选项：借新还旧、偿还有息负债、补充流动资金、项目建设、用于投资股权、用于基金出资。保留金额与组合用途的自由补充；项目建设提示提供可研报告、土地证书、相关许可证。已有用途文字保留。
- 移除重大资产重组及投资者保护选项。更新和复核按审计报告附注与适用规则核对重组事项，证据不足列待核实；不将合并范围变动直接等同于重大资产重组。
- 历史募集书只询问“有 / 没有”；没有时要求本发行人年度审计报告及业务收入附注，可选上传相似募集书，不展示内部参考资料或匹配流程。
- 更新页恢复默认展开的选填表单，包括发行规模与债券安排、参与机构、评级与增信、募集资金用途、其他项目信息。删除主题导航和对话内的结构化填写卡片；右侧对话只用于额外信息与修改要求。
- 发行规模分为申报总额和本期规模；用自由文本说明各品种规模、期限、含权、专项用途及回拨等安排，不预设两个品种。单一主承销商只写名称，多家时再说明实际分工。
- 已填的旧对话主题内容与未完成草稿迁回更新表单，重复的自动说明被合并；自由补充保留并可修改、移除。复核页不显示这些选填表单，先前已经提供的信息作为补充说明保留。修改或删除额外说明不改变更新表单中的字段。填空示例本身不会成为项目事实。
- 承销机构按实际分工自由填写，单一主承销商不必拆分角色。旧草稿的期限、主承销商、联席主承销商、簿记管理人与受托管理人会迁入新输入区。
- 更新与复核共用项目说明区。消息与结构化字段一起保存，作为用户安排与补充资料参与处理。支持直接填写授信总额、已用和未用额度等信息；按发行人提供注明来源，核对日期、单位与勾稽，未附证明或与材料冲突时列待核实。消息区目前负责收集要求和展示收录确认，不伪装成已完成材料分析的即时问答。
- 项目草稿、待补材料与待确认报价均在“全部项目”中恢复。选中的本地文件在上传前仅存在于浏览器；上传后的文件保存在项目中。

## 材料上传

不再用材料类型下拉框。更新页直接显示历史募集书（选择“有”时必需）、审计报告 / 财务报表及附注（必需）、募投项目与权证材料、其他项目材料；选择“没有”时增加可选的相似募集书分区。募投材料提示涵盖可研、备案、土地和建设许可、基金备案、子公司股权投资文件。

选中文件后逐份上传并保存。每份文件的进度来自实际传输字节事件，传输完成与后台保存成功分别显示；失败可重试，已保存文件可以移除。上传期间不能评估，评估或删除期间暂时锁定编辑。评估失败后重新读取已保存文件标识，避免用户替换材料时仍使用旧清单。每次上传、删除或修改要求都会使原报价失效。

历史募集书及待复核募集书须为 DOCX；可选相似募集书支持 DOCX / PDF，其他支持材料支持 DOCX / PDF / XLSX / CSV / TXT。最多60份、合计80 MB。相似募集书仅供结构参考，不可引用为本发行人财务、业务或经营事实。

## 复核范围

复核页只保留必要基本信息，要求上传待复核募集书与审计报告 / 财务报表及附注，并在提交前展示三类检查。对话仅补充已知差异、核验线索或特别关注事项，不再引导填写发行安排、资金用途和参与机构：

1. 财务数据：与财务证据对照金额、期间、单位及勾稽。
2. 合规与格式：按适用法规和发行市场规则检查披露要求，结合 DOCX 字体、字号与段落信息检查格式；未取得正式规则或只能取得主题字体时明确限制，不编造要求。
3. 公开信息：围绕公告与重大事项、工商与控制关系、诉讼处罚与信用、债券与违约四个方向检索，并结合已配置的工商及债券服务核对。单次检索失败不阻断其他方向。

检索受实际服务配置与套餐权限约束；用户明确要求仅用上传材料时不查询外部。报告列明已执行和未覆盖的范围，不把有限搜索称为完整全网覆盖，也不把无法取得依据的事项标为通过。当前没有真实搜索或工商服务联调验收；复杂 Word 视觉版式仍需人工检查。

## 材料生成与券商模板

材料生成默认选中第一项“上传最新版募集书”（DOCX / PDF），第二项为“关联募集书项目”。明确选过项目的未完成草稿保留已有选择，旧版仅停留在关联方式但未选择项目的草稿改为上传。提供五类独立章节模板：立项报告、主承销商核查意见、法律意见书、推荐函、募集说明书摘要。摘要另选私募债或公募债版本。

左侧保留材料选择、募集书来源、券商模板与补充资料，所选材料的模板结构可在选择区展开查看。右侧沿用更新募集书的项目对话样式，提供“补充说明与写作要求”输入区，展示当前材料及募集书来源。可连续加入项目信息、写作重点、格式要求，并逐条修改或移除；快捷示例追加到已有输入，不覆盖正在填写的内容。窄屏下改为上下排列。

对话说明与未完成输入按账号保存在本机浏览器，旧版写作要求自动迁为一条说明。点击生成时，已记录的说明和输入框中的内容合并进入实际生成提示；正在修改时替换对应说明，避免重复。合计最多12000字、50条，超限保留输入并提示精简。加入说明不发起模型请求或消耗生成额度；生成上传期间锁定编辑，失败后可保留要求重试。对话仅确认收录，不声称已完成材料分析。

关联项目会复制本次所用材料快照：优先采用已完成的更新稿，否则使用当前上传的募集书，并在页面提示尚未完成更新的情况。读取更新稿时采用接受修订后的正文，避免提取已删除旧值。内部参考稿不进入发行人事实来源。

立项报告必须提供券商全称。首次使用该券商时要求上传模板或已完成的立项报告作为参考，同时建议提供立项规则。可读取的模板自动存入当前账号的券商模板库，按文件哈希去重并保留版本；以后可自动复用或选版本，也可上传新模板。当前不共享客户模板到其他账号。

生成采用模板章节、样式及页面尺寸，逐节编制正文与表格并校验引用。参考报告里的旧公司事实、页眉、签章和批注不复制到新文档。结果为可编辑 Word 及编制说明，缺少证据列待补；意见类文件是供机构审核的草稿。模板结构复用不等于逐像素复制原版式。

材料生成沿用对话 / 文件额度：每次1次问答，加计本次新上传文件；关联项目材料及复用模板不重复计文件额度。更新与复核继续使用下述确认点数流程。

## 点数评估初版

策略版本：`2026-09-workload-v2`。实现位置：`lib/work-estimate.mjs`。这是可继续校准的首版产品定价规则，尚未用真实成本样本校准。

| 工作项 | 当前规则 |
| --- | --- |
| 基础整理与更新 / 复核 | 2 点 / 1 点 |
| 无历史稿的完整编制 | 更新额外 3 点 |
| 跨市场或品种转换 | 更新额外 2 点；原稿品种尚不能识别时，1 点核对工作量 |
| 财务数据更新 | 按已解析财务材料中的不同年度估算，1–10 点；当前更新及复核须提供财务材料才能评估，不接受旧表单覆盖 |
| 多品种安排 | 额外 1 点 |
| 阅读量 | 超过6万字后，每增加6万字或不足6万字的一档加1点 |
| 跨材料核对 | 超过4类材料后，每增加3类或不足3类的一档加1点 |

服务器生成报价；客户端不能提交点数。确认请求只提交报价编号。并发启动串行处理，重复确认不会重复预占。新材料解析失败或匹配不足时不生成可启动报价。

## 内部业务匹配

无历史稿且未上传相似募集书时使用以下后台流程；上传了可读取的相似募集书时，以该文件为结构参考，事实仍完全来自本项目资料。

1. 从最近完整年度审计材料提取合并口径、带单位及收入数值的分业务收入；校验主体、年度和逐字引文，不使用行业标签代替业务收入。
2. 按同一口径营业收入排序，取得前三项。来源冲突、不足三项或第三名并列时，不猜测结果。
3. 在已核对来源、可解析正文、状态适用且未被新版本替代的库内资料中，核对前三项业务是否全部一致。基础名称仅做保守规范化，没有用宽泛行业相同替代完整匹配。
4. 匹配相同时优先考虑本次市场、发行方式和较新版本；匹配不足时保存项目并阻止启动，不随意回退到无关企业。
5. 任务复制独立文件，内部保留来源与匹配证据。参考企业事实不能作为本企业财务或经营证据。用户接口与成果说明不展示内部库条目。

当前仅有少量公共收录，严格匹配的业务覆盖范围有限；OCR与复杂表格也可能导致无法确认业务收入。应继续扩充和维护资料，而不是降低匹配要求后把不完整匹配当成功。

## 验证边界

隔离测试覆盖免费创建和评估、确认扣点、旧报价失效、上传进度与重试、评估期间编辑锁定、解析失败后文件清单同步、并发幂等、失败释放、账号隔离、市场联动、业务匹配证据、无匹配阻断、五类材料与两种摘要的真实 Word 导出、券商模板复用与隔离，以及公开检索的分项失败。测试使用模拟材料、模拟模型和模拟外部查询，不代表真实发行人文件质量或现行规则已验收。浏览器视觉检查仍需完成。
