# BondBuddy 官网

本文件保留原官网的设计说明；源码已整理为独立目录，可与产品原型分别迭代。

## 预览

- 官网：`http://127.0.0.1:4321/`
- 工作台：`http://127.0.0.1:4320/`
- 独立 HTML：`exports/bondbuddy-landing.html`，样式、交互与界面 SVG 均内嵌，可双击打开。此文件中的产品入口指向本机 `4320` 端口。

## 页面内容

官网包含产品定位、券商客户价值、工作台示意、四项功能切换、可放大的产品界面、三步工作流程、两档月度套餐、点数加购、常见问题、Windows 下载区。适配桌面与移动端，导航和功能标签支持键盘操作，弹窗支持 Escape 关闭和焦点返回，尊重系统减少动态效果设置。

功能插图依据当前产品工作流绘制；其中的项目记录、处理结果、对话与数量均为明确标注的演示数据。没有注入工作台真实业务数据，也没有虚构客户案例、效率统计或商业数据库上线状态。

## 源文件与部署

`public/` 是完整静态站点，包含 `index.html`、`website.css`、`website.js`、`assets/`。整目录可上传至静态网站托管服务，无构建依赖、外部字体或第三方追踪脚本。本次仅实现本地页面，未发布到公网。

部署前在 `index.html` 底部的 `site-config` 中，将 `appUrl` 改为正式网页版地址。套餐与产品体验按钮目前进入现有应用的对应页面，由应用处理登录和订阅；官网不自动下单。

Windows 安装包尚未制作，当前点击“获取 Windows 版”会打开明确的即将上线说明，并提供网页版入口。安装包发布后，填写 `windowsDownloadUrl`，同时更新首屏、下载区和常见问题中的发布状态。仅接受 HTTP(S) 下载地址，不能填入脚本协议。正式短信与支付上线前应保留演示说明；外部数据接入状态必须与实际授权服务一致。

## 维护与导出

修改界面示意图后运行 `node scripts/build-site-previews.mjs`。源数据和布局在该脚本中，可复现五张 SVG 产品图。

修改官网后运行 `node scripts/export-website.mjs`，更新独立 HTML；部署目录与独立导出文件均需保持一致。
