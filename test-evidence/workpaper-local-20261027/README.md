# 底稿批量生成真实本地验证

固定产品提交：9e9ddf35170c191524e5f211f4579076db226161，PR #762。
2026-10-27 在独立 Docker Compose 环境 http://localhost:5211 完成。

真实浏览器登录、募集书上传采用、XLSX 导入、四类模型判断、确认门、生成、刷新恢复和浏览器 ZIP 下载通过。没有 API mock；数据库为独立 PostgreSQL 16，存储为持久化 Azurite。样本资料与应用积分为合成测试数据；gpt-6-sol 两次正式任务调用为真实模型，均有 measured usage 及 exit 0。

- confirmation-required.png / completed.png：确认门与完成后的页面。
- 实际下载底稿包.zip：浏览器真实下载，纯合成样本。
