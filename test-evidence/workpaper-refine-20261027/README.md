# 底稿页四处组件设计审计与修正

范围：用户截图中圈出的顶部导航、募集书来源、目录下拉框、查找与选择工具栏。以现有 `styles.css`、`file-generation-ux.css` 的森林绿配色、次级按钮、文件来源条、表单及焦点样式为依据。产品及同步原型固定于 `ada9a4bfe6e5a7db96808f073957a0d9129f8341`，修正提交为 `d1c9ba1e`、`ada9a4bf`。

|组件|发现|修正|
|---|---|---|
|顶部导航|四个散落文字链接缺少统一操作外观，移动端间距不一致|复用次级按钮，44px 高、13px 字号、7px 圆角、8px 间距；手机排成两列；保留原路由和项目上下文|
|募集说明书来源|来源标签、文件名、版本混在一行文件信息中，文件图标和更换操作缺少组件边界|统一来源条、40px 图标容器、14px 文件名、独立“已采用 · Vn”状态；查看/更换使用44px次级按钮，长文件名允许换行|
|已上传目录|原生 select 未继承字体及表单尺寸，横向无限拉伸|保留原生选择行为与关联标签，44px 高、14px 字号、边框及焦点态，桌面最大640px；识别数量与控件分离，窄屏换行|
|查找与选择|按钮居中对齐于标签加输入框；全局 label 额外25px/9px边距造成实际页面残余偏移|限定标签外边距为0，输入框和按钮统一44px、底部对齐；添加搜索图标，手机输入框整行、两操作等宽|
