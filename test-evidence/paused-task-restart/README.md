## 行为与范围

暂停任务使用同一个 run、固定输入、检查点与原计费规则。点击先读取真实状态，确认可恢复后仅调用 resume，进入队列；重复点击、其他页面已恢复和响应丢失均核对原任务，不调用 execute。核对类暂停显示原因及只读状态检查，不绕过后台检查。

覆盖更新/编制、复核/重核/修订/导出、各文种与底稿单项、问答、诚信核查、文件一致性与关联文件更新、逐份文件检查、项目任务记录、助手卡片和暂停回复、底稿批次与底稿库。批次恢复先恢复暂停子任务，复读批次 revision 后恢复队列；保留试生成待确认动作。

材料解析新增 POST `/api/v1/projects/{project_id}/materials/{material_id}/parse-job/resume`，按归属、job ID、材料版本与 SHA 绑定；只恢复原 paused/awaiting_ocr 作业，保留完成阶段，重复请求只产生一次恢复事件。OCR 未就绪仍会暂缓。
