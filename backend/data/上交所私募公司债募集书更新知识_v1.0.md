# 上交所非公开发行公司债券募集说明书撰写与财务更新知识

版本：1.0.0｜整理日期：2026-09-16｜用途：模型知识增强与可追溯的募集说明书更新。

## 1 适用边界与来源层级

本知识针对上海证券交易所、面向专业投资者非公开发行的公司债券。通用撰写要求以所给上交所规则为依据；实际使用应确认规则适用时点、发行人类型和专项品种。本文件不是对全部现行规则的核验结论。

本次评测固定为“历史募集说明书全文财务更新至2025年6月”：新增财务事实只能来自用户上传的财务报表及附注，历史募集说明书用于结构、历史比较信息和原有项目定义。不得联网补充财务、工商、评级、发行条款资料，不得读取其他本地业务文件。规则材料中的企业名称、示例数字、日期和示例原因均不是项目事实。

规则标识：
- 【规】所给交易所规则中的要求；保留原适用条件和例外，不能推广为所有项目的无条件要求。
- 【专】专家材料中的工作方法或提示阈值，不自动等同于监管标准。
- 【整】为消除来源冲突、落实用户任务和保证数据可核查而制定的整理口径。

优先顺序：用户明确的任务范围与事实来源限制；经确认适用的交易所规则；适用且不冲突的专家方法。专家文件自称“唯一权威”不改变层级。旧模板被划除的文字不作为有效意见；空白意见、问句和未确认阈值不当作已确认结论。遇到材料冲突，记录并继续完成不受影响的更新，不得自行掩盖。

财务报告期、募集说明书拟签署日、规则适用日是三个不同字段。“更新至2025年6月”不是“将签署日改成2025年6月30日”，也不是将文件生成日写为签署日。2026年版知识可用于本次方法测试，但不能据此宣称全部规则在2025年6月已经生效。本次不重写发行法律条款。

## 2 开始更新前的资料与报告期核对

【规 R00 8.1.1、8.1.4】非公开发行按第八章调整后参照适用申请文件及编制指引；要求提供最近两年的财务报告和审计报告及最近一期财务报告或报表，不得直接套用公募三年一期。

【整】本次默认展示2023年度、2024年度及2025年1—6月，先核对五份材料实际包含的期间和原书列示结构；如材料不支持完整期间，明确缺口，不能补造。已有必要的更早历史事件、历史交易数据和背景比较不因滚动而一概删除。报表比较窗口需要滚动时统一调整列数与相关文字；同一年度补中期与跨年度滚动分别处理。

建立材料清单：文件编号、主体全称、财务期间、合并或母公司口径、币种和金额单位、是否审计、审计机构、报告号及意见原文。文件名不代替报告正文核验。缺少审计报告不能凭“通常经过审计”标成已审计；没有证据时标记“未提供对应审计报告，审计状态待核实”，已明确未经审计则照实注明。

【规 R00 8.2.1】所给2023年版本规定最近一期财务报告在截止日后6个月内有效，延长至多1个月且须申请获准；不能自行按已延期处理。这是申报时效要求。本次2025年6月的历史任务不因当前日期而擅自改成2026年报告期，也不据此声称产物可直接用于当前发行。

## 3 全文定位和事实来源

先建立全文位置清单，再更新第五节等主要财务内容，最后回写全文引用。位置须覆盖正文、表格、表格前后文字、重大事项提示、释义、脚注、页眉页脚和文本框中实际存在的财务引用。按章节名称和内容对应，不机械依赖“第五节”或原知识文件中的表号。

每个待处理位置标记以下一种状态：
1. 已按新材料更新；
2. 资料缺失，明确保留旧报告期或标记【待补充：主体、期间、项目】；
3. 口径或判断待确认，列明冲突双方；
4. 无需修改，说明属于历史事实、合同约定或本次范围外内容。

【整】数字分类后再修改：报告期末余额、期间发生额、比率或计算数、历史事件金额、合同阈值、未来计划、发行参数、第三方评级引文、截至签署日的状态。禁止全文批量替换年份或金额。

每条事实记录：主体、期间、报表范围、指标或明细名称、原始值、原始单位、统一单位值、来源文件、可核验的页码/工作表/表名/行列/段落定位、取数说明。每个计算数再保存公式和输入记录编号。不要编造源文件页码；不能可靠定位页面时用可复现的表名和行列。

同一主体、期间、范围、指标使用同一事实记录回填所有位置。不同口径即使名称一样也不得共用。概要与正文不一致时回查原始材料，不能仅以“正文为准”消灭差异。

来源按字段匹配，不设“最新审计报告压倒一切”的总排序：
- 对应年度数据取对应审计材料；2025年中期数据取中期报表及附注。
- 历史募集说明书中仍需保留的历史比较值可沿用，但标记为仅有历史披露、是否已由新材料复核；不得伪造为新报表取数。
- 同期间有明确重述或重分类说明时依据该说明处理，保留原数、重述后数和原因。仅发现期初与上年期末不等，不能自行认定差错、自动覆盖或强行勾平。
- 同主体、期间、范围的正文报表与附注有无法解释的矛盾时列为冲突；不能简单按文件编号或文件新旧任选一个。

## 4 期间 数值与计算规则

【专 E03】时点数据使用2025年6月30日；利润、收入、成本、现金流等发生额使用2025年1—6月。每个“分别为”后数字的数量、顺序须与前述期间逐一对应。

- 2025年6月末与2024年末可作资产负债余额比较；2025年上半年与2024年上半年才是相同期间同比。缺少上年同期，不以2024全年代替同比基数。
- 不自动年化中期收入、利润、现金流、周转率或利息保障指标；如原项目定义要求年化，先核实定义、所需输入和展示说明。
- 先统一币种和单位，再计算，最后按原书精度展示。元转万元除以10000，万元转亿元除以10000；不同币种无汇率依据不得相加。
- 区分0、空白、破折号、不适用和未披露，不把未披露补成0。金额的负号、括号、千分位和小数点须核对。
- 百分比变化与百分点不同。比例由10%变成45%是上升35个百分点；相对增幅另算，不能都写“增长35%”。
- 同口径正基数的一般增长率为（本期－上期）÷上期×100%；零或负基数时避免机械给出误导性增长率，优先说明增减额、扭亏/转亏及计算口径。
- 展示精度造成的尾差可说明，不调整原始报表数据以凑合计。计算和核查使用未舍入值。

【专 E03、E02】基础公式：
| 指标 | 公式与限制 |
| --- | --- |
| 净资产 | 资产总额－负债总额；核对是否指全部所有者权益，不能自动替换为归母权益 |
| 毛利 | 同业务、同期间营业收入－营业成本 |
| 毛利率 | 毛利÷营业收入×100%；总体毛利率按合计毛利÷合计收入，不平均分部毛利率 |
| 收入/成本/资产/负债占比 | 分子与对应的合计分母保持同主体、期间、口径 |
| 流动比率 | 流动资产÷流动负债 |
| 速动比率 | （流动资产－存货）÷流动负债；原项目有特别定义则核查并说明 |
| 资产负债率 | 负债总额÷资产总额×100% |
| 受限资产占比 | 受限资产账面价值÷同期期末总资产×100%；净资产占比若另列须另标分母 |
| 对外担保占比 | 担保余额÷原条款要求期间的净资产×100%；专家一般分析用最近一期末，原文若约定经审计年末不得静默换成中期 |
| 同期变动额 | 本期－比较期；同一口径并说明比较期间 |

【整】分母为零、数据缺失或范围不明，标记不适用/待确认，不能计算出无穷大或补零。

EBITDA与利息指标必须保留项目定义。【专 E03问题16】提供的候选EBITDA公式为：利润总额＋计入财务费用的利息支出＋固定资产折旧＋无形资产摊销＋长期待摊费用摊销；这是候选方法，不替代原项目已明确口径。不得将财务费用净额当作利息支出，也不得推定缺失折旧、摊销或资本化利息为0。
【整】E03的简化利息保障倍数公式与E02“分母含资本化利息”存在差异。R00 3.7.2所列含资本化利息公式位于面向普通投资者公开发行的专门段落，不能不分对象强套给私募。用原募集书明确的项目定义核对新材料；定义或分母不完整时列缺口，不跨年度更换公式。未明确的“335指标”不自行解释。

## 5 第五节财务会计信息的完整更新

【规 R00 3.7.1—3.7.7，经第八章调整】【专 E03第五节】

1. 审计与编制基础：逐期核对机构、文号、意见类型、会计准则/编制基础、会计政策与估计变更、差错更正、合并范围变化。不同年度机构分别保留，不全换成最新机构。
2. 审计意见照原报告准确表述。带强调事项段的无保留意见仍属于无保留意见；保留意见、否定意见、无法表示意见不能统称“非标准无保留意见”。强调事项、持续经营等相关段落分别识别。缺少补充说明时标记所需说明，不伪造董事会或会计师结论。
3. 检查合并资产负债表、利润表、现金流量表以及母公司相应三张表的所有实际列示项目、合计、期间标题和脚注；原书有其他财务表也逐一检查。缺少某张报表不能由另一口径代替。
4. 新科目、改名、重分类先确定映射；不能仅凭名称相似合并数据。保留净利润与归母净利润、全部权益与归母权益的区别。
5. 财务分析明细逐表核对：应收与其他应收的余额、账龄、坏账/减值、性质及前五名；存货构成及减值；长期投资、投资性房地产、固定资产、在建工程；借款、债券、租赁和其他有息融资；关联交易、担保、诉讼、承诺、受限资产、现金流补充资料。按原书实际项目扩展，不能只更新上述例子。
6. 最新期仅有合计、没有前五名或账龄等明细时更新合计，明细保留准确的旧期标签并提示待更新，或在最新期列明确留缺；不得把上年明细移到中期标题下。
7. 会计政策等事项不能只看最新一份附注，也不能只因发生年份退出比较窗口就删去仍影响本期理解的内容。
8. 确需备考报表的重组使用对应备考报告并区分实际/模拟数据，不能将两个主体报表简单相加。

【整】基本勾稽：资产＝负债＋所有者权益；分项与合计；毛利与收入成本；现金流三类净额及汇率影响与现金净变动；期末现金及现金等价物与期初加净变动。货币资金与现金及现金等价物可能范围不同，不能强行相等。若材料本身存在差异，报告差异而非改造原始事实。

## 6 有息债务 担保与受限资产

【专 E03问题5、7及第五节】【规 R00 3.7.4—3.7.7、附件8】

有息债务先做逐笔或逐类范围表，再汇总。通常检查短期借款、计息应付票据、一年内到期的非流动负债、长期借款、应付债券、租赁及长期应付款中的有息融资，并核对其他相关项目。该清单是检查起点，不是所有项目通用的固定求和公式。

- 应付票据是否计息须有材料或明确项目定义；不能全部默认为有息或无息。
- 一年内到期部分已从长期项目转出时不能再计入原长期余额。区别债券本金、账面价值、应计利息、发行费用和折溢价。
- “长期应付款－专项应付款”不是普适的有息债务公式；只有附注明细及项目定义支持时才可采用，并解释剩余项目性质。
- 租赁负债、本金与利息、保理/信托/融资租赁分类不得重复。各类别和各期限段的合计与总额核对。
- 对外担保区别提供与接受、额度与实际余额、对合并范围内与外、是否合并抵销。担保对象、期限、状态有资料才更新。
- 受限资产用账面价值并列限制原因；评估价值、融资余额和受限账面价值不得互换。
- 附注应付债券仅证明相应报表日的会计余额，不代表截至签署日全部存续债券本金、发行/兑付、逾期或违约状态。

【专 E03第四节】子公司数量须区分全部、一级、重要子公司；合营、联营、参股与并表范围不混用。附注已明确披露的子公司财务数据可以直接使用，缺少项目才列补充需求。持股大于50%但未并表，核对并说明原因，不自动调整合并范围。

重要子公司30%筛选：专家采用最近一年资产、净资产或收入占合并相应项目30%以上；R14投资者保护参考文本脚注采用最近一期经审计口径且允许项目自定义。用于不同章节时明确各自定义；不将中期未经审计口径偷换成合同定义。

业务收入分类变化需建立有依据的对应表，不按名称相似任意归并。前五大客户、供应商、工程进度、项目投入和未结算金额未在五份材料中披露时列缺口，不能从科目总数拆出明细。

## 8 分析文字与重大事项的写法

【规 R00 3.1.1、3.2.3、3.6.7、3.7.3】【专 E02 G-NEUT、E03】

允许依据可比数据更新“增加、下降、扭亏、占比变化”等事实性描述，并计算同口径分项对合计变动的贡献。不要把“同时变化”写成经营因果关系：解释总资产的构成变化应比较资产分项，不因长期借款增加就断言其导致总资产增长；资金来源和用途另需依据。

原因、行业地位、现金流未来改善、债务偿付保障等判断只依据材料中的实际说明。不能沿用不再适用的旧原因，不能把模板中的“回款时点、扩大业务、政府支持”等例子写成事实。缺少原因时可写“主要变动项目为……，具体原因【待补充】”。

重大事项提示核对六类约定：发行和含权条款、资金用途及变更、增信、违约争议、投资者保护、持有人会议及受托管理的重要约定。核对九类影响事项：重组、股权质押冻结争议、短债/高成本债务、现金流和偿债指标、担保受限资产、评级、审计事项、不良信用处罚诉讼、其他重大事项。本次只更新材料能够支持的财务事实及必要分析，不自行生成发行方案或法律条款。

旧重大事项逐条标记持续、已解决、有后续影响、资料不足，不无声删除。材料明确揭示的新重大风险不能因专家模板写“默认不披露”而隐去；先准确列事实，专业性质和披露措辞待复核。

报告期内资产/净资产/收入变动达到50%仅作异常核查线索，不能直接认定重大资产重组。R00 3.6.9明确参照相应重大资产重组认定标准，尚需交易事实、对象、指标口径等证据；半年收入与全年收入不直接作此判断。

## 9 监管要求与专家阈值分别使用

【规 R00 3.6.7、3.7.3】主要业务板块一般关注收入或毛利润占比10%以上；近一年及近一期资产项目占总资产10%以上、负债项目占总负债10%以上，以及变动幅度30%以上的报表项目，应分析变动和原因。“以上”包含等于。分母、比较期间和原文条件必须一起保留；低于阈值仍可能有重要信息。

【规 R05】下表为所给2025年修订版的重点关注规则摘要。只有规则适用时点和发行人适用性明确，且分子、分母和所需资料齐全时，才计算并作相应提示；不代表一触发即不符合发行条件。

## 10 一般撰写及发行后模拟的条件规则

以下适用于后续完整撰写业务，本次财务更新无额外资料时仅保留原文并登记必要缺口：
- 使用上交所非公开发行、挂牌转让的适用表述；不得把专家模板中的公募“证监会注册”声明不加审查地当成私募固定范文。法律声明由已确认适用的项目文件确定。
- 本次申报总额与本期发行额、一般债券与专项品种、主体评级与债项评级分开；是否评级/增信由项目材料确定，不从附注推断。
- 募集资金按偿债、补流、项目投资、股权/资产收购、基金投资、混合用途分别取证；用途、金额、发行费用及计划时点须相互对应。不能从旧项目恢复本期方案或复制“均按约定使用”的结论。
- 【规 R00 8.4.1】私募募集资金变更按约定程序及适用要求办理，且与会议规则、受托管理协议一致；不存在有效约定或调整可能重大影响持有人时按原规则处理。原专家“谁家孩子谁抱走”等简化口号不代替具体适用规则。
- 发行后模拟先明确“资金到账尚未使用”还是“到账并按用途使用完毕”，再编制平衡的增减表。不能笼统将项目建设一律增加在建工程、将基金出资一律增加长期股权投资；按项目性质及会计分类确定。有息债务偿还须区分被偿还项目、到期部分及利息费用。
- 同一方案下第三节与第五节使用同一模拟假设，但第五节各报告期实际指标仍是实际数据。不能把所有模拟结果写成“偿债能力提高”。
- 【规 R14使用说明】投资者权益保护参考文本应按实际选择条款并调整编号，相关阈值和救济期限是约定条件，不能按报表更新。不得将全部备选项同时拼入正式文本。
- 城市建设、房地产、投资控股和专项品种需要额外规则及项目资料。本知识不将2026专项规则强套入本次普通私募财务更新。

## 11 修订 追溯与交付检查

【专 E03】【整】文字增删使用真实Word修订，包含金额、比例、期间和分析文字。表格数字也尽量保留真实修订，更新单元格可加统一浅色底纹便于定位；底纹不替代修订。新增或删除比较列记录为结构变化，不能只改显示标题。保留原书段落、表格、样式、目录和编号。

每项修改对应一条变更记录：位置、原文/原值、新文/新值、来源或公式、原因、状态。可在批注中标注短来源，并在台账提供完整定位；不能用整段材料复制充当溯源。

导出前检查：
- 全文位置清单全部有状态；资料已提供的地方不能以【待补充】逃避更新。
- 关键报表及所有引用没有主体、期间、单位错配；日期和“分别为”顺序一致。
- 每个新增事实有依据；合计和指标计算可复核；缺失、矛盾、零基数均明确。
- 原风险与新数据不冲突；没有虚构原因、违法违规定性或“截至签署日无……”结论。
- 合同数字、历史事件、发行参数未被误改；担保/评级/授信等缺口未被用旧数伪装补齐。
- 文件可以打开，修订可接受/拒绝；接受全部新修订后的正文与变更台账一致。拒绝本次修订应恢复相应原文；已有原始修订单独保留或在统一预处理时明确处理。
- 核对表格续页、表头、目录、脚注、页码及交叉引用，没有截断、重叠或乱码。不能仅凭程序成功保存声称版式验收完成。
